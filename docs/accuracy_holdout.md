# 金属管の中で電線をつないではいけません

## 結論
金属管内では電線に接続点を設けてはいけません。接続は、ジョイントボックスやプルボックス、器具のボックスなど、点検できる場所で行います。

## 根拠
- **電気設備技術基準の解釈 第159条（金属管工事）第1項第二号**
  「金属管内では、電線に接続点を設けないこと」
- 同様の規定が他の配線方法にもあります。
  - 合成樹脂管工事（第158条）
  - 金属可とう電線管工事（第160条）
- 電線の接続そのものの基準は、次の条文で定められています。
  - **電気設備技術基準（省令）第7条**
  - **解釈 第12条**（電線の接続法）：接続部分で電線の電気抵抗を増加させない、引張強さを20%以上減少させない、接続部分の絶縁を電線の絶縁物と同等以上の効力のあるもので被覆する、など
- 電気工事士の技能試験でも、管内接続に当たる施工は欠陥として扱われます。

## 禁止されている理由
1. **点検できない**：接続部の接触不良や発熱、絶縁劣化を発見できません。
2. **電線の引き替えができない**：接続部が管内で引っかかり、引き抜きも再挿入もできなくなります。
3. **事故のおそれ**：接続部が管内で発熱したり絶縁が劣化したりすると、短絡や地絡、火災につながります。金属管は導電性なので、漏電すると管に電流が流れる危険もあります。
4. **電線の損傷**：通線時に接続部が管内で引っかかり、被覆が傷つく原因になります。

## 実務での対処
- 電線を分岐する場合や、長い距離で電線をつなぐ必要がある場合は、途中にボックスを設けます。
- ボックス内では、リングスリーブ、差込形コネクタ、ねじ込み形コネクタなどで接続し、必要に応じて絶縁処理をします。
- ボックスにはふたをします。
- 管の途中でボックスが必要になりそうなときは、配管ルートを設計する段階で位置を決めておきます。

## 補足
条文の番号や細かい文言は、解釈の改正で変わることがあります。現場で確認するときは、最新の「電気設備技術基準の解釈」と内線規程（日本電気協会）を見てください。

# 金属管に入れる電線

## 結論
**絶縁電線（IV、HIVなど）を使います。** ただし「屋外用ビニル絶縁電線（OW）」は使えません。電線の形状にも条件があります。

## 根拠
**電気設備技術基準の解釈 第158条（金属管工事）第1項**

- 電線は**絶縁電線**（屋外用ビニル絶縁電線を除く）であること
- 電線は**より線**、または**直径3.2mm以下の単線**（アルミ線は4mm以下）であること
  - 短い金属管に収める場合は例外です
- 金属管内では**電線に接続点を設けない**こと

上位の規定は電気設備技術基準（省令）第56条・第57条（配線の感電・火災防止、使用電線）です。

## 実務上のポイント

1. **よく使う電線**
   - IV（600Vビニル絶縁電線）
   - HIV（耐熱ビニル絶縁電線）
   - 屋内配線では、IVが最も一般的です

2. **太さの目安**
   - 1.6mm、2.0mm、2.6mm、3.2mmは単線でOKです。
   - 3.2mmを超える太さは、**より線**（5.5mm²以上など）にします。

3. **管内で接続しない**
   - 接続はボックス内で行います。
   - 管内で接続すると、後から点検も交換もできないためです。

4. **管の太さと本数**
   - 電線の被覆を含む断面積の総和が、管の内断面積の**約48%以下**が目安です。
   - 詳細は**内線規程**の金属管工事の項で確認してください。
   - 内線規程は民間規程ですが、実務の標準として広く使われています。

5. **同じ回路の電線は一緒に通す**
   - 交流回路では、行きと帰りの電線を別々の金属管に入れません。
   - 電磁的不平衡により管が発熱するためです。

6. **金属管の接地**
   - 金属管自体には接地工事が必要です（電技解釈 第158条の接地規定、第29条）。
   - 300V以下ならD種接地、乾燥した場所の短い管など、省略できる条件もあります。

# 電灯配線と電話線・LANケーブルを近くに通すときの注意点

## 1. 基本の考え方：接触させない、混触させない

電灯線（強電）と電話線・LANケーブル（弱電）が接触すると、次の問題が起きます。
- 弱電側に電圧がかかり、感電や機器の破損につながる
- 発熱して火災の原因になる
- 被覆の劣化や損傷で、気づかないうちに混触する

## 2. 根拠となる法令・基準

| 根拠 | 内容 |
|---|---|
| **電気設備に関する技術基準を定める省令 第62条** | 配線は、他の配線や弱電流電線等と接近・交差する場合、混触による感電・火災のおそれがないよう施設すること |
| **電気設備技術基準の解釈 第167条** | 低圧配線と弱電流電線等との接近・交差の具体的な方法 |
| **有線電気通信設備令（屋内電線に関する規定、第11条付近）** | 通信線側から見た強電流電線との関係（離隔・接触防止） |

※項・号の細かい番号は改正で変わることがあります。工事の前に最新の条文を確認してください。

## 3. 実務での具体的な注意点

**① 接触しないように施設する**
- 電灯線と弱電線は、直接触れないように離して施工します。
- 解釈第167条では、離隔するか、隔壁を設けるか、電線を絶縁管などに収めるといった方法が示されています。

**② 同じ管・ボックス・ダクトに一緒に入れない**
- 電灯線と弱電線を同じ電線管に通すのは原則NGです。
- 同一ボックスに入れる場合は、**隔壁（セパレータ）** で仕切るなどの対策が必要です。

**③ 交差は直角に**
- 並行して長く走らせるのは避けます。
- 交差する場合は、直角に近い角度で短く交差させます。

**④ ケーブルを傷つけない**
- 固定のステープルを強く打ち込みすぎない、角で擦れないようにする、といった基本も大切です。
- 被覆損傷が混触の原因になります。

**⑤ ノイズ対策（LANケーブルの場合）**
- 法令上の義務ではありませんが、電灯線と近接・並走するとノイズで通信品質が落ちることがあります。
- 並走を避ける、距離をとる、金属管やセパレータで分けるのが有効です。
- 蛍光灯の安定器やインバータ機器の近くも避けましょう。

## 4. 資格との関係
- 電灯配線（一般用電気工作物の600V以下の工事）は、**電気工事士法**により、第二種電気工事士以上の資格が必要です（法第3条）。資格なしの方は電気工事の作業に従事できません。
- 弱電工事（電話・LAN）自体は電気工事士の対象外ですが、強電との離隔や接近の判断は、電気工事士の責任で確認する場面が多いです。

## まとめ
**「触れさせない・同じ管に入れない・並走を避ける・隔壁や管で分ける」** が基本です。迷ったら先輩や施工管理者に確認し、現場では最新の電技解釈と内線規程を確認してください。

# 住宅の屋内電路の対地電圧

## 結論
**原則は150V以下**です。

- 根拠：電気設備技術基準の解釈 **第143条第1項**（電路の対地電圧の制限）
- 対象は住宅の屋内電路です。ただし電気機械器具内部の電路は除きます。

## 対地電圧とは（解釈 第1条）
- **接地式電路**：電線と大地との間の電圧
- **非接地式電路**：電線間の電圧

### 実務での例
| 方式 | 対地電圧 | 住宅での扱い |
|---|---|---|
| 単相2線式100V（接地側あり） | 100V | OK |
| 単相3線式100/200V（中性線接地） | 100V | OK（200V機器も使える） |
| 単相2線式200V（非接地） | 200V | 原則NG（下記の例外条件が必要） |
| 三相200V（非接地） | 200V | 原則NG（同上） |

「200Vを使っているから150V超」とは限りません。一般的な住宅の単相3線式なら、200V機器を使っても対地電圧は100Vです。

## 例外：300V以下まで認められる場合
エアコンやIHクッキングヒーターなど、**定格消費電力2kW以上の機器**と、それに電気を供給する屋内配線については、次の条件を満たせば対地電圧**300V以下**で施設できます（解釈 第143条第1項ただし書）。

- 電路の対地電圧は300V以下
- 配線は、人が触れるおそれのない隠ぺい場所に施設し、合成樹脂管工事、金属管工事、ケーブル工事のいずれかで行う
- 機器には専用の開閉器と過電流遮断器を設ける（過電流遮断器が開閉機能を兼ねる場合は開閉器を省略可）
- 地絡時に自動で電路を遮断する装置（漏電遮断器など）を設ける
- 機器と配線は、電気的に分離した専用のものとする

このほか、太陽電池や蓄電池、燃料電池など、住宅用の直流電路についても個別の例外規定があります。

## 根拠

# ケーブルが壁を貫通する部分の施工

壁の種類（木造の壁、コンクリート壁、防火区画の壁、外壁）で対応が変わります。

## 1. 共通の基本

- **穴は必要最小限にし、切り口のバリや角でケーブル被覆を傷つけないようにします。** 被覆が傷つくと漏電や火災の原因になります（電気設備技術基準 第56条、配線の感電・火災防止）。
- **コンクリート壁や金属板の貫通では、スリーブ（さや管）やブッシングを使って保護します。**
- **貫通部でケーブルに無理な力や曲げをかけません。** 固定は貫通部の近くで行い、ケーブルが壁の中で引っ張られないようにします。
- ケーブル工事の一般的な施設方法は、電気設備技術基準の解釈（電技解釈）第164条（ケーブル工事）を確認してください。

## 2. 外壁の貫通（屋外→屋内）

- **雨水が入らないようにします。** 防水型のウェザーキャップや防水スリーブを使い、屋外側を下向きにします。ケーブルは一度下に垂らしてから立ち上げる（ドリップループ）と水が伝って入りにくくなります。
- 貫通部の隙間は、防水・防火性のあるシーリング材やパテで処理します。

## 3. 防火区画・耐火構造の壁・床の貫通（特に重要）

- ケーブルが防火区画を貫通する場合は、**建築基準法施行令 第112条第20項**（防火区画を貫通する配管等）の対象です。
- 貫通部の隙間を、**不燃材料（モルタルなど）で埋める**か、**国土交通大臣認定を受けた耐火措置工法（耐火パテ、耐火シート、耐火ブロック、措置材など）** で処理します。
- 認定工法は、使用するケーブルの種類・太さ・本数、壁の種類、穴の大きさが決まっています。**メーカーの施工要領書どおりに施工**してください。
- 施工後は、貫通部に区画貫通処理であることを示す標識を貼る場合が多いです。

## 4. 木造の壁・金属ラスや金属板の貫通

- 金属ラスや金属板を貫通するときは、**電線がそれらに触れないよう、絶縁管（合成樹脂管や磁器製の管など）で保護**します。接触していると、被覆が傷んだときに壁の金属部分が充電されて感電や火災につながります。
- 詳しい規定は電技解釈の各工事の条文と**内線規程**（日本電気協会）にあります。条番号は版によって異なるので、最新版で確認してください。

## 5. 現場でありがちなミス

- 穴あけ後にバリを取らず、ケーブルを引いて傷つける。
- 防火区画の貫通部を、普通のコーキングやウレタンフォームで埋めてしまう。
- 外壁の貫通部の防水が不十分で、雨漏りや壁内の腐食を起こす。
- 壁内に隠れているケーブルや配管、スタッドを確認せずに穴をあけてしまう。

## 6. 資格について

- 一般住宅や小規模店舗などの電気工事は、**第二種電気工事士**の資格が必要です（電気工事士法 第3条）。
- 資格のない方は、壁の穴あけ、ケーブルを通す補助、清掃、材料の運搬といった**補助作業**に限られます。配線の接続・固定などの電気工事そのものはできません（電気工事士法施行規則 第2条の軽微な工事を除く）。

## まとめ

| 場所 | 主な対策 |
|---|---|
| 一般の壁 | バリ取り、必要ならスリーブやブッシング |
| 外壁 | 防水処理、ドリップループ、シーリング |
| 防火区画 | 不燃材での充填、または認定耐火措置工法（令112条20項） |
| 金属ラス・金属板 | 絶縁管で保護し、金属部分と電線を接触させない |

現場ごとに設計図書（特記仕様書）や元請・先輩電気工事士の指示がありますので、迷ったら必ず確認してから施工してください。

# 結論

**第二種電気工事士の免状だけでは、自家用電気工作物（高圧受電の工場など）の配線工事はできません。** ただし、例外がいくつかあります。

## 1. 根拠：電気工事士法 第3条

| 条項 | 内容 |
|---|---|
| 第3条第1項 | 自家用電気工作物（最大電力500kW未満の需要設備）の電気工事は、**第一種電気工事士**でなければ作業に従事できない（特殊電気工事を除く） |
| 第3条第2項 | **一般用電気工作物**の電気工事は、第一種または第二種電気工事士でなければ従事できない |
| 第3条第3項 | ネオン工事・非常用予備発電装置工事は**特種電気工事資格者** |
| 第3条第4項 | 自家用電気工作物のうち、**600V以下の簡易電気工事**は、認定電気工事従事者でも従事できる |

違反すると、電気工事士法第14条により**3月以下の懲役または3万円以下の罰金**です。

## 2. 例外的にできるケース

### ① その工場が「一般用電気工作物」の場合
- 600V以下の低圧で受電している工場が該当し、**第二種でも工事できます**（電気事業法第38条第1項、電気事業法施行規則第48条）。
- ただし、爆発性・引火性の物質が存在し危険が特に大きい場所などは、低圧受電でも自家用扱いになります（同規則第48条）。
- 同一構内に小出力発電設備以外の発電設備（例：出力50kW以上の太陽光発電）がある場合も同様です。

### ② 認定電気工事従事者の認定を受けた場合
- 第3条第4項により、**600V以下で使用する設備の工事（電線路を除く）**、つまり工場の低圧配線や動力回路などが可能になります。
- 認定は、第二種電気工事士免状に加えて実務経験や認定講習などの要件を満たして受けます。詳細は電気工事士法施行規則を確認してください。
- 高圧部分（受電設備、キュービクル、高圧ケーブルなど）は対象外です。

### ③ 軽微な工事・軽微な作業
- 電気工事士法施行令第1条、施行規則第2条で定める**軽微な工事・作業**は、無資格でも可能です。例：電線管相互の接続、ボックスの取付け、端子へのコードのねじ止めなど。
- 配線工事の本体は対象外です。

### ④ 補助作業
- 第一種電気工事士などの**指揮・監督のもとでの補助作業**（穴あけ、ケーブル運搬、配管の取付けなど）は、電気工事に当たらない範囲であれば可能です。
- ケーブルの結線や接続などは、有資格者本人が行う必要があります。

## 3. 実務上の確認ポイント

1. **受電電圧と契約種別の確認**：高圧受電なら自家用、低圧受電なら原則として一般用です。
2. **工事範囲の確認**：高圧部分は第一種、低圧部分は第一種または認定電気工事従事者が対象です。
3. **特殊な場所の確認**：爆発性雰囲気のある場所などは、電気設備技術基準（電技解釈 第175条〜）の防爆要求にも注意してください。
4. **電気工事業の登録**：事業として請け負う場合は、電気工事業法による登録・届出と主任電気工事士の設置が必要です（電気工事業法第3条、第19条）。

## まとめ

- 第二種のみ：一般用電気工作物（低圧受電の工場など）は可能です。高圧受電の工場の配線工事は不可です。
- 第二種＋認定電気工事従事者：自家用でも600V以下の簡易電気工事は可能です。
- 第一種：500kW未満の自家用電気工作物の工事が可能です。

まず工場の受電方式を確認し、必要なら第一種電気工事士の取得や認定電気工事従事者の認定を検討してください。

# 検電器の使い方

検電器は、**「電気が来ていない」ことを作業直前に自分で確かめる道具**です。感電事故の多くは「切ったつもり」「回路を間違えた」から起きるため、停電作業では必ず使います。

## 1. 根拠になる法令
- **労働安全衛生規則 第339条第1項**
  - 電路を開路して作業するときは、開閉器への施錠や通電禁止の表示、または監視人の配置が必要です（第1号）。
  - 開路した電路が**高圧・特別高圧**なら、**検電器具で停電を確認**し、**短絡接地器具で確実に短絡接地**することが義務です（第2号）。
- 低圧は条文上、検電が明記されていません。しかし、作業者を感電から守るという趣旨と社内の安全ルールから、**低圧でも検電は実務上の必須手順**です。
- **労働安全衛生規則 第36条第4号**：高圧・特別高圧、低圧の充電電路の敷設や修理などの業務には、特別教育が必要です。
- **電気工事士法 第3条**：電気工事の作業は、資格を持つ人が行います。資格のない人は、有資格者の指示や監督のもとで補助作業のみ行えます。

## 2. 基本の手順
1. **電圧に合った検電器を選ぶ**
   - 低圧用、高圧用、特別高圧用があります。使用電圧に合わないものは、検知できなかったり、感電の危険があったりします。
   - 高圧用は絶縁棒（伸縮式など）が付いた専用品です。
2. **使用前点検**
   - 外観（割れ、汚れ、絶縁部の傷）と電池を確認します。
   - テストボタンや検電器チェッカーで、**正常に作動するか**を確認します。
   - 点検で異常があれば、使わずに交換します。
3. **開路と表示**
   - ブレーカーや開閉器を切り、施錠するか「通電禁止」の札を掛けます。
4. **検電**
   - 作業する箇所のすべての線について、**各相ごと・相間・対地間**で確認します。単相3線式なら、R-S-T各相と中性線、大地を確認します。
   - 接触式は、先端を導体の金属部分にしっかり当てます。
   - 非接触式は、被覆の上から近づけて反応を見ます。
   - **電源側と負荷側の両方**を確認すると確実です。
5. **使用後にもう一度作動確認**
   - 「鳴らなかった」のが無電圧だからか、故障だからかを区別するため、検電の後にも検電器が正常に作動するか確認します。
6. **高圧・特別高圧なら短絡接地**
   - 検電後に短絡接地器具を取り付けます（第339条第1項第2号）。
   - 順序は「接地側を先に接続し、線路側を後に接続」です。取り外すときは逆の順にします。

## 3. 注意点
- **検電器が鳴らなくても、無電圧とは限りません。**
  - 電池切れや故障のほか、感度不足や接触不良、被覆が厚い場合や金属管内の配線などが原因になります。
  - 非接触式は、**シールド線や金属管の中の配線**には反応しにくいです。
- **誘導電圧や残留電荷**にも注意します。長いケーブルやコンデンサ（進相コンデンサなど）では、停電後も電気が残ることがあります。
- 高圧用は、**絶縁棒の握り部の「つば」より先を持たない**ようにします。
  - 絶縁用保護具や防具の使用は、労働安全衛生規則 第341条〜第343条や第349条などに規定があります。
- 雨天や湿気が多い場所では誤動作や絶縁低下が起こりやすいため、使用を控えます。
- 低圧の確認には、検電器に加えて**テスターで電圧を測る**のも有効です。ただし、測定する時点でも「電気が来ているかもしれない」前提で扱います。

## 4. 初心者が覚えておくこと
- **検電は「確認」であり、安全の保証ではありません。**
- 検電する前に、自分で触ったり、導体に近づいたりしてはいけません。
- 判断に迷ったら、必ず先輩や有資格者に確認します。

もし使う場面（盤内、コンセント、高圧キュービクルなど）が決まっていれば、その用途に合わせた具体的な手順も説明できます。

# ねじなし電線管（E管）とは

## 概要
**管端にねじを切らず、止めねじで接続する金属製の電線管**です。呼び方は「E19」「E25」のようにEを付けます（Eは Electric の頭文字とされます）。規格は **JIS C 8305（鋼製電線管）** で、次の3種類が規定されています。

| 種類 | 記号 | 特徴 |
|---|---|---|
| 厚鋼電線管 | G管 | 肉厚が厚く、管端にねじを切って接続する |
| 薄鋼電線管 | C管 | 肉厚が薄く、ねじ切りして接続する |
| **ねじなし電線管** | **E管** | 最も薄肉で軽く、ねじ切り不要 |

呼び番号は、E管・C管では外径に近い数字です（E19なら外径約19 mm）。G管は内径に近い数字なので、同じ数字でも外径が違う点に注意してください。

## 特徴
- ねじ切り機が不要で、**金切りのこやパイプカッタで切断するだけ**なので施工が早い
- 軽く、曲げ加工もしやすい
- 肉厚が薄いため、**強い衝撃を受ける場所ではG管のほうが適する**
- ねじ込み式ではないので、**接続部の締付けが不十分だと抜けや接地不良の原因**になる

## 接続部品と施工の要点
- **ねじなしカップリング**：管どうしの接続用
- **ねじなしボックスコネクタ**：ボックスへの接続用（ロックナットで固定）
- **ねじなしブッシング**：管端の電線保護用

施工の流れと注意点は次のとおりです。
1. 管を切断し、**リーマで内側のバリを必ず除去**する（電線の被覆を傷つけないため）
2. カップリング内の突き当たりまで管をしっかり差し込む
3. **止めねじの頭がねじ切れるまで**締め付ける（所定トルクで切れる構造のものが多い）
4. 管端にはブッシングを付ける
5. 曲げる場合は、管の内側半径を**管内径の6倍以上**にする（内線規程）

## 根拠となる法令・基準
- **電気設備技術基準の解釈（電技解釈）第159条（金属管工事）**
  - 使用する電線は絶縁電線（屋外用ビニル絶縁電線を除く）で、より線または短い単線であること
  - 管内で電線に接続点を設けないこと
  - 管の厚さは、コンクリートに埋め込む場合は1.2 mm以上、それ以外は原則1 mm以上
  - 管の端口や内面は、電線の被覆を損傷しないよう滑らかにすること
  - 金属管には接地工事を施すこと（省略できる条件あり）
- **電技解釈 第17条**：接地工事の種類と施工方法（接地工事の種類はD種）
- **JIS C 8305**：鋼製電線管の寸法・品質の規格
- **内線規程 3110節（金属管工事）**：曲げ半径や支持間隔などの実務的な基準（民間規程ですが、現場の実務上の拠り所です）

※ 電技解釈は改正されることがあり、項・号の番号が変わる場合があります。実際の施工や試験前には、最新版を確認してください。

## 第二種電気工事士との関わり
技能試験では**E19などのねじなし電線管**を使う課題が出ます。ボックスコネクタ、ロックナット、ブッシングの取付けが問われるので、**差込み不足や締付け不足は欠陥**になります。

追加で、曲げ加工、接地の省略条件、他の配管（PF管・VE管）との使い分けなども説明できますので、必要なら聞いてください。
