# 金属管の中で電線をつないではいけません

## 根拠
**電気設備技術基準の解釈 第159条（金属管工事）第1項**で、金属管内には電線の接続点を設けないこととされています。

同条では、ほかにも次のように定められています。
- 電線は絶縁電線（屋外用ビニル絶縁電線を除く）とする
- 電線はより線、または直径3.2 mm以下（アルミ線は4 mm以下）の単線とする

なお、電線の接続の一般的な方法（電気抵抗を増やさない、絶縁性能を落とさない、引張強さを20％以上減少させない等）は**同解釈 第12条（電線の接続法）**にあります。

## 接続点を設けてはいけない理由
- 接続部が見えず、点検や補修ができない
- 電線の引き替えや引き込みのときに、接続部へ力がかかって抜けたり断線したりする
- 接続部の発熱や絶縁劣化が管内で起き、放熱できないため火災や漏電の原因になる

## 実際の施工
接続は、管の途中にある**アウトレットボックスやジョイントボックスなどの中**で行います。
- 接続部は、規定の接続器具（差込形コネクタ、リングスリーブ、ボルト接続など）を使い、絶縁処理をします。
- ボックスには、ふたを取り付けます。

## 補足
- 金属ダクト工事では、条件を満たせばダクト内で接続できます（解釈 第163条）。金属管と同じ扱いではありません。
- 電線の接続作業そのものが電気工事にあたるため、資格のない人はできません（電気工事士法 第3条）。無資格の方は、この作業は有資格者に任せ、見て学ぶようにしてください。

# 金属管に入れる電線の選び方

## 結論
**屋外用ビニル絶縁電線（OW）以外の絶縁電線**を使います。現場では **IV（600Vビニル絶縁電線）** が最も一般的で、必要に応じて HIV（600V二種ビニル絶縁電線）なども使います。

## 根拠：電気設備技術基準の解釈 第159条（金属管工事）
低圧屋内配線の金属管工事では、次の3点が定められています。

1. **電線は絶縁電線（屋外用ビニル絶縁電線を除く）であること**
   - 裸電線は使えません。
   - OW（屋外用ビニル絶縁電線）も使えません。
2. **電線は「より線」または「直径3.2mm以下の単線」であること**（アルミ線は直径4mm以下）
   - 短小な金属管に収める場合は例外です。
   - 銅線の単線なら直径3.2mm（約8mm²）までで、それより太い電線は**より線**にします。
3. **金属管内では電線に接続点を設けないこと**
   - 接続はプルボックスやジョイントボックス内で行います。
   - 管内で接続すると、点検や電線の引き替えができず、発熱や絶縁不良の原因にもなります。

## 実務上の注意
- **電線管の太さに余裕を持たせる**：同じ管に何本も入れると、引き入れ時に被覆を傷つけたり、発熱で電流容量が下がったりします。電線の被覆を含めた断面積の合計が管の内断面積の**約48%以下**が目安です（内線規程 JEAC 8001 の金属管工事の項）。
- **管の端口は電線を傷めない形状にする**：ブッシングを付けるなどして、被覆を損傷しないようにします（解釈第159条）。
- **接地工事も必要**：金属管には原則として接地工事をします（解釈第159条、第17条、第29条）。条件によって省略できる場合もあります。
- **電線の許容電流**：太さは負荷電流に対して許容電流が足りるものを選びます（解釈第146条）。電線管に複数本入れる場合は電流減少係数も考慮します。

## 資格について
電気工事士法第3条により、一般用電気工作物の工事は電気工事士の資格が必要です（軽微な工事を除く）。資格がない方は、**有資格者の指示・監督のもとで補助作業**をする形になります。

不明点があれば、使用電圧や施工場所（屋内・屋外・コンクリート埋設など）を教えてもらえれば、より具体的に答えます。

# 電灯配線と電話線・LANケーブルを近くに通すときの注意点

## 1. 基本の考え方：混触させない
電灯配線（強電）と電話線・LANケーブル（弱電流電線等）が接触すると、弱電側に電圧がかかって感電や火災、機器の破損につながります。そのため、接近・交差する場合は混触しないようにすることが求められています。

**根拠**
- 電気設備技術基準（電技省令）第62条：配線が他の配線や弱電流電線等と接近・交差する場合は、混触による感電・火災のおそれがないよう施設すること。
- 電気設備技術基準の解釈（電技解釈）第167条：低圧配線と弱電流電線等・管との接近または交差の具体的な方法。

## 2. 現場での具体的な方法
電技解釈第167条の趣旨に沿うと、実務上は次のいずれかになります。

1. **離隔する**：互いに接触しないように施設します。がいし引き工事など露出配線の場合は、離隔距離の数値が決められています。
2. **隔壁を設ける**：絶縁性の隔壁で仕切ります。
3. **保護管に収める**：電灯線側または弱電側を、合成樹脂管や金属管などの**絶縁性・耐火性のある管**に入れて、直接接触しないようにします。

離隔距離などの細かい数値は、電技解釈の最新版か内線規程（JEAC 8001）で必ず確認してください。私の記憶だけで数値を断定するのは避けたほうがよいです。

## 3. 同じ管・ボックスに一緒に入れない
- 電灯線と電話線・LANケーブルを**同じ電線管、ダクト、ボックスに一緒に入れるのは原則NG**です。
- スイッチボックスやアウトレットボックスで同居させる場合は、隔壁で仕切ります。
- 詳細は内線規程の該当節で確認してください。

## 4. 通信品質（ノイズ）の観点
法令上の義務とは別に、品質面でも離すのが基本です。
- 電源線と並行して長く敷くと、誘導ノイズで通信速度の低下やエラーが起きることがあります。
- LANケーブルは、電源線との間隔を確保する、交差するなら直角に交わす、金属管やシールド付きケーブルを使う、といった対策が有効です。
- 離隔の目安は、JIS X 5150（構内情報配線システム）やISO/IEC 14763-2など、配線規格に示されています。

## 5. 資格との関係

# 結論

**原則としてできません。** 第二種電気工事士の免状だけでは、自家用電気工作物の電気工事に従事できません。ただし、**工場が「一般用電気工作物」にあたる場合**や、**軽微な作業**に限っては可能です。

---

## 1. 根拠（電気工事士法 第3条）

| 対象 | 必要な資格 | 条文 |
|---|---|---|
| 一般用電気工作物の工事 | 第一種または第二種電気工事士 | 第3条第2項 |
| 自家用電気工作物（最大電力500kW未満の需要設備）の工事 | **第一種電気工事士** | 第3条第1項 |
| 上記のうち「簡易電気工事」（600V以下） | 第一種電気工事士、または**認定電気工事従事者** | 第3条第4項、施行規則第2条の2 |
| ネオン工事・非常用予備発電装置工事 | 特種電気工事資格者 | 第3条第3項 |

簡易電気工事（600V以下で使用する自家用電気工作物の工事。電線路に係るものを除く）は、第二種電気工事士のままではできません。第一種の免状か、認定電気工事従事者認定証が別途必要です。

違反した場合は罰則があります（同法第14条）。

## 2. 例外として第二種でも工事できるケース

**① 工場が一般用電気工作物に該当する場合**
- 低圧（600V以下）で受電しており、小出力発電設備を超える発電設備を同一構内に設置していない工場は、一般用電気工作物です（電気事業法施行規則第48条第1項）。
- この場合は第二種電気工事士でも工事できます。
- ただし、火薬類製造所など爆発性・引火性の物が存在する場所は除外されます（同条第2項）。
- 「工場だから自家用」とは限らないので、**受電方式（高圧か低圧か）と発電設備の有無**を確認してください。

**② 軽微な作業（電気工事士法施行規則 第2条）**
- 自家用電気工作物でも、600V以下で使用する接続器・ライティングダクトへの電線接続、電圧600V以下の電気機器へのコード接続などの軽微な作業は、免状がなくても可能です。
- 第二種電気工事士でなくてもできる作業なので、「第二種だからできる」わけではありません。

**③ 補助作業**
- 第一種電気工事士（または認定電気工事従事者）の指示・監督のもと、穴あけ、電線の引き込み、運搬などの補助的作業に従事することは可能です。
- 電線の接続、器具の取付け・結線など、電気工事士法上の「電気工事の作業」は含まれません。

## 3. 第二種電気工事士が自家用電気工作物の工事をしたい場合

- **第一種電気工事士**の免状を取得する。
  - 試験は筆記と技能です。
  - 免状交付には実務経験（5年）などの要件があり、第二種の経験だけでは不足する場合があります。
- または、**認定電気工事従事者認定証**を取得する。
  - 第二種電気工事士の免状取得後、実務経験3年以上＋認定講習の受講が要件です。
  - 対象は簡易電気工事のみです。

## 4. 補足

- 最大電力500kW以上の需要設備は、電気工事士法第3条の対象外です。実際には電気主任技術者の監督のもとで施工されます。
- 電気工事業を営む場合は、別途電気工事業法に基づく登録等と、主任電気工事士の配置が必要です。

**まとめ**

- 低圧受電で一般用電気工作物に該当する工場なら、第二種でも可能です。
- 現場に入る前に、**その工場が一般用か自家用か**を必ず確認してください。

# 検電器の使い方

検電器は、**電気が来ているかどうかを確認する器具**です。「停電したはず」という思い込みで作業しないために使います。

## 1. 法令上の位置づけ

- **労働安全衛生規則 第339条（停電作業を行なう場合の措置）**
  - 電路を開路して作業する場合は、開閉器に施錠するか、通電禁止の表示をするか、監視人を置きます（第1項第1号）。
  - 開路した電路が**高圧または特別高圧**の場合は、**検電器具で停電を確認**し、**短絡接地器具で確実に短絡接地**します（第1項第3号・第4号）。
  - 条文上、検電器具による確認が明記されているのは高圧・特別高圧です。ただし低圧でも、実務では検電して確認するのが基本です。
- **原則は停電作業**です。活線作業・活線近接作業をする場合は、安衛則 第341条〜第343条付近の防護措置（絶縁用保護具、防具など）が必要です。条番号は改正されることがあるので、最新の条文で確認してください。

## 2. 基本の流れ（確認 → 検電 → 確認）

1. **使用前点検**
   - ひび割れや汚れがなく、電池が入っていることを確認します。
   - 検電器の定格電圧が、対象の電圧（低圧用か高圧用か）に合っていることを確認します。
2. **作業前の動作確認**
   - 充電中とわかっている電路や、チェッカー（テスト用）で、検電器が正常に作動することを確認します。
3. **対象箇所を検電**
   - 作業する**すべての相・すべての極**を検電します。単相3線式なら赤・黒・白（中性線）それぞれです。
   - 検電する場所は、**作業箇所の電源側・負荷側**を含め、できるだけ作業箇所に近いところにします。
4. **作業後でなく「検電直後」にもう一度動作確認**
   - 検電後、再び既知の充電部などで、検電器が壊れていなかったか確認します。
   - 無反応を「停電」と判断するには、この前後の確認が重要です。

## 3. 低圧用検電器（若手が使うことが多い）

- **ネオン式・電子式（音と光）**があります。先端の金属部を測定箇所に当て、反応で充電の有無を判断します。
- コンセントや端子台では、**各極それぞれ**に当てます。
- **反応がなくても「停電」と断定しない**でください。次のような原因が考えられます。
  - 電池切れや故障
  - 先端が被覆の上から当たっていて、金属に触れていない
  - 感度不足
- 誘導電圧・静電誘導で**誤って反応する**こともあります。迷ったら**テスター（回路計）などで電圧を測って確認**してください。

## 4. 高圧用検電器の注意点

- **有資格者・教育を受けた人が行う作業**です。
  - 高圧の電気取扱いには**特別教育**が必要です（安衛則 第36条第4号）。
  - 第二種電気工事士の工事範囲は**600V以下**です（電気工事士法 第3条、同法施行規則 第2条）。
- 次のものを使用します。
  - **絶縁手袋・絶縁長靴・保護帽**などの保護具（安衛則 第341条・第342条付近の規定）
  - 検電器の**握り位置（つばより手前）**を守ること
  - 雨天・湿度が高いときは使用に注意し、できれば避けること
- 検電後は、**短絡接地**を行ってから作業します。これは第339条の要求事項です。

## 5. よくある失敗

- 動作確認をせず、「鳴らなかったから大丈夫」と判断する。
- 1相しか検電しない。
- 作業中に別の電源（他回路・逆流・誘導電圧）から通電する可能性を忘れる。
- 低圧用検電器を高圧に使う。

## 6. 最低限守ること

> **「確認 → 検電 → 確認」を行い、停電が確認できるまでは充電中として扱う。**

不安なときは、上司や有資格者に確認してから作業してください。

必要なら、「コンセント回路での検電の具体手順」や「分電盤での使い方」も説明します。

# ねじなし電線管（E管）とは

## 概要
電線を通す**鋼製の電線管**の一種で、**管の端にねじを切らずに**、専用の附属品で接続するタイプです。呼び方は **E19、E25、E31、E39、E51、E63、E75** で、Eは "Electric" ではなく、ねじなし（Edgeless 的な意味合いで覚える人が多い）電線管の記号として使われています。数字はおおよその外径(mm)です。規格は **JIS C 8305**（鋼製電線管）です。

## 金属管の種類との比較

| 種類 | 記号 | 肉厚 | 接続方法 |
|---|---|---|---|
| 厚鋼電線管 | G | 厚い | ねじ接続 |
| 薄鋼電線管 | C | 薄い | ねじ接続 |
| **ねじなし電線管** | **E** | 薄い | **止めねじ（ねじ切れ式）** |

## 特徴
- **ねじ切り作業が不要**なので、施工が速く、現場作業が楽です。
- 薄肉で軽く、扱いやすいです。
- 切断後は **リーマ**で内側のバリを必ず取ります。電線の被覆を傷つけないためです。
- 曲げは **パイプベンダ**を使います。

## 接続の方法
- 管どうしは**ねじなしカップリング**で接続します。
- ボックスとの接続は**ねじなしボックスコネクタ**とロックナットを使います。
- 管を奥まで差し込み、**止めねじの頭部がねじ切れるまで締め付けます**。これで規定の締付けができた目安になります。
- 技能試験でも、このねじ切れの確認や管の差込みが見られます。

## 根拠になる法令・基準
- **電気設備技術基準の解釈 第158条（金属管工事）**
  - 管と附属品は、堅ろうに、かつ電気的に完全に接続すること。
  - 管の端口や内面は、電線の被覆を損傷しない滑らかなものとすること。
  - 管の厚さの規定（コンクリート埋込みは1.2mm以上など）があります。
  - 電線管内では電線に接続点を設けないこと。
  - 金属管には接地工事を行うこと（省略できる条件あり）。
- **電気設備技術基準の解釈 第29条**：接地工事の種類と施設方法。
- **JIS C 8305**：ねじなし電線管の寸法や厚さの規格。
- **内線規程 1360節（金属管工事）**：民間規程ですが、実務の標準として広く使われています。

爆発性粉じんや可燃性ガスのある場所の工事（解釈第175条など）では、ねじ接続の厚鋼電線管などが求められ、ねじなし電線管は原則使えません。

## 資格との関係
- 電気工事は、電気工事士法第3条により、**資格がなければ作業できません**。補助作業はできますが、配線や接続などの本体作業はできません。
- **第二種電気工事士**ができるのは、一般用電気工作物（住宅や小規模店舗など）の工事です。
- ねじなし電線管を使った金属管工事は、第二種電気工事士の**技能試験**でも出題されます。

条文の項番や内容は改正されることがあります。実際の施工では、最新の「電気設備技術基準の解釈」や内線規程、現場の仕様書を確認してください。
