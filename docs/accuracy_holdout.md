# 金属管の中で電線を接続してもいいか

**結論：だめです。金属管の中では電線に接続点を設けてはいけません。** 接続はボックス内で行います。

## 根拠

- **電気設備技術基準の解釈 第159条第1項第三号（金属管工事）**
  「金属管内では、電線に接続点を設けないこと」
- **電気設備技術基準（省令）第7条／解釈 第12条（電線の接続法）**
  接続部で電気抵抗を増やさないこと、接続部の強さを20％以上落とさないこと、絶縁性能を電線と同等以上に保つことなどを求めています。
- 同じ考え方は、合成樹脂管工事（解釈 第158条）や金属可とう電線管工事（解釈 第160条）にもあります。

※解釈は改正されることがあるため、実務では最新版や内線規程も確認してください。

## なぜだめなのか

- 管内の接続部は点検も増し締めもできず、接続不良による発熱や火災のおそれがあります。
- 電線を引き入れたり引き替えたりするときに、接続部が管内で引っかかったり、外れたり、被覆が傷ついたりします。
- 接続部は電線より太くなりがちで、管内に収まりにくくなります。

## 実際の施工

- 接続は、アウトレットボックス、ジョイントボックス、プルボックスなどの**ボックス内**で行います。
- 接続方法は、差込形コネクタ、リングスリーブ、ねじ込み形コネクタなどです。接続後は絶縁処理（テープ、キャップなど）を行います。
- 距離が長い場合や曲がりが多い場合は、途中にプルボックスを入れて、そこで引き入れや接続をします。

## 資格について

電線の接続を含む電気工事の作業は、軽微な工事を除き、電気工事士法第3条により有資格者でなければできません。

- 第二種電気工事士：一般用電気工作物（住宅や小規模店舗など）の工事
- 資格なし：電気工事士の補助作業（管の搬入、配管の補助など）

資格がない人が接続作業をすることは法令違反です。

## まとめ

- 金属管の中では接続しない。
- 接続はボックス内で行う。
- 接続作業ができるのは有資格者のみ。

# 金属管に入れる電線の選び方

## 結論
**屋内配線なら、ビニル絶縁電線（IV）などの「絶縁電線」を使います。** ただし次の2点に注意してください。
- 屋外用ビニル絶縁電線（OW）は使えません。
- 太い電線は、単線ではなく**より線**にします。

## 根拠と具体的なルール

### 1. 絶縁電線を使う（OWは不可）
電気設備技術基準の解釈 **第158条（金属管工事）第1項** により、電線は「絶縁電線（屋外用ビニル絶縁電線を除く）」とされています。
- 一般的には **IV**（600Vビニル絶縁電線）、**HIV**（耐熱用）、**EM-IE**（エコ電線）などを使います。
- 裸電線は使えません。

### 2. 単線は直径3.2mm以下、それ以上はより線
同じく解釈 **第158条第1項** で、電線は次のいずれかとされています。
- より線
- 直径3.2mm（アルミ線は4mm）以下の単線

短い金属管に収める場合は例外です。

実務では、**直径3.2mmを超える太さは、より線（例：5.5mm²以上）を使う**と覚えるとよいです。

### 3. 管内で電線を接続しない
解釈 **第158条第1項** により、金属管内に電線の接続点を設けてはいけません。接続は、ボックス内で行います。

### 4. 電線の最小太さ
低圧配線の電線は、解釈 **第146条** で、直径1.6mm以上の軟銅線、またはこれと同等以上の強さと太さのものとされています。

### 5. 関連事項
- **接地**：金属管にはD種接地工事などが必要です（解釈 **第159条**）。ただし、条件によって省略できる場合もあります。
- **1回路の電線は同一管に入れる**：交流回路で電線を別々の管に分けると、電磁的不平衡で管が発熱するおそれがあります。
- **管内の電線の占積率**：管の内断面積に対する電線の占有率の目安は、民間規程の**内線規程（JEAC 8001）**に示されています。条番号は版によって異なるので、お手元の版で確認してください。
- **ケーブルを金属管に入れる場合**：これは主に防護目的の施工です。解釈第158条の「絶縁電線」の話とは別に、使用場所に応じた条文を確認してください。

## 現場でのポイント
1. 電線は**IVが基本**です。太さは負荷の電流と、電線の許容電流（内線規程などの表）で決めます。
2. **太いものはより線**にします。引き入れも楽になります。
3. 管内の電線の本数が多いと、**許容電流の低減**が必要です。
4. 電線には**PSEマーク**があるか確認します（電気用品安全法）。

不明点があれば、先輩や有資格者に確認してください。なお、第二種電気工事士の資格がないと、**電気工事士法上、電気工事そのものを行えません**（補助作業のみ可）。この点は資格のない方は特に注意してください。

# 電灯配線と電話線・LANケーブルを近くに通すときの注意点

## 1. 基本的な考え方（法令）

**電気設備技術基準（電技）第62条**
配線は、他の配線や弱電流電線等と接近・交差する場合、混触による感電や火災のおそれがないように施設しなければなりません。

**電気設備技術基準の解釈（電技解釈）第167条**
低圧屋内配線が弱電流電線等（電話線、LANケーブル、インターホン線など）と接近・交差する場合の具体的な方法を定めています。概要は次のとおりです。

- **がいし引き工事の場合**
  - 離隔距離を10cm以上とする（裸電線なら30cm以上）。
  - または、300V以下の場合に限り、絶縁性の隔離物を設ける、もしくは十分な長さの難燃性・耐水性のある堅ろうな絶縁管に収める。
- **合成樹脂管・金属管・ケーブル等の工事の場合**
  - 弱電流電線等と**接触しないように**施設する。

※条文の細部は改正されることがあるため、最新の電技解釈で確認してください。

## 2. 現場での実務ポイント

1. **接触させない**
   VVFケーブルと電話線・LANケーブルを一緒に束ねたり、同じステープルで留めたりしないでください。被覆が傷んだとき、混触して弱電側に電圧がかかるおそれがあります。
2. **同じ管・ボックス・ダクトに入れない**
   電灯の配線管に弱電線を一緒に通すのは避けます。ダクトやラック内では隔壁（セパレータ）で仕切ります。詳細は内線規程にも記載があります。
3. **離隔をとる**
   法令上は「接触しない」が最低ラインです。実務では、ノイズ対策のため数cm〜30cm程度離すのが一般的です。並行して長く走らせるのは避け、交差するときは直角に交差させます。
4. **ノイズ対策**
   LEDの電源、インバータ、調光器、蛍光灯の安定器などは、LANの通信品質を落とすことがあります。シールド付きケーブルを使うか、離隔を大きくとってください。
5. **ボックス内・分電盤まわり**
   弱電線を強電のボックスに引き込む場合は、仕切りを設けるか、ボックスを別にします。
6. **識別**
   後の工事や点検で誤認しないよう、ケーブルの種類が分かるようにしておきます。

## 3. 資格に関する注意

# ケーブルが壁を貫通する部分の施工

## 基本の考え方
貫通部で守るべきことは次の4つです。

1. ケーブルの被覆を傷つけない
2. 金属部分と電気的に接触させない
3. 火や煙を通さない（防火区画の場合）
4. 水を入れない（外壁の場合）

壁の種類によってやるべきことが変わります。

## 1. 一般の壁（木造・石膏ボードなど）
- 開口部のバリや角を処理し、必要に応じてブッシングや保護管（合成樹脂管・金属管）を使ってケーブルを保護します。
- ケーブルを無理に曲げたり、壁の中でねじったり、引きずって被覆を傷つけたりしないようにします。
- ケーブルを造営材（壁・梁など）に沿わせる場合は、支持点間を2m以下にして固定します。
- 根拠：電気設備技術基準の解釈（電技解釈）**第164条**（ケーブル工事）、電気設備技術基準 **第56条**（配線の感電・火災の防止）

## 2. メタルラス・金属板張りの壁
- 木造のモルタル壁などにはメタルラスが入っています。ケーブルをそのまま通すとラスに触れて漏電や火災の原因になります。
- **ラスと電気的に絶縁**するため、合成樹脂管などの絶縁性のある管にケーブルを通し、ラスに触れないようにします。
- 根拠：電技解釈 **第145条**（メタルラス張り等の木造造営物における施設）

## 3. 防火区画・耐火構造の壁や床
- 貫通部の隙間は、**不燃材料（モルタルなど）で埋める**か、国土交通大臣認定を受けた防火区画貫通処理工法（耐火パテ、防火措置材など）で施工します。
- 認定工法は、メーカーが指定するケーブル種類・太さ・本数・施工方法に従う必要があります。
- 根拠：建築基準法施行令 **第112条第20項**（防火区画を貫通する配管等）
- 条項は改正で変わることがあります。現場では設計図書や特記仕様書も確認してください。

## 4. 外壁の貫通（屋外↔屋内）
- 雨水が壁内に入らないように、防水ブッシングや防水カバーを使い、貫通部にコーキングなどの防水処理をします。
- 屋外側にケーブルを垂らす「ドリップループ（水切り）」を作り、伝った水が貫通部に入らないようにします。
- 屋外側は立ち上がり（スリーブ）を付けるなどして、水が入りにくい形にします。
- 根拠：電気設備技術基準 **第56条**、電技解釈 **第164条**ほか

## 5. その他の注意点
- **水道管・ガス管・通信線との離隔**
  - 壁内でも、他の管や弱電流電線に接触しないようにします。
  - 根拠：電技解釈 **第167条**（低圧配線と弱電流電線等又は管との接近又は交差）
- **金属管で貫通する場合**
  - 交流回路では、同一回路の電線（行き・帰り）を同じ管に通します。
  - 管の端口にはブッシングを付けて被覆を保護します。
- **電線管などで貫通する場合**
  - 貫通部の仕上げ（雨仕舞い、防火措置）も忘れないでください。

## 資格との関係（電気工事士法）
- 壁を貫通するケーブル配線は電気工事に当たります。**資格がない場合は補助作業のみ**で、電線を造営材に取り付けたり接続したりする作業はできません（電気工事士法 **第3条**）。
- 第二種電気工事士は、一般用電気工作物（600V以下で受電するもの）などの工事に従事できます。

# 結論

**原則としてできません。** 自家用電気工作物の電気工事の作業は、第一種電気工事士（または特殊電気工事の資格者など）の仕事です。第二種電気工事士の範囲は、原則として一般用電気工作物（住宅、小規模店舗など）です。ただし、**例外が3つ**あります。

---

## 1. 根拠

**電気工事士法 第3条**

| 項 | 内容 |
|---|---|
| 第1項 | 第一種電気工事士でなければ、自家用電気工作物（500kW未満の需要設備）の電気工事の作業に従事できない。ただし、保安上支障のない軽微な作業は除く |
| 第2項 | 一般用電気工作物の電気工事は、第一種または第二種電気工事士でなければ従事できない |
| 第3項 | ネオン工事・非常用予備発電装置工事は、特種電気工事資格者などでなければ従事できない |
| 第4項 | 簡易電気工事（後述）は、第一種電気工事士または認定電気工事従事者でも従事できる |

- 自家用電気工作物のうち、第一種の対象となるのは**最大電力500kW未満の需要設備**です（電気工事士法施行規則 第2条の2）。500kW以上の需要設備や、発電所・変電所・送配電線路は、電気工事士法の資格の対象外です。
- 「従事してはならない」とあるため、**第一種の人が現場で監督していても、第二種の人が自家用の工事作業をしてよいことにはなりません。**
- 違反すると、作業した本人と、させた事業者の双方が罰則の対象になり得ます（同法 第14条など）。

---

## 2. 例外

### ① 軽微な作業（法第3条第1項ただし書、施行規則 第2条第2項）
無資格者でも可能な作業です。たとえば次のようなものがあります。
- 600V以下の電気機器の端子へ、電線（コード、キャブタイヤケーブル、ケーブルを除く）をねじ止めする作業
- 電線管の曲げ・切断・ねじ切り
- 金属製ボックスを造営材に固定する作業
- 配電盤を造営材に取り付ける作業
- 電線を支持する柱・腕木の設置・変更　など

これらは「配線そのものの工事」ではなく、あくまで補助的・軽微な作業です。細かい列挙は施行規則を直接確認してください。

### ② 簡易電気工事（法第3条第4項）
**第二種電気工事士が「認定電気工事従事者認定証」を取得すれば**、**600V以下で使用する自家用電気工作物（電線路を除く）**の電気工事（簡易電気工事）ができます。認定は、免状取得後の実務経験3年以上、または認定講習の修了などが要件です。
→ 工場の**低圧（200V/400V）配線工事**は、これでできる場合があります。**高圧部分（キュービクル内の高圧側など）は対象外**です。

### ③ 工場でも「一般用電気工作物」の場合
低圧（600V以下）で受電し、構内に一定規模以上の発電設備などがない小規模な工場は、**一般用電気工作物**にあたる場合があります（電気事業法 第38条第1項、同法施行規則 第48条）。この場合は第二種で施工できます。
ただし、火薬類製造所など、爆発・引火のおそれが特に大きい場所は除外されます。工場が一般用か自家用かは、**受電方式と設備構成**で判断してください。

2. 工事内容は**低圧側のみか**（簡易電気工事の範囲か）
3. 自分は**認定電気工事従事者認定証**を持っているか
4. 迷ったら、**第一種電気工事士の資格者**か、**電気主任技術者**に確認する

# 検電器の使い方

検電器は「電気が来ているか」を確認する道具です。**無反応でも停電とは限らない**ので、補助的に使い、最終判断は手順全体で行います。

## 1. 法的な位置づけ

- **労働安全衛生規則 第339条第1項**：電路を開路して作業するときは、次の措置が必要です。
  - 開閉器に施錠し、通電禁止の表示をするか、監視人を置く（第1号）。
  - 高圧・特別高圧の電路は、**検電器具で停電を確認**し、**短絡接地器具で確実に短絡接地**する（第2号）。
- 低圧では検電器具の使用は条文上の明文義務ではありません。ただし、停電作業の基本として実務上は必ず行います。多くの会社も社内規程で義務化しています。
- **労働安全衛生規則 第36条第4号**（特別教育）：高圧・特別高圧の充電電路の点検や、低圧の充電電路の敷設・修理などの業務には、**特別教育の修了**が必要です。
- **電気工事士法 第3条**：電気工事は資格が必要で、第二種は一般用電気工作物（低圧）の工事が対象です。無資格者は、軽微な工事（同法施行規則第2条）以外は作業できません。
- 高圧の検電は、有資格者や電気主任技術者の指示・監督のもとで行います。**無資格者が単独で行ってはいけません**。

## 2. 種類と選び方

| 種類 | 特徴 |
|---|---|
| 低圧用（検電ペン型・非接触式、ネオン式など） | 屋内配線、分電盤、コンセント |
| 高圧用（風車式、発光式、音響式） | 受電設備、高圧ケーブル |

- **使用電圧に合ったもの**を使います。低圧用を高圧に使うのは厳禁です。
- 交流用か直流用かも確認します。交流用の非接触式は直流を検知できません。

## 3. 基本手順（確認→検電→確認）

1. **使用前点検**
   - 外観（割れ、汚れ、破損）、電池、ブザーやランプの作動を確認します。
   - 校正や点検の期限も確認します。
2. **動作確認（使用前）**
   - 既知の充電部や、検電器チェッカー（テスト用発生器）で正常に反応することを確認します。
3. **検電**
   - 作業する**すべての電線・端子（各相、各極）**に当てます。
   - 低圧の場合は、対地間と線間（電線相互間）の両方を意識します。
   - 高圧の場合は、絶縁手袋などの保護具を着用し、**電圧に応じた絶縁性能のある操作棒**で行います（安衛則第341条、第342条の考え方）。
4. **動作確認（使用後）**
   - 再度、既知の充電部で反応を確認します。検電中に電池切れや故障がなかったことを証明するためです。
5. **記録・表示**
   - 開閉器に施錠し、「作業中・投入禁止」を表示します（安衛則第339条第1項第1号）。
   - 高圧では短絡接地を行います。

## 4. 失敗しやすい注意点

- **無反応＝停電ではありません**。検電器の故障や電池切れ、電線の被覆の状態、シールド線、検出感度の限界などが原因のことがあります。
  - 非接触式は、電線から離れすぎていたり、ケーブルの種類によっては反応しないことがあります。
  - 逆に、近くの充電線の影響（誘導）で反応することもあります。
- **非接触式だけに頼らない**：確実にしたいときは、**テスター（回路計）**で電圧ゼロを確認します。
- 単相100Vの接地側（白線）は、通常は反応しません。ただし、**中性線の断線**などがあると、接地側でも電圧が出ることがあります。線間の電圧も確認してください。
- **ブレーカーを切った＝停電ではありません**。逆送電、他回路からの渡り配線、共用の中性線、蓄電池や太陽光発電、コンデンサの残留電荷などに注意します。
- 検電器は、感電防止の保護具や安全手順の**代わりにはなりません**。絶縁手袋、保護メガネなど、現場のルールに従ってください。

## 5. 若手へのポイント

- 資格のない人は、検電の補助や見学にとどめ、**必ず指導者と一緒に**行いましょう。
- 第二種電気工事士の範囲（低圧、一般用電気工作物）を超える高圧の検電は、自分で判断せず上司に任せます。
- 作業手順書や社内ルールを優先してください。**必ず現場の責任者に確認**を。

## まとめ

検電は、「点検、動作確認、検電、再確認、施錠・表示（高圧は短絡接地も）」の流れで行い、反応がなくても最後はテスターなどで確認します。

# ねじなし電線管とは

## 概要
**ねじなし電線管**は、電線を保護する金属製の配管（金属管）の一種です。管の端にねじ山を切らず、専用のねじなし用付属品で接続します。

- 規格：**JIS C 8305（鋼製電線管）**
- 記号：**E管**（呼び方は E19、E25、E31 など。数字は管の外径に近い寸法で、単位はmm）
- 仲間：厚鋼電線管（G管）、薄鋼電線管（C管）は、どちらも管端にねじを切って接続します。

## 薄鋼電線管（C管）との違い

| | ねじなし電線管（E管） | 薄鋼電線管（C管） |
|---|---|---|
| 接続方法 | 止めねじを締め付ける | 管端にねじを切って接続 |
| 肉厚 | さらに薄い | 薄い（厚鋼よりは薄い） |
| 加工 | 切断してバリを取るだけ | ねじ切り作業が必要 |
| 特徴 | 施工が早く、軽い | ねじ切り機が必要 |

## 接続部品（ねじなし用）
- **ねじなしカップリング**：管と管をつなぐ
- **ねじなしコネクタ**：管とボックスをつなぐ
- **ブッシング**：管端で電線の被覆を傷つけないようにする

締め付けねじは、**頭部がねじ切れるまで締めるタイプ**が一般的です。ねじ切れることで締め付けが十分だったと確認でき、接続の緩みも防げます。

## 施工の基本手順
1. **切断**：パイプカッタや金切りのこで管軸に直角に切る
2. **面取り（リーマ掛け）**：切断面のバリを必ず取る。電線の被覆を傷つけないために重要
3. **曲げ**：ベンダを使う。曲げ半径は管内径の6倍以上
4. **接続**：管を付属品の奥まで確実に差し込み、止めねじを締める

## 根拠となる法令・基準

### 電気設備技術基準の解釈（電技解釈）第159条「金属管工事」
ねじなし電線管にもこの条文が適用されます。主な内容は次のとおりです。
- 電線は**絶縁電線（屋外用ビニル絶縁電線を除く）**とする
- **より線**を使う。ただし短小な管では、銅線10mm²以下、アルミ線16mm²以下なら単線も可
- **管内では電線を接続しない**
- 管の厚さは、コンクリートに埋め込む場合は**1.2mm以上**とする
- 管相互、および管とボックスは、堅ろうかつ電気的に完全に接続する
- 管の端口は、電線の被覆を損傷しない構造とする
- 湿気の多い場所では、防湿装置を施す
- 金属管には**接地工事**を行う（省略できる条件もあり）

### 電気設備技術基準（省令）第56条
低圧配線に求められる絶縁性能の根拠です。電技解釈は、この性能を満たす具体的な方法を示したものです。

### 内線規程（JEAC 8001）3110節「金属管工事」
法令ではなく民間規程ですが、実務ではほぼ必ず参照します。電線の本数と管サイズの選び方（電線の被覆を含む断面積の総和が、管内断面積の**48%以下**）なども載っています。

## 現場での注意点
- **バリ取りを怠ると、電線を引くときに被覆を傷つけて地絡や短絡の原因になります。**
- 止めねじは**ねじ切れるまで**確実に締める。緩むと接地の連続性が損なわれます。
- 屋外や湿気の多い場所では、**防水形の付属品**を使う。
- 管とボックスの接続部では、**接地の連続性**を確認する。

## 資格との関係
金属管工事は、**第二種電気工事士**の範囲（一般用電気工作物の600V以下の工事）に含まれます（電気工事士法第3条）。資格がない場合は、有資格者の指示・監督のもとで補助作業を行う形になります。
