# 金属管の中で電線を接続してはいけません

## 根拠
**電気設備技術基準の解釈 第159条（金属管工事）第1項**で、低圧屋内配線の金属管工事では「金属管内では、電線に接続点を設けないこと」と定められています。この解釈は、電気設備に関する技術基準を定める省令（第56条、第57条など）の電線接続・配線の安全要求を満たす具体的な方法を示したものです。

号の番号は改正で変わることがあるため、現場で引用する場合は最新版の条文で確認してください。

## 禁止の理由
- **点検・確認ができない**：管内の接続部は目視できず、接触不良や絶縁不良を見つけられません。
- **発熱・火災の危険**：接続部が接触不良を起こして発熱しても気づけません。
- **接続部が傷みやすい**：接続部は太くなり、被覆も不均一になりがちです。電線を引き入れたり引き替えたりするときに、管内で引っかかって電線が損傷したり、接続部が外れたりします。
- **電線の入れ替えが困難になる**：後日の配線変更や更新の際に支障が出ます。

## 接続が必要なときは
接続は、**アウトレットボックス、プルボックス、ジョイントボックスなどのボックス内**で行います。電線の接続そのものは、解釈第12条の次の要件を満たす必要があります。
- 電気抵抗を増加させない
- 引張強さを20%以上減少させない
- 接続部分の絶縁電線の絶縁物と同等以上の絶縁効力のあるもので十分被覆する（接続器を使う場合を除く）

## 補足
- 合成樹脂管工事（第158条）や金属可とう電線管工事（第160条）など、他の管工事でも管内に接続点を設けないのが原則です。
- 第二種電気工事士の技能試験でも、管内接続は欠陥（施工不良）として扱われます。
- 一般用電気工作物の工事は、軽微な工事を除いて**電気工事士法第3条**により有資格者でなければ従事できません。資格のない方は、有資格者の指示・監督のもとで補助作業の範囲にとどめてください。

# 金属管に入れる電線

## 結論
**絶縁電線（屋外用ビニル絶縁電線を除く）** を使います。現場では、**IV線（600Vビニル絶縁電線）** が最も一般的です。

## 根拠
**電気設備技術基準の解釈 第159条（金属管工事）第1項**

| 号 | 内容 |
|---|---|
| 第一号 | 電線は**絶縁電線**であること（**屋外用ビニル絶縁電線＝OW線は不可**） |
| 第二号 | 電線は**より線**、または**直径3.2mm以下の単線**（アルミ線は4mm以下）であること。ただし**短小な金属管**に収めるものは除く |
| 第三号 | **金属管内では電線に接続点を設けない** |

※条文の項・号は改正されることがあるので、実務では最新版を確認してください。

## 実務上のポイント

**1. 使える電線の例**
- IV、HIV（耐熱用）、EM-IE（エコ電線）などの絶縁電線
- ケーブルを金属管に通すことも可能ですが、通常は絶縁電線を引き入れます。

**2. 使えない電線の例**
- OW（屋外用ビニル絶縁電線）。解釈で明確に除外されています。
- DV（引込用ビニル絶縁電線）も、本来は引込線用なので管内配線には使いません。

**3. 太さの考え方（第二号）**
- 単線は3.2mm（約8mm²）までです。
- これより太い電線は**より線**を使います。
- 理由は、管内への引き入れや曲がり部分での作業性を確保するためです。

**4. 管内で接続しない（第三号）**
- 接続はプルボックスやジョイントボックス内で行います。
- 管内で接続すると、点検や交換ができず、事故の原因になります。

**5. 管に入れる本数の目安**
- 電線の総断面積（絶縁被覆を含む）が、管の内断面積の**約32％以下**（同じ太さの電線なら約48％以下）が目安です。
- これは**内線規程**（民間規程、日本電気協会）の金属管工事の節にあり、法令ではありません。ただし実務の標準です。

**6. 関連する注意**
- 交流回路では、**同じ回路の電線は全部同じ管に収める**のが原則です（片方だけ通すと、管が過熱することがあります）。これも内線規程の内容です。
- 金属管自体の**接地工事**の要否は、解釈第159条の別項で定められています。使用電圧や管の長さ、場所の条件によって省略できる場合があります。

## まとめ
- 迷ったら **IV線（より線、または3.2mm以下の単線）** を使います。
- **OW線は使いません。**
- **管内では接続しません。**

# 電灯配線と電話線・LANケーブルを近くに通すときの注意点

## 1. 基本の考え方（法令）
- **電気設備技術基準 第62条**：配線は、他の配線や弱電流電線等と接近・交差する場合、**混触による感電や火災のおそれがないように**施設しなければなりません。
- **電気設備技術基準の解釈 第167条**（低圧配線と弱電流電線等の接近・交差）：具体的な施工方法が示されています。私の記憶では、次のいずれかが基本です。
  - 電灯線と弱電流電線を**離隔**して、接触しないようにする
  - 間に**隔壁**を設ける
  - どちらかを**絶縁管などに収める**（離隔と同等の保護）

  ※ 離隔距離の数値や条件は、配線方法（ケーブル、管、がいし引きなど）で変わります。必ず最新の解釈の条文、または内線規程で確認してください。

## 2. 実務での注意点
1. **同じ配管・ダクト・ボックスに混在させない**
   - 電灯線（100V/200V）と通信線は、原則として**同一の管やボックスに入れません**。
   - 同じボックスに入れる必要がある場合は、**隔壁（セパレータ）**で完全に仕切ります。
2. **接触させない**
   - LANケーブルや電話線は、電灯線に使うVVFなどの**電圧に耐える絶縁を前提にしていません**。
   - 被覆が傷つくと、**電灯線が通信機器に混触して感電や機器の焼損**を起こすおそれがあります。
   - 結束バンドで一緒に束ねるのは避けましょう。
3. **交差は直角に**
   - 平行して長く並走させると、誘導ノイズでLANの速度低下や通信エラーが起きやすくなります。
   - どうしても交差する場合は**直角に交差**させます。
4. **離隔を確保する**
   - 法令上の最低限に加えて、ノイズ対策としても**できるだけ離す**のが実務の基本です。
   - LAN配線の規格では、電力線との推奨離隔が示されています。メーカーや設計仕様を確認してください。
5. **壁内・天井内の施工**
   - 器具の取付け穴やジョイントボックス付近で近づきやすいので注意します。
   - ケーブルラックでは**別の段に分ける**か、仕切りを設けます。
6. **ケーブルの被覆を傷つけない**
   - 電灯線も通信線も、金属端部やステープルで傷を付けないようにします。
   - 貫通部には保護材（ブッシングなど）を使います。

# 結論

**原則としてできません。** 工場の受電設備や構内配線など、自家用電気工作物の電気工事は、第二種電気工事士の免状だけでは従事できません。

## 根拠

| 区分 | 必要な資格 | 根拠 |
|---|---|---|
| 一般用電気工作物の工事 | 第一種または第二種電気工事士 | 電気工事士法 第3条第2項 |
| 自家用電気工作物（最大電力500kW未満の需要設備）の工事 | 第一種電気工事士 | 同法 第3条第1項 |
| 自家用のうち**簡易電気工事**（600V以下で使用する設備、電線路を除く） | 第一種電気工事士、または**認定電気工事従事者** | 同法 第3条第4項、同法施行規則 第2条 |
| 自家用のうち**特殊電気工事**（ネオン工事、非常用予備発電装置工事） | 特種電気工事資格者 | 同法 第3条第3項 |

第二種電気工事士は、自家用電気工作物の工事について、上表の第一種電気工事士の欄に含まれていません。そのため、工場の配線工事は原則として担当できません。

## 例外：資格がなくてもできる「軽微な作業」

自家用電気工作物でも、保安上支障がないとして、資格を必要としない軽微な作業があります（電気工事士法 第3条第1項かっこ書き、同法施行規則 第2条第1項）。例としては次のようなものです。

- 電圧600V以下で使用する電気機器や配線器具に接続する、接続線の接続作業の一部
- 露出型点滅器や露出型コンセントの取り換え
- 電線を支持する柱や腕木などの設置・変更に関する作業

ただし、これは第二種の免状の効力ではなく、**無資格者でもできる作業**です。具体的な範囲は施行規則第2条の条文で必ず確認してください。

## 実務上の注意点

1. **工場内でも一般用電気工作物の部分は第二種で可能です。** 一般用電気工作物に該当する設備、たとえば低圧受電で、かつ発電設備などの条件を満たす小規模な事務所・店舗部分であれば、第二種で施工できます。ただし、工場構内で受電設備と一体の設備は、通常は自家用電気工作物になります。区分の判断は電気事業法施行規則 第48条（一般用電気工作物の範囲）に基づきます。
2. **無資格または資格不足で従事すると罰則があります。** 電気工事士法 第3条違反は、同法 第14条により、3月以下の懲役または3万円以下の罰金です。
3. **「補助者」としての作業は可能です。** 有資格者（第一種など）の指揮のもとで補助的な作業をする場合でも、電気工事士でなければできない作業を自分で行うことはできません。現場の運用は会社の保安管理や有資格者に確認してください。

## 自家用の工事を担当できるようになるには

- **第一種電気工事士**：試験に合格し、免状の交付に必要な実務経験（原則3年）を満たす必要があります（電気工事士法 第4条第3項）。第二種を持っていなくても受験できます。
- **認定電気工事従事者**：第二種電気工事士の免状を取得後、実務経験（3年以上）などの要件を満たして認定講習を受ければ、**600V以下の簡易電気工事**に従事できます（同法 第3条第4項、同法施行規則 第2条の3）。

工場で働くのであれば、まず第一種電気工事士の取得を目指すのがおすすめです。

# 検電器の使い方

検電器は、**電気が来ていないこと（停電）を確認する器具**です。「ブレーカーを切ったから大丈夫」と思い込まず、必ず検電して確認します。

## 1. 根拠になる法令
- **労働安全衛生規則 第339条（停電作業を行う場合の措置）**
  - 電路を開路したら、開閉器に施錠し、通電禁止の表示をするか監視人を置く。
  - 残留電荷を放電させる。
  - **検電器具で停電を確認する**。
  - 高圧・特別高圧では、さらに**短絡接地器具で確実に短絡接地**する。
- **労働安全衛生規則 第36条第4号・第5号**：充電電路や、それに近接する場所での作業には**特別教育**が必要です。資格がなくても、この教育を受けていない人は作業できません。
- **電気工事士法 第3条**：電気工事は資格者が行います。第二種電気工事士は600V以下の一般用電気工作物が対象で、**高圧設備の工事はできません**。

## 2. 検電器の種類（電圧に合ったものを選ぶ）
- **低圧用**：ペン型や音・光で知らせるタイプ。
- **高圧用**：伸縮式の絶縁棒つきで、音・光で知らせるタイプ。
- 低圧用で高圧は検電できませんし、危険です。**必ず対象の電圧に適合した製品**を使います。

## 3. 使用前点検
- 外観に割れ、汚れ、破損がない。
- 電池が入っていて、動作確認（テストボタンなど）で音・光が出る。
- 高圧用は、絶縁性能の定期点検の期限が切れていない。
- 異常があれば使わず、交換や修理に出します。

## 4. 基本手順（前後確認が大切）
1. **保護具を着ける**（絶縁手袋、保護メガネ、ヘルメットなど。高圧は高圧用の絶縁保護具）。
2. **検電器が正常に動くか確認する**。活線（電気が来ている所）か、チェッカー・テスト機能で確認します。
3. **対象を検電する**。
   - 先端を導体の金属露出部に当てるか近づけます。
   - **全相（R・S・T、単相なら両線）を1本ずつ**確認します。
   - 作業する箇所のできるだけ近くで確認します。
4. **「反応なし」＝停電と判断する**。
5. **もう一度、検電器が正常に動くか確認する**。これは、検電中に電池切れや故障で反応しなかった可能性を排除するためです。
6. 高圧以上では、**検電後に短絡接地**をしてから作業に入ります。

## 5. 注意点
- **反応しない＝安全とは限りません。** 電池切れ、感度不足、接触不良、非接触型の限界などがあるため、前後の動作確認が必須です。
- **誤表示に注意**：
  - 隣の充電線からの誘導で、停電していても反応することがあります。
  - 長いケーブルや浮いている線では、静電誘導で反応することがあります。
  - 被覆の上から検知するタイプは、被覆の厚さやシールドで感度が変わります。
- **検電は施錠・表示とセット**です。他人が誤って投入しないようにします。
- 不明なときは必ず**先輩や責任者に確認**します。

## まとめ
**「動作確認 → 検電（全相）→ 動作確認」** が基本で、高圧は **「検電 → 短絡接地」** まで行います。

検電器の型式ごとの細かい操作は、取扱説明書や会社の作業手順書も確認してください。

# ねじなし電線管とは

## 概要
**ねじなし電線管（E管）** は、電線を保護するための**金属製の電線管**です。管の端部にねじを切らず、専用の附属品で接続します。規格は **JIS C 8305（鋼製電線管）** で、同じ金属管でも次の3種類があります。

| 種類 | 記号 | 特徴 |
|---|---|---|
| 厚鋼電線管 | G管 | 肉厚。ねじ切りして接続 |
| 薄鋼電線管 | C管 | 薄肉。ねじ切りして接続 |
| **ねじなし電線管** | **E管** | **薄肉でねじがない。止めねじ式で接続** |

呼び方は E19、E25、E31 のように、「E＋管の呼び（外径に近い数字）」で表します。

## 接続の仕組み
ねじ切りの代わりに、**ねじなしカップリング**や**ねじなしボックスコネクタ**を使います。

- 管を差し込み、**止めねじの頭がねじ切れるまで**締め付けます。
- 頭がねじ切れることで、規定のトルクで固定できたことが分かります。

## 施工の基本手順
1. **切断**：パイプカッタや金切りのこで切ります。
2. **面取り**：**リーマ**で管端の内側のバリを必ず除去します。電線の被覆を傷つけないためです。
3. **曲げ**：パイプベンダを使い、電線の引き入れに支障のない曲げ半径にします。
4. **接続**：ねじなしカップリングやコネクタで固定します。
5. **ボックス接続部**：ボックスコネクタとロックナットで固定し、管端には**絶縁ブッシング**を付けます。
6. **接地**：金属管には接地工事が必要です（後述）。

## 関連する法令・基準

### 電気設備技術基準の解釈（経済産業省）
- **第158条（金属管工事）**：主な要件は次のとおりです。
  - 使用電線は絶縁電線（屋外用ビニル絶縁電線を除く）で、より線か、短い単線（銅は直径3.2mm以下）とする。

  - 管の厚さは、コンクリート埋込みの場合は**1.2mm以上**（それ以外は原則1mm以上）とする。
  - 管の端口や内面は、電線の被覆を傷めないよう滑らかにする。
  - 湿気や水気のある場所では、防湿装置を設けるなど水の浸入対策をする。
