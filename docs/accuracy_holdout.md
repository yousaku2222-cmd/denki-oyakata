# 金属管の中で電線を接続してもよいか

**結論：接続してはいけません。** 電線の接続は、必ずボックス（アウトレットボックス、プルボックス、ジョイントボックスなど）の中で行います。

## 根拠

- **電気設備技術基準の解釈 第159条（金属管工事）第1項**
  「金属管の内部では、電線に接続点を設けないこと」と定められています。号数は改正で変わることがあるので、最新版で確認してください。
- **電気設備技術基準（省令）第7条（電線の接続法）**、**解釈 第12条（電線の接続法）**
  接続部で電気抵抗を増やさないこと、絶縁性能を落とさないこと、断線のおそれがないことを求めています。
- 合成樹脂管工事（解釈 第158条）や金属可とう電線管工事（解釈 第160条）でも、管内に接続点を設けてはいけません。

## 管内接続がだめな理由

1. **点検できない**：接続部の緩み、過熱、絶縁劣化を目視で確認できません。
2. **電線の入れ替え・引き直しができない**：接続部が管内で引っかかり、断線や被覆損傷の原因になります。
3. **接続部に張力がかかる**：電線を引っ張る力や熱による伸縮で、接続が外れたり接触不良になったりします。
4. **放熱が悪い**：接触不良で発熱しても熱がこもり、火災につながるおそれがあります。

## 実際の施工

- 接続が必要な箇所には、ボックスを設けます。
- ボックス内では、リングスリーブ、差込形コネクタ、ねじ込み形コネクタなどで接続し、必要な絶縁処理をします。
- 電線は、管内で接続が不要な長さで通線します。

## 資格に関する注意

電線の接続作業は電気工事にあたり、**電気工事士法 第3条**により、第二種電気工事士などの資格が必要です。資格のない方は、有資格者の指示のもとでの補助作業にとどまります。接続そのものは行えません。

# 金属管に入れる電線

## 結論
**絶縁電線（IV、HIV、EM-IEなど）を使います。**ただし次の条件があります。

| 条件 | 内容 |
|---|---|
| 電線の種類 | 絶縁電線（**屋外用ビニル絶縁電線 OW は不可**） |
| 太さ・形状 | **より線**、または**直径3.2mm以下の単線**（アルミ線は4mm以下） |
| 接続点 | **管の中では電線を接続しない** |

## 根拠
**電気設備技術基準の解釈 第159条（金属管工事）第1項**
- 一号：絶縁電線（屋外用ビニル絶縁電線を除く）であること
- 二号：より線または直径3.2mm（アルミ線は4mm）以下の単線であること。ただし短小な金属管に収める場合は除く
- 三号：金属管内では電線に接続点を設けないこと

あわせて、電気設備技術基準（省令）第57条により、配線の電線は感電や火災のおそれがないように施設する必要があります。

## 現場での補足

**1. 電線の選び方**
- 一般的には 600Vビニル絶縁電線（IV）が使われます。
- 耐熱性や環境配慮が必要なら、HIVやEM-IE（エコ電線）も使います。
- 単線は直径3.2mm（断面積では約8mm²）までです。それより太い場合は、より線を使います。
- DV線（引込用ビニル絶縁電線）は、屋内配線の金属管には使いません。

**2. 管内の接続禁止の理由**
接続部は点検も増し締めもできません。接触不良による発熱で火災になるおそれがあるため、接続は必ずプルボックスやジョイントボックス内で行います。

**3. 本数の目安**
管に入れる電線の本数や太さは、内線規程（3110節）の電線管の太さの選定表で確認します。一般に、電線の被覆を含む断面積の総和が、管の内断面積の**32％以下**になるように選びます。

**4. 同一回路の電線は同じ管に入れる**
交流回路では、1回路の電線をすべて同一管に収めます。往路と復路を別々の金属管に通すと、電磁的不平衡で管が発熱します。

**5. ケーブルを入れる場合**
金属管にケーブルを通すこともできます。この場合、金属管は保護管の扱いになります。

**6. 製品の確認**
電線は電気用品安全法の適合品（PSEマーク付き）を使います。

## 資格との関係

# 電灯配線と電話線・LANケーブルを近づけるときの注意点

## 1. 安全面（感電・火災の防止）

**根拠：**
- 電気設備技術基準（省令）第62条：配線は、他の配線や弱電流電線等と接近・交差する場合、混触による感電や火災のおそれがないように施設すること。
- 電気設備技術基準の解釈（電技解釈）第167条：低圧配線と弱電流電線等（電話線、LANケーブル、インターホン線など）が接近・交差する場合の施設方法。

**実務上のポイント：**
- 電灯線と弱電線は接触させない。混触すると、弱電機器の破損のほか、弱電線側に電圧がかかって感電や火災につながるおそれがあります。
- 接近・交差する場所では、次のいずれかで対処します。
  - 十分な離隔をとる。
  - 間に絶縁性のある隔離物（合成樹脂製の仕切り板など）を入れる。
  - どちらかを、絶縁性・耐火性のある管やダクトに収める。
- 工事方法ごとに細かい条件が異なります（がいし引き、ケーブル工事、管工事など）。最新の条文で確認してください。

## 2. 同一の管・ダクト・ボックスに入れない

- 電灯線（強電）と電話線・LANケーブル（弱電）は、原則として同じ電線管やダクトに一緒に入れません。
- 同じボックスを使う場合は、隔壁（セパレータ）で仕切ります。
- 実務ではこの考え方が基本です。詳細は電技解釈第167条や内線規程（日本電気技術規格委員会 JESC E0005）で確認してください。

## 3. ノイズ対策（通信品質の確保）

法令の話ではありませんが、実務では重要です。

- 電灯線と並行して長く敷くと、誘導ノイズでLANの速度低下や通信エラーが起きることがあります。
- 並行区間をできるだけ短くし、離隔をとります。
- 交差するときは直角に交差させます。
- 分電盤、蛍光灯の安定器、インバータ機器のそばは避けます。
- 離隔の目安は、構内情報配線の規格（JIS X 5150 など）やケーブルメーカーの施工資料に示されています。

## 4. 資格・工事区分に関する注意

- 電灯配線工事は、一般用電気工作物であれば電気工事士法の対象です。第二種電気工事士以上の資格が必要で、資格がなければ工事できません（電気工事士法第3条）。

# 検電器の使い方

## 1. 検電器とは
電路に電圧がかかっているかどうかを確認する道具です。停電作業では、**「切ったはず」を「切れている」と確認するために使います**。

| 種類 | 主な用途 | 例 |
|---|---|---|
| 低圧用 | 屋内配線、分電盤など（600V以下） | ペン型、検電ドライバ、非接触式 |
| 高圧用 | 受電設備、高圧ケーブルなど（6.6kVなど） | 風車式、音響・発光式（絶縁棒付き） |

**必ず対象の電圧に合った定格のものを使います。** 低圧用を高圧に使うのは厳禁です。

## 2. 基本の手順

**① 使用前点検**
- 外観（割れ、汚れ、絶縁部の傷）を確認する
- 電池残量を確認し、チェックボタンがあれば押して動作を確認する
- 定格電圧と使用範囲を確認する

**② 停電措置**
- 開閉器を切り、施錠するか通電禁止の表示をする（または監視人を置く）

**③ 検電器の動作確認（検電前）**
- 活線であることがわかっている電路や、専用の試験器で、正常に反応するか確認する

**④ 検電**
- 握りの絶縁部（つばより手前）を持つ。つばより先には触れない
- 先端を導体の露出部に確実に接触させる
- **すべての相・極について行う**（三相ならR-S-T、中性線や接地側も）
- 反応がない（音や光が出ない）ことを確認する

**⑤ 検電器の動作確認（検電後）**
- 再度、既知の活線などで正常に反応するか確認する。検電中に電池切れや故障が起きていないかを確かめるためです

**⑥ 作業開始**
- 高圧・特別高圧では、検電後に短絡接地を行う

この「確認→検電→確認」の流れは、現場で「活線→死線→活線確認」などと呼ばれる基本動作です。

## 3. 注意点（若手がやりがちなミス）
- **反応なし＝停電、とは限りません。** 電池切れ、接触不良、被覆の上から当てている、故障などが原因のことがあります。
- 非接触式（被覆越しに検知するタイプ）は補助的なものです。低圧では、最終的にテスターで電圧がないことを確認すると安心です。
- 高圧ケーブルやコンデンサには残留電荷があります。検電だけで安心せず、放電と接地を行います。
- 停電した電路でも、隣接する活線からの誘導電圧や、他の電源からの逆流（誤通電）の恐れがあります。
- 高圧では、絶縁手袋・絶縁靴・保護帽などの保護具を使い、検電器は絶縁棒付きのものを使います。
- 使用前に必ず点検し、汚れや湿気で絶

# ねじなし電線管（E管）とは

## 一言でいうと
**管の端にねじを切らず、止めねじ（締付けねじ）で接続する金属製の電線管**です。管の呼び方に「E」が付くので**E管**とも呼ばれます（E19、E25、E31…）。規格は **JIS C 8305（鋼製電線管）** に定められています。

## 金属管の種類と比較
| 種類 | 記号 | 特徴 |
|---|---|---|
| 厚鋼電線管 | G管 | 肉厚で丈夫。管端にねじを切って接続 |
| 薄鋼電線管 | C管 | 薄くて軽い。管端にねじを切って接続 |
| **ねじなし電線管** | **E管** | **薄肉でねじ切り不要。止めねじで接続** |

ねじ切りの手間がないので、現場では特に屋内の露出配管や隠ぺい配管でよく使われます。

## 接続に使う主な部材
- **ねじなしカップリング**：管と管をつなぐ
- **ねじなしボックスコネクタ**：管とボックスをつなぐ
- **ブッシング**：管端で電線の被覆を傷つけないための保護材
- **サドル**：管を壁や天井に固定する

## 施工のポイント
1. **切断**：パイプカッタや金切りのこを使う
2. **リーマ掛け**：切断面のバリを必ず取る（電線の被覆を傷つけないため）
3. **曲げ**：パイプベンダを使い、管が潰れないよう曲げる。曲げ半径は一般に**管内径の6倍以上**（内線規程による）
4. **接続**：管をカップリングやコネクタの奥までしっかり差し込み、止めねじの**頭がねじ切れるまで**締め付ける。緩むと、機械的強度も電気的接続も不十分になる
5. **接地**：金属管は電気的につながっている必要があり、必要な場合は接地工事を行う

## 根拠となる法令・基準
- **電気設備技術基準の解釈 第158条（金属管工事）**
  - 使う電線は絶縁電線（屋外用ビニル絶縁電線を除く）
  - 電線は、より線または一定太さ以下の単線（短い管に収める場合を除く）
  - 管内では電線に接続点を設けない
  - 管の厚さの規定（コンクリート埋込みは1.2mm以上など）
  - 管相互、管とボックスなどは、堅ろうかつ電気的に完全に接続する
