# 電灯配線と電話線・LANケーブルを近づけるときの注意点

## 1. 基本的な考え方
電灯配線（強電）と電話線・LANケーブル（弱電）が近いと、次の2つの問題が起きます。

- **安全面**:絶縁劣化や被覆の損傷で混触すると、弱電側に電圧がかかります。感電や火災、機器の破損につながります。
- **通信品質**:電灯線から誘導ノイズを受け、通信速度の低下やエラーの原因になります。

## 2. 法令上のルール

### 電気設備技術基準の解釈 第167条(低圧配線と弱電流電線等との接近・交差)
低圧配線が弱電流電線等と接近または交差する場合は、混触による感電や火災のおそれがないように施設します。主な方法は次のとおりです。

- **離隔距離を確保する**:10cm以上(低圧配線が裸電線の場合は30cm以上)。
- **使用電圧300V以下の場合**は、次のいずれかでも可とされています。
  - 間に絶縁性の隔壁を堅ろうに設ける。
  - 低圧配線を絶縁管(合成樹脂管など)に収める。
  - 弱電流電線側を絶縁管に収める。

※細かい条件は改正されることがあるため、施工前に最新の解釈で確認してください。

### 同じ管・ボックスに入れない
低圧配線と弱電流電線は、原則として同一の管、線ぴ、ダクト、ボックス内に一緒に収めません。やむを得ず同じボックス内に収める場合は、セパレータ(隔壁)で区分するなどの対策が必要です。

### 上位の根拠
- 電気設備技術基準(省令)第56条(配線の感電又は火災の防止):配線は、施設場所の状況や電圧に応じて、感電や火災のおそれがないように施設することを定めています。第167条はこれを具体化した規定です。
- 内線規程(日本電気協会の民間規程)にも、弱電流電線との離隔や同一管収納の禁止が示されています。法令ではありませんが、現場では実務上の基準として広く使われています。

## 3. 現場での実務ポイント

- **交差は直角に**:やむを得ず交差させるときは直角に交わらせます。長い距離の平行配線は避けます。
- **離隔は法定の10cmで満足しない**:LANケーブルはノイズの影響を受けます。100V配線でも、特に蛍光灯やインバータ機器の配線に対しては、できるだけ離します。
- **配線ルートを分ける**:天井裏や壁内では、電灯線と通信線で別々の支持材やルートを使い、結束バンドで一緒に束ねません。
- **金属管・金属ダクトの接地**:金属製の配管やダクトを使う場合は、接地(D種など)が必要です。
- **コンセント・スイッチボックスの共用に注意**:強電と弱電を同じボックスに入れる場合は、仕切り板のある製品を使います。

## 4. 資格の注意点

# 結論

**原則としてできません。** 第二種電気工事士が従事できるのは、**一般用電気工作物**の電気工事の作業です。工場が高圧受電などの**自家用電気工作物**である場合、その配線工事は第一種電気工事士などの資格が必要です。

# 根拠

- **電気工事士法 第3条第1項**
  自家用電気工作物（最大電力500kW未満の需要設備）の電気工事の作業は、第一種電気工事士でなければ従事できません。
- **電気工事士法 第3条第2項**
  一般用電気工作物の電気工事の作業は、第一種または第二種電気工事士でなければ従事できません。第二種の守備範囲はこちらです。
- **電気工事士法 第3条（特殊電気工事・簡易電気工事に関する各項）**
  - ネオン工事・非常用予備発電装置工事は、**特種電気工事資格者**でなければ従事できません。第一種でもできません。
  - 600V以下で使用する設備の工事（簡易電気工事）は、**認定電気工事従事者**も従事できます。
- **電気工事士法 第4条の3**
  認定電気工事従事者認定証に関する規定です。
- **電気工事士法施行規則 第2条**
  資格がなくてもできる軽微な作業を定めています。

# 例外：「工場」でも一般用扱いなら第二種で可

自家用か一般用かは、建物の種類ではなく**受電方式や設備**で決まります（電気事業法 第38条、電気事業法施行規則 第48条）。

- 600V以下（低圧）で受電する小規模な工場や作業場は、一般用電気工作物にあたることがあり、その場合は第二種で施工できます。
- ただし次のものは自家用扱いになり、第二種だけでは施工できません。
  - 高圧（6.6kVなど）で受電している設備
  - 小出力発電設備の規模を超える発電設備（太陽光50kW以上など）を持つ設備
  - 爆発性・引火性の物が存在し、事故のおそれが多い場所に設置される設備

まず、その工場の**受電電圧と電気工作物の区分**を確認してください。

# 第二種でもできること

1. **軽微な作業**（施行規則 第2条）
   資格不要の範囲として、次のような作業があります。
   - 配線器具の取付け・取外し（一定の範囲）
   - 電線管に電線を通す作業
   - 電柱や腕木の設置など

   ただし、範囲は限定されています。
2. **認定電気工事従事者の認定を受ける**
   第二種電気工事士の免状交付後に**3年以上の実務経験**を積み、認定講習を修了すると、**600V以下**の自家用設備の簡易電気工事ができます。高圧部分は不可です。
3. **第一種電気工事士を取得する**
   第二種取得者は、筆記試験の一部免除は特にありません（実務経験の要件は試験合格後の免状交付に関係します）。

# 検電器の使い方

検電器は「電気が来ていないこと」を作業前に確認する道具です。感電事故を防ぐための基本中の基本です。

## 1. 法令上の位置づけ
- **労働安全衛生規則 第339条（停電作業を行う場合の措置）**
  - 開路に用いた開閉器に施錠するか、通電禁止の表示をするか、監視人を置く（第1項第1号）。
  - コンデンサやケーブルがある回路では、残留電荷を放電する（同項第2号）。
  - **高圧・特別高圧の電路は、検電器具で停電を確認し、短絡接地器具で確実に短絡接地する（同項第3号）。**
- 低圧でも、停電作業をする以上は無電圧の確認が必要です。実務上は検電器やテスターで確認します。
- **労働安全衛生規則 第36条第4号**：充電電路の敷設・修理などの業務には特別教育が必要です。
- **電気工事士法 第3条**：電気工事の作業は資格者が行います。無資格者は補助作業に限られ、検電も資格者の指示・監督下で行います。

## 2. 使う手順（基本は「確認→検電→再確認」）

**① 使用前点検**
- 本体の割れ、汚れ、水濡れ、コードの傷がないか見る。
- 電池が入っているか、テストボタンで音や光が出るか確認する。
- **使う電圧に合った検電器か確認する。** 低圧用を高圧に使ってはいけません。

**② 動作確認（検電前）**
- 同じ種類の検電器で、**電気が来ているとわかっている箇所**（またはチェッカー）で反応を確認します。
- ここで反応しない検電器は、「無電圧」と表示しても信用できません。

**③ 検電**
- 対象は**全相・全極**です（単相3線なら赤・白・黒すべて、三相なら全相）。
- 先端を導体の露出部に確実に当てます。隣の線や端子に触れてショートさせないよう注意します。
- 高圧では、**絶縁手袋・絶縁長靴・保護帽**などを着け、握り部の限度表示より先を持たない。
- 反応なし＝無電圧と判断します。

**④ 再確認（検電後）**
- もう一度、充電部で検電器が動くか確認します。検電中に電池切れや故障が起きていないことを確かめるためです。
- 「生きている→対象は無電圧→やはり生きている」という流れが安全の基本です。

**⑤ 高圧の場合**
- 無電圧を確認したら、放電と短絡接地を行います（第339条第1項第2号・第3号）。

## 3. 注意点
- **反応がない＝安全とは限りません。** 電池切れ、故障、使用電圧の不適合、検知部の接触不良などが原因のことがあります。
- 非接触（検知）型は、被覆の状態やケーブルの配置、静電気で誤表示することがあります。確実に確認したいときは、露出導体にテスターを当てる、または接触型検電器を使います。
- 雨天や湿気の多い環境では、感度が変わったり絶縁性能が落ちたりします。
- 検電後も、作業中は施錠・表示・監視で誤投入を防ぎます。検電はあくまで確認手段で、停電措置の代わりにはなりません。

## 4. 若手の方へ
- 分電盤の中でも、**ブレーカーを切った後でも一次側（電源側）は充電されています。** 検電する場所と範囲を先輩や責任者に確認してください。
- 無資格の場合は、**必ず資格者の指示のもとで行う**こと。わからないときは自己判断せず質問してください。

具体的な機種（ネオン式・電子式・高圧用・非接触型）や現場（分電盤、キュービクルなど）を教えてもらえれば、もう少し細かく説明できます。

# ねじなし電線管（E管）とは

## 概要
**ねじなし電線管**は、電線を保護する**金属製の配管材（金属管）**の一種です。管の端部にねじを切らずに、専用の附属品（カップリングやコネクタ）の**止めねじを締めて接続**します。管の呼びには「E」を付け、**E19、E25、E31、E39、E51、E63、E75**があります。数字は、おおよその外径(mm)に対応した呼びです。規格は**JIS C 8305（鋼製電線管）**で、次の3種類のうちの1つです。

| 種類 | 記号 | 特徴 |
|---|---|---|
| 厚鋼電線管 | G管 | 肉厚。ねじ切りして接続 |
| 薄鋼電線管 | C管 | G管より薄い。ねじ切りして接続 |
| **ねじなし電線管** | **E管** | **最も薄く軽い。ねじ切り不要** |

## 特徴
- **ねじ切り作業が不要**なので、施工が早く軽い。
- 管が薄いので、**機械的強度はG管・C管より劣る**。
- 管の切断後は、**切り口の面取り（リーマ掛け）**が重要。
- 接続部の止めねじは、**頭部がねじ切れるまで締め付ける**タイプが一般的（締付けトルクの管理になる）。

## 主な附属品
- ねじなしカップリング（管どうしの接続）
- ねじなしボックスコネクタ（ボックスとの接続）
- ブッシング（管端の保護）
- 絶縁ブッシング、サドルなど

## 根拠となる法令・基準
1. **電気設備技術基準の解釈 第159条（金属管工事）**
   - 電線は絶縁電線（屋外用ビニル絶縁電線を除く）で、より線または一定径以下の単線であること。
   - 管内では**電線に接続点を設けない**こと。
   - 管の厚さは、コンクリート埋込みの場合は**1.2mm以上**、それ以外は**1mm以上**（継目なし、長さ4m以下の乾燥場所などの例外あり）。
   - 管の端口や内面は、**電線の被覆を損傷しない滑らかな構造**とすること。
   - 管相互、および管とボックスは、**堅ろうかつ電気的に完全に接続**すること。
   - 金属管には**接地工事**をすること（一定の条件で省略可）。
2. **電気設備技術基準の解釈 第175〜177条**（粉じん、可燃性ガス、危険物のある場所）
   - 爆燃性粉じんや可燃性ガスのある場所は、より厳しい施設条件が定められています。E管は管が薄く、ねじ接続でもないため、こうした場所には**原則使えません**。
3. **JIS C 8305**（鋼製電線管）：寸法や肉厚などの製品規格。
4. **内線規程（JEAC 8001）**：民間規程ですが、実務上は重要です。たとえば曲げ半径は管内径の6倍以上、1区間の曲げ角度の合計は270度以内、といった内容です。

## 施工のポイント
- 切断は、パイプカッタか金切りのこを使い、**リーマで内外面のバリを必ず除去**する。
- 曲げは**パイプベンダ**で、管をつぶさないように行う。
- カップリングへは**管を奥まで差し込んでから**止めねじを締める。
- 接地線は、必要な場合にボックスコネクタ部などで確実に接続する。

## 資格との関係
一般用電気工作物の電気工事は、**電気工事士法 第3条**により電気工事士でなければ従事できません。無資格の方は、配管の運搬、切断、曲げなどの補助的作業にとどまります。どこまでが補助作業かは、法令や通達で整理されています。迷ったら、必ず**有資格の先輩や上司に確認**してください。

第二種電気工事士の技能試験では、ねじなし電線管の施工（ボックスコネクタ、カップリング、リングレデューサなど）が出題されます。実物で練習すると理解しやすいです。
