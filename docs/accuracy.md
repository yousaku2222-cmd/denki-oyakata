# L線とN線の違い、線の色

## 1. LとNの違い（単相100Vの場合）

| | L線（Live） | N線（Neutral） |
|---|---|---|
| 呼び方 | 非接地側電線（電圧側） | 接地側電線（中性線） |
| 対地電圧 | 約100V（触ると感電する） | ほぼ0V |
| 理由 | 柱上変圧器の二次側で、片方の線に接地をしていない | 同じ変圧器の片方の線に**B種接地工事**をしている |
| 色 | **黒**（ほかに赤・青など） | **白** |

- 「Nは0Vだから触っても安全」とは限りません。負荷に電流が流れており、断線や接地不良があれば電位が上がります。**必ず停電してから作業してください。**
- 緑は電気を送る線ではなく、**接地線（アース線）** です。通常は電流が流れず、漏電時に電流を地面へ逃がして感電や火災を防ぎます。

| 色 | 意味 |
|---|---|
| 黒 | L（非接地側） |
| 白 | N（接地側） |
| 緑（または緑／黄） | 接地線 |
| 赤 | 単相3線式（100/200V）のもう一方の電圧側線。黒と赤がL1・L2で、白が中性線N |

# 工事写真を撮る理由

結論から言うと、**「あとから見えなくなる部分が、きちんと施工されたことを証明するため」**です。

## 1. 主な理由

### ① 隠れる部分は完成後に確認できない
天井裏、壁の中、床下、地中埋設、コンクリート打込み配管、接地極などは、仕上げると見えません。あとで「本当にやったのか」「規定どおりか」を確認する手段が写真しかありません。

### ② 検査・確認の記録になる
- 発注者や監督員が毎回立ち会えるわけではないので、写真が確認の代わりになります。
- 公共工事では、特記仕様書や共通仕様書（公共建築工事標準仕様書〈電気設備工事編〉など）、国交省の「営繕工事写真撮影要領」に基づいて提出を求められます。
- 絶縁抵抗や接地抵抗の測定値（計器の表示）も、写真で残すのが一般的です。

### ③ 不具合やトラブルのときの証拠になる
- 工事後に漏電、火災、不具合などが起きたとき、施工に問題がなかったことを示す資料になります。
- 他業種による破損、設計変更、追加工事の証拠にもなります。
- 請負の契約不適合責任（**民法第559条・第562条、第637条**）が問われたときにも、施工状況を説明する根拠になります。

### ④ 技術基準への適合を示す
次のような項目は、写真で施工状況を示すことが多いです。
- 絶縁抵抗：**電気設備技術基準 第58条**
- 接地工事：**電気設備技術基準 第10条・第11条**、**電気設備技術基準の解釈 第17条**
- 埋設深さ、配管の支持間隔、ボックス内の接続など（内線規程や解釈に基づく）

### ⑤ 保守・改修・引き継ぎに使える
何年後かの改修や点検のとき、配管やケーブルがどこを通っているかが分かります。

### ⑥ 社内の品質管理・教育
先輩や上司のチェックを受けられ、失敗や良い施工例の共有にも使えます。

## 2. 法令上の位置づけ（注意点）

**写真の撮影そのものを直接義務づけた法令は、基本的にありません。** 撮影が必要になるのは、主に次の場合です。
- 工事請負契約や仕様書で指定されている
- 発注者や元請から提出を求められている

関連する記録義務としては、次のものがあります。
- **電気工事業法（電気工事業の業務の適正化に関する法律）第24条**：電気工事業者は帳簿を備え、保存する義務があります（詳細は同法施行規則）。
- **建設業法第40条の3**：建設業者は帳簿を備え、保存する義務があります（詳細は同法施行規則）。

これらは写真ではなく帳簿の義務ですが、「施工内容を記録して残す」という考え方は同じです。条番号は改正されることがあるので、実務では最新の条文や契約図書を確認してください。

## 3. 撮り方の基本

- **隠れる前に撮る**（ふた閉め、埋め戻し、天井張りの前）
- **黒板（工事名・場所・内容・日付・寸法）を入れる**
- **スケールや定規で寸法を示す**（埋設深さ、離隔、ピッチなど）
- **全景と近景の両方**を撮る
- **施工前・施工中・施工後**で撮る
- 測定値は**計器の表示が読める**ように撮る
- 写真を**加工・改ざんしない**（信用を失い、契約上も問題になります）

迷ったら、「あとで見えなくなる？」「証明が必要になりそう？」と考えて、**多めに撮っておく**のが安全です。何を撮るべきかは、現場ごとの仕様書や撮影要領に従い、不明な点は先輩や監督に確認してください。

# 漏電が起きる原因

## 1. 漏電とは
電気は本来、電線（導体）の中だけを流れます。**絶縁が劣化・破壊されて、電気が大地や金属部分など本来通らない経路に流れ出る現象**が漏電です。電気設備の用語では「地絡」にあたります。

漏電した電気は、人が触れれば感電、発熱すれば火災の原因になります。

## 2. 漏電が起きる主な原因

絶縁物（被覆・碍子・巻線のワニスなど）が壊れる、または絶縁が効かなくなることが根本原因です。

| 原因 | 具体例 |
|---|---|
| **経年劣化** | ビニル被覆の硬化・ひび割れ、ゴムの劣化、電動機巻線の絶縁低下 |
| **熱による劣化** | 過負荷、接続部の緩みによる発熱、断熱材に埋まったケーブル |
| **水分・湿気** | 浴室、屋外、地中、結露、雨水の浸入。水は絶縁抵抗を大きく下げる |
| **機械的損傷** | 施工時の被覆の傷、ステープルの打ち込み過ぎ、壁内での釘・ビス貫通、ボックス角での引っ張り・こすれ |
| **施工不良** | 接続部の絶縁処理不足、防水処理の不備、Vケーブル外装のむき過ぎ、電線の挟み込み |
| **動物・虫** | ネズミのかじり、ゴキブリなどの侵入 |
| **化学的要因** | 油、薬品、塩害、紫外線による被覆の劣化 |
| **汚損・ほこり** | 端子部や配線器具にたまったほこりが湿気を含み、絶縁が低下（トラッキング現象） |
| **機器の内部故障** | 電気温水器、エアコン、洗濯機、水中ポンプのヒーターや巻線の絶縁破壊 |

## 3. 漏電しやすい場所
- 水気のある場所（浴室、洗面所、屋外、厨房）
- 湿気の多い場所（地下、床下、工場の洗浄エリア）
- 振動の多い場所（モーター周り、可動部の配線）
- 高温になる場所（ヒーター周り、天井裏の熱だまり）

## 4. 関連する法令・基準
※条番号は改正されることがあるため、実務では最新版を確認してください。

- **電気設備技術基準（電技）第5条**：電路は、大地から絶縁しなければならないこと（絶縁の原則）を定めています。
- **電技 第58条**：低圧電路の絶縁性能として、漏えい電流を規定値以下に抑えることを求めています。
- **電技解釈 第14条**：低圧電路の絶縁抵抗値を定めています。
  - 対地電圧150V以下（100V回路）：**0.1MΩ以上**
  - 300V以下で上記以外（三相200Vなど）：**0.2MΩ以上**

# アース（接地）の目的

## 結論
**漏電したときに、人が感電したり火災が起きたりするのを防ぐため**です。副次的に、機器の保護、ノイズや静電気の逃がしにも役立ちます。

## 1. 感電防止（一番の目的）
機器の内部で絶縁が劣化して漏電すると、金属の外箱に電圧がかかります。

- **アースなし**：外箱が充電したままになり、人が触ると体を通って電流が大地に流れ、感電します。
- **アースあり**：漏電電流の大部分が接地線から大地に流れ、外箱の電位が下がります。触っても体に流れる電流は小さくなります。

この数字は、**接続できる電線の公称断面積（mm²）の系列**に由来します。端子専用の数字ではなく、電線側の呼び方をそのまま使っています。

# 100V回路の絶縁抵抗

## 結論
**0.1MΩ以上**が必要です。

## 根拠
- **電気設備技術基準（電技）第58条**：低圧電路の絶縁抵抗値を定めています（絶縁性能の基本規定）。
- **電技解釈 第14条**：具体的な数値を示しています。

| 電路の使用電圧 | 絶縁抵抗値 |
|---|---|

| 300V以下で、対地電圧150V超 | 0.2MΩ以上 |
| 300V超 | 0.4MΩ以上 |

## 補足

- **三相3線式200V（非接地）**：対地電圧は200Vなので、0.2MΩ以上です。

# D種接地工事の接地抵抗値

**原則は100Ω以下**です。ただし、次の条件を満たす場合は**500Ω以下**まで緩和されます。

| 条件 | 接地抵抗値 |
|---|---|
| 原則 | **100Ω以下** |
| 低圧電路で、地絡時に**0.5秒以内**に自動的に電路を遮断する装置（漏電遮断器など）を施設する場合 | **500Ω以下** |

## 根拠
- **電気設備技術基準の解釈（電技解釈）第17条第3項**（D種接地工事の施工方法）
- D種接地工事を適用する対象は、使用電圧300V以下の低圧機器の金属製外箱など（**電技解釈第29条**）です。

## 補足
- 接地線は、**直径1.6mm以上の軟銅線**などを使用します（電技解釈第17条第3項）。
- 300Vを超える低圧機器の場合は、D種ではなくC種接地工事（10Ω以下、0.5秒以内の遮断装置があれば500Ω以下）になります（電技解釈第17条第4項）。

- 試験（第二種電気工事士）では、「100Ω以下、0.5秒以内に遮断する漏電遮断器があれば500Ω以下」とセットで覚えておくと確実です。
