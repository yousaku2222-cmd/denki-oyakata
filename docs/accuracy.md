# L線とN線の違い、線の色

## 1. LとNの違い

| | L（Line） | N（Neutral） |
|---|---|---|
| 呼び方 | 非接地側電線（電圧側） | 接地側電線（中性線） |
| 対地電圧 | 約100V | ほぼ0V |
| 感電 | 触れると感電する | 条件によっては感電する |

- 柱上変圧器の低圧側の1線には、B種接地工事が施されています（電気設備技術基準の解釈 第24条）。この接地された線がNです。
- 接地されていない線がLで、大地との間に100Vがかかっています。
- Nは大地とほぼ同電位ですが、安全とは限りません。負荷につながった状態でN線が断線すると、負荷を通って電圧が現れます。Nも触らず、必ず停電させて作業してください。

## 2. 電線の色

| 色 | 意味 | 備考 |
|---|---|---|
| **黒** | 非接地側（L） | 電圧線 |
| **白** | 接地側（N） | 単相100Vでは必ず白をNに使う |
| **緑**（緑／黄） | 接地線（PE） | 通常は電流が流れない。機器の金属部の接地用 |
| **赤** | 非接地側（L） | 単相3線式の2本目の電圧線、または三相の1相 |

- **単相3線式（100V/200V）**は、赤と黒が電圧線（L1・L2）で、白が中性線です。赤－黒間で200V、赤または黒と白の間で100Vになります。
- **単相200V**では、白を使わず、黒と赤など両方が非接地側になります。この場合、白は使えません。
- **三相3線式**では、赤・白・黒を各相に使うことがあります。この場合、白が接地側とは限りません。

## 3. 現場で守ること

- **スイッチ・ヒューズ・ブレーカーはL（非接地側）に入れます。** N側だけを切る配線にすると、器具が停電中でも充電されたままになります。
- **コンセントは接地側極に「W」の表示があります。** 向かって左の長い穴がNで、ここに白線をつなぎます。
- **ソケット（受金ねじ部）は接地側（N）につなぎます。** 電球交換時の感電防止のためです。
- **緑の線は電流を流す線として使いません。**

## 4. 根拠法令

- 電気設備技術基準の解釈 第10条（電線の識別）：色の取り決めが定められています。接地線は緑、接地側電線は白または灰色などです。
- 電気設備技術基準の解釈 第24条：B種接地工事
- 電気設備技術基準の解釈 第17条：接地工事の種類と施設方法
- 電気設備技術基準の解釈 第29条：機械器具の金属製外箱の接地
- 内線規程（民間規程）：コンセントの極性、スイッチを非接地側に入れること等

※解釈は改正が多く、条番号や内容が変わっていることがあります。実際に使う際は最新版を確認してください。

- **色だけを信じない。** 古い建物や他業者の施工では、色が違ったり、白が電圧線に使われたりしていることがあります。必ず検電器とテスターで確認してください。
- 作業前に必ず**停電させ、検電する**ことが基本です。

# 工事写真を撮る理由

## 結論
工事写真は、**「ちゃんと基準どおりに施工した」ことを、あとから目で見て証明するため**に撮ります。工事が終わると天井裏・壁の中・地中・ボックスの中などは見えなくなるので、写真が唯一の証拠になります。

なお、電気工事士法などに「写真を撮れ」と直接書いた条文は、私の知る限りありません。実際には**契約（仕様書）で求められる**ことがほとんどです。

## 主な理由

### 1. 隠れる部分の施工証明
- 天井内配線、壁内配管、埋設配管、接地極、ボックス内の接続部など
- 検査や引渡しの時点では確認できないため、施工中に撮ります。

### 2. 技術基準に適合していることの証明
電気設備は、次のような基準に合って施工されている必要があります。
- 電気設備に関する技術基準を定める省令（例：第58条 低圧電線路の絶縁性能）
- 電気設備技術基準の解釈（例：第14条 低圧電路の絶縁性能、第17条 接地工事の施設方法）
- 内線規程（民間規程）

絶縁抵抗値や接地抵抗値の測定結果、電線の接続状況、接地線の太さや埋設状況などを、写真で記録します。

### 3. 発注者・監督員への報告と検査対応
- 公共工事では、仕様書や写真撮影要領（例：国土交通省の「営繕工事写真撮影要領」）で、撮る項目や方法が決まっています。
- 民間工事でも、契約や施工要領書で求められるのが一般的です。
- 写真がないと「施工していない」と扱われ、やり直しや手直し、場合によっては請求や支払いに影響することもあります。

### 4. トラブル・事故時の証拠
- 後日、漏電、火災、感電などが起きたときに、施工に問題がなかったことを示す材料になります。
- 請負工事では、引渡し後も施工不良の責任（契約不適合責任）を問われる可能性があります（民法第559条で準用される第562条、第637条）。その際の防御資料になります。

### 5. 帳簿・記録の補強
電気工事業者は、施工内容の帳簿を備え付け、5年間保存する義務があります（電気工事業の業務の適正化に関する法律 第24条、同法施行規則）。帳簿に写真の添付義務はありませんが、**施工内容を裏づける資料**として写真を使う会社は多いです。

### 6. 保守・改修時の資料
- 数年後に改修や増設をするとき、どこに何が通っているかが分かります。
- 後から入る別の職人が助かります。

### 7. 安全管理・教育
- 施工状況や安全対策（養生、墜落防止、活線近接作業の措置など）の記録になります。
- 若手の教育や、ミスの振り返りにも使えます。

## 撮るときのポイント
- **着工前・施工中・完了後**の3段階で撮ります（ビフォー・アフター）。
- **工事黒板**に、工事名、場所、内容、日付、測定値などを書いて一緒に写します。
- 隠れる前に撮ります。ボード張りや埋め戻しの後では撮れません。
- 測定値（絶縁抵抗・接地抵抗）は、計器の表示と黒板を同じ画面に入れます。
- 全体の写真と、接続部などのアップの両方を撮ります。
- 何の写真か分かるよう、場所や系統が特定できる構図にします。
- 写真を加工したり差し替えたりしてはいけません（改ざんは契約違反や信用失墜につながります）。

# 漏電が起きる理由

## 1. 漏電とは
本来は電線の中だけを流れるはずの電流が、絶縁が壊れたり弱ったりした箇所から、大地や金属部分、水、人体などへ流れ出る現象です。電気的には、電路と大地の間の絶縁抵抗が下がった状態（地絡）です。

つまり、**電線や機器の「絶縁」が何らかの理由で壊れる、または劣化する**ことが根本原因です。

## 2. 主な原因

### ① 絶縁体の劣化（経年・環境）
- 熱、紫外線、湿気、油、薬品などでビニル被覆やゴムが硬化・ひび割れする
- 過負荷や接続部の発熱による被覆の焼損
- ほこり＋湿気による汚損（トラッキング現象。コンセントとプラグの間など）

### ② 機械的な損傷
- 配線を釘・ビス・カッターで傷つける（壁内配線への打ち込みなど）
- 無理な曲げ、引っ張り、踏みつけ、挟み込み
- 金属管やボックスの角、バリでの被覆擦れ
- ネズミなどの動物のかじり

### ③ 施工不良（若手が特に注意すべき点）
- ケーブルの外装や絶縁被覆を剥くときに、芯線の絶縁体まで傷つけた
- 圧着、差込形コネクタ、テープ巻きなど、接続部の絶縁処理が不十分
- 端子からはみ出したよりのヒゲ（素線）が筐体に接触している
- 接地線と充電線の結線ミス
- 防水処理が必要な屋外・水気のある場所での施工不良（ケーブルの引込口、ジョイント部）

### ④ 水の侵入・結露
雨水、結露、浸水が絶縁物の表面や内部に入ると、絶縁抵抗が大きく下がります。屋外配線、地中配線、浴室・厨房まわりで多く発生します。

### ⑤ 機器内部の故障
モーターの巻線の絶縁劣化、電熱器のヒーター断線・絶縁不良、インバータやノイズフィルタ（コンデンサ）による漏れ電流などがあります。

### ⑥ サージ・過電圧
雷サージなどで絶縁が破壊されることがあります。

## 3. なぜ問題か
- **感電**：漏電している機器の金属外箱に触れると、人体に電流が流れます
- **火災**：漏電箇所で発熱や放電（スパーク）が起き、周囲の可燃物に着火します
- **設備の損傷**：機器の故障や停電につながります

## 4. 関係する法令・基準

| 内容 | 根拠 |
|---|---|
| 電路は原則として大地から絶縁する | **電気設備に関する技術基準を定める省令（電技省令）第5条** |
| 地絡（漏電）に対する保護対策（漏電遮断器の施設など） | **電技省令第15条** |
| 低圧電路の絶縁性能 | **電技省令第58条** |
| 絶縁性能の具体的な数値、漏えい電流の基準（1mA以下） | **電気設備技術基準の解釈（電技解釈）第14条** |
| 地絡遮断装置（漏電遮断器）の施設 | **電技解釈第36条** |
| 金属製外箱などの接地（感電防止） | **電技解釈第29条** |

### 絶縁抵抗値の目安（電技省令第58条）
- 使用電圧300V以下で対地電圧150V以下（例：単相100V）：**0.1MΩ以上**
- 使用電圧300V以下でそれ以外（例：三相200V）：**0.2MΩ以上**
- 使用電圧300V超：**0.4MΩ以上**

絶縁抵抗の測定が困難な場合は、漏えい電流が1mA以下であることで代えられます（電技解釈第14条）。

# アース（接地）の目的

## 結論
アースの主目的は、**漏電や異常電圧が起きたときに、人が感電したり火災が起きたりするのを防ぐこと**です。電流の逃げ道を意図的につくり、機器の外箱などの電位が危険な値まで上がらないようにします。

## 具体的な役割

### 1. 機器の外箱に触れたときの感電防止
内部で絶縁が劣化して外箱に電圧が出る（漏電）と、アースがなければ外箱が対地電圧に近い電位になります。そこに人が触れると、人体を通って大地へ電流が流れ、感電します。

アースがあれば、
- 漏電電流の大部分がアース線側（人体よりはるかに低抵抗）を流れる
- 外箱の電位が低く抑えられる

ため、危険性が大幅に下がります。

### 2. 遮断器を確実に動作させる
アースがあると地絡電流が流れ、漏電遮断器（ELB）や過電流遮断器が検知して動作します。アースがないと電流が流れず、遮断器が動かないまま外箱が充電状態で残ります。

### 3. 高圧と低圧の混触対策（B種接地）
変圧器内部で高圧側と低圧側が接触（混触）すると、低圧側に高電圧が侵入します。低圧側の電位上昇を抑えるため、変圧器の低圧側に**B種接地**を施します。

### 4. その他
- 雷サージや異常電圧の逃がし

# 圧着端子の「2」「3.5」「5.5」の意味

## 数字は適用電線の公称断面積（mm²）
圧着端子の呼びの数字は、圧着できる電線の太さ（公称断面積、単位 mm²）の区分を表します。

| 端子の呼び | 適合電線の目安 |
|---|---|
| 1.25 | 0.25〜1.65 mm² |
| 2 | 1.04〜2.63 mm² |
| 5.5 | 2.63〜6.64 mm² |
| 8 | 6.60〜10.5 mm² |
| 14 | 約 10〜16 mm² |
| 22 | 約 16〜25 mm² |

範囲はメーカーやJIS C 2805の区分によって多少異なるため、正確には製品の仕様を確認してください。

## なぜ「2」「3.5」「5.5」という半端な数字なのか
端子が特別なのではなく、日本の電線の公称断面積の系列がそうなっているためです。電線は 0.9、1.25、2、3.5、5.5、8、14、22、38、60、80、100…（mm²）というサイズで作られています（例：JIS C 3307 の600Vビニル絶縁電線）。端子はこの系列に合わせて作られています。

この系列は、現場でよく使う単線の太さが元になっているとされています。
- 1.6 mm 単線 → 断面積 約2.0 mm² → 「2」
- 2.0 mm 単線 → 約3.14 mm² → 「3.5」
- 2.6 mm 単線 → 約5.3 mm² → 「5.5」

つまり「1.6mm、2.0mm、2.6mm といういつもの電線に対応するサイズ」と覚えると実務で役立ちます。この対応は目安としての理解で、細かい数値は規格ごとに異なります。

## ハイフンの後ろの数字は別の意味

- 前の数字（2、5.5）：適合電線の断面積
- 後ろの数字（4、5）：取り付けるねじの呼び径（mm）。M4なら4

# D種接地工事の接地抵抗値

## 結論
**100Ω以下**です。

ただし、**低圧電路で地絡を生じたときに0.5秒以内に自動的に電路を遮断する装置（漏電遮断器など）を施設する場合は、500Ω以下**まで緩和されます。

## 根拠
- **電気設備技術基準の解釈 第17条第4項第一号**
  - D種接地工事の接地抵抗値は100Ω以下とする。
  - 低圧電路で、地絡時に0.5秒以内に自動的に電路を遮断する装置を施設するときは500Ω以下とする。
- 接地線の太さも同条に規定があり、一般には**直径1.6mm以上の軟銅線**（またはこれと同等以上の強さ・太さのもの）を使います。

## 実務上の注意
- D種接地工事は、**300V以下の低圧機器の金属製外箱や配管**などに施します（解釈 第29条）。対地電圧が300Vを超える低圧機器は**C種接地工事**（10Ω以下、条件により500Ω以下）になります。

- 実際の施工では、500Ωまで許されるからといって高い値を狙わず、**できるだけ低い抵抗値にする**のが安全上望ましいです。
- 水気のある場所や、機器の設置条件によっては、別途の規定（例：解釈 第143条、第29条など）も関係します。現場の条件に応じて最新の解釈と内線規程を確認してください。
