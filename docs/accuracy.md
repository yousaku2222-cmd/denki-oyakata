# 資格がなくてもできる作業

結論から言うと、**あります。ただし範囲は限られます。** 無資格の人ができるのは、次の①「軽微な工事」と②「補助的な作業」の2種類です。

## 1. 根拠となる法令の考え方

- **電気工事士法 第3条**
  - 自家用電気工作物（500kW未満の需要設備）の電気工事の作業は、第一種電気工事士でなければ従事できません（第1項）。
  - 一般用電気工作物の電気工事の作業は、第一種または第二種電気工事士でなければ従事できません（第2項）。
  - どちらも「保安上支障がないと認められる作業で経済産業省令で定めるもの」は除かれています。
- **電気工事士法 第2条第3項**: 「電気工事」の定義から、**政令で定める軽微な工事は除かれています**。
- **電気工事士法施行令 第1条**: 軽微な工事の具体的な範囲です。
- **電気工事士法施行規則 第2条**: 電気工事士でなければできない作業が列挙されています。そこに含まれない補助的な作業は、資格がなくても可能です。

※施行令・施行規則の細かい号の区分は改正されることがあります。実際に判断するときは、最新の条文で確認してください。

## 2. 資格なしでできる作業の例

### ① 軽微な工事（施行令第1条）
そもそも「電気工事」に当たらないものです。

- 600V以下で使用する配線器具（接続器、点滅器、開閉器など）への電線の**ねじ止め工事**（ただし、露出形のスイッチ・コンセントの取替えを除く部分など、施行規則側の制限があるので注意）
- 600V以下の電気機器や蓄電池の端子への電線のねじ止め
- 600V以下で使用する電力量計、電流制限器、ヒューズの取付け・取外し
- インターホン、電鈴、火災感知器などに使う**二次側36V以下の小型変圧器の二次側配線**
- 電線を支持する柱、腕木などの設置・変更
- 地中電線用の暗渠や管の設置・変更

### ② 補助的な作業（施行規則第2条に列挙されていないもの）
電気工事士の指示・監督のもとで行う、たとえば次のような作業です。

- 墨出し、資材の運搬、清掃
- 穴あけ、はつり、コア抜きなどの建築的な作業
- ケーブルの延線を手伝う作業など

保安上のリスクが低く、電線の接続や器具の取付けそのものではない作業が該当します。

## 3. 無資格ではできない作業の例（施行規則第2条の列挙事項）

- 電線相互の接続
- 電線をがいし、造営材に取り付ける作業
- 電線管、線ぴ、ダクトに電線を収める作業
- 配線器具（スイッチ、コンセントなど）の取付け・取外し、電線の接続
- 電線管の曲げ・ねじ切り、管とボックスの接続
- 金属製ボックスの取付け
- 配電盤の取付け・取外し
- 接地線・接地極の工事　など

「電線を触る、つなぐ、収める、器具を付ける」作業は、資格が必要と考えてください。

## 4. 第二種電気工事士の範囲

- できるのは、**一般用電気工作物**の電気工事です（法第3条第2項）。
- **自家用電気工作物（ビル、工場など）**の電気工事は、第一種電気工事士が必要です（法第3条第1項）。
- 例外として、600V以下の自家用電気工作物の**簡易電気工事**は、認定電気工事従事者の認定を受ければ従事できます（法第3条第4項）。

## 5. 注意点

1. **罰則**: 無資格で電気工事をすると、本人は電気工事士法違反（法第14条。3月以下の懲役または3万円以下の罰金）になり得ます。
2. **労働安全衛生法の特別教育**: 低圧の充電電路の敷設・修理の業務には、特別教育が必要です（労働安全衛生法第59条第3項、労働安全衛生規則第36条第4号）。電気工事士の資格があっても必要な場合があります。
3. **停電作業の原則**: 電路を停電させて作業するのが原則です（労働安全衛生規則第339条）。
4. **他法令**: 軽微な工事であっても、他の法令で資格が必要な場合があります。
   - 火災報知設備の設置: 消防設備士（消防法第17条の5など）
   - 通信、LAN、電話線の端末設備の接続: 工事担任者（電気通信事業法第71条）
5. **現場での判断**: 補助作業と電気工事の線引きがあいまいな場合は、自己判断せず、主任電気工事士や元請の監督者に確認してください。解釈に迷うときは、管轄の産業保安監督部に問い合わせるのが確実です。

資格のない間は、補助作業をしながら現場で経験を積み、第二種電気工事士の取得を目指すのが一般的な流れです。

# L線とN線の違い、電線の色

## 1. LとNの違い

| | L（Line） | N（Neutral） |
|---|---|---|
| 呼び方 | 非接地側電線、電圧側、活線 | 接地側電線、中性線 |
| 対地電圧 | 約100V（単相100V回路の場合） | ほぼ0V |
| 理由 | 柱上変圧器の二次側の1線にB種接地工事が施されているため | 接地されている線がNになる |

- 単相100V回路では、電源側の変圧器の片側がB種接地工事で大地とつながっています。この接地された線がNで、もう一方がLです。
- **Nは0Vに近いだけで、触っても安全とは限りません。** 負荷が動作中に断線していると、負荷を介してN側に電圧が出ることがあります。また、Nに電流が流れている最中に切断すると感電や火花の危険があります。作業前は必ずL・Nとも検電し、遮断器を切ってください。
- 単相3線式（100V/200V）では、中性線がN、両外線がL1・L2です。

## 2. 電線の色

| 色 | 用途 |
|---|---|
| **黒** | L（非接地側）。単相3線式ではL1側 |
| **白** | N（接地側）。単相3線式では中性線 |
| **赤** | 単相3線式のL2側（VVFの3心は黒・白・赤）。三相では赤・黒・青など、機器や回路で変わる |
| **緑** | 接地線（アース、E）。緑/黄の縞もある |

- **緑は電流を流す線ではなく、保護用のアース線です。** 緑をLやNの代用にしてはいけません。
- VVF 2心ケーブルは黒と白、3心は黒・白・赤です。
- 器具側では、スイッチは黒（L側）を開閉し、白は切らずに通します。コンセントでは、W表示や長い方の穴が接地側（N）、ランプレセプタクルでは、ねじ込み部分を接地側（N）につなぎます。

## 3. 根拠となる法令・基準

- **電気設備技術基準（省令）第10条・第11条**：電気設備の接地の原則と方法。
- **電気設備技術基準の解釈 第17条**：接地工事の種類（A〜D種）と施工方法。
- **同 第24条**：高圧・特別高圧と低圧が混触した場合の危険防止（変圧器のB種接地）。
- **電線の色の区別**：電技解釈には、白・黒を一律に義務付ける条文は私の知る限りありません。実務上は、**内線規程（JEAC 8001）** の電線色別に関する規定と、電線の規格（JIS C 3342 など）が根拠になります。内線規程は民間規格ですが、現場でも試験でも標準として扱われます。条番号は版によって異なるため、お手元の版で確認してください。
- 第二種電気工事士の技能試験でも、「接地側＝白、非接地側＝黒、接地線＝緑」という施工条件が示されます。

**ポイント：色は決まりごとなので必ず守り、そのうえで色を信用しすぎず、検電で確認する習慣をつけてください。**

# 工事写真を撮る理由

## 一言でいうと
**「あとから確認できない部分を、正しく施工した証拠として残すため」**です。電気工事は、天井裏・壁の中・床下・地中など、完成すると見えなくなる部分がたくさんあります。

## 主な理由

1. **隠れる部分の施工証明**
   - 配管や配線の経路、接地極の埋設、ボックス内の結線、支持間隔、防火区画の貫通処理など
   - 完成後は開けないと確認できないので、写真が唯一の証拠になります。

2. **仕様どおり・基準どおりに施工した証明**
   - 設計図書や仕様書、技術基準に合っているかを第三者（元請、監督員、施主、検査員）に示せます。
   - 例:
     - 絶縁抵抗測定の値（電気設備技術基準 第58条、同解釈 第14条）
     - 接地工事の施工状況（電気設備技術基準 第10条、同解釈 第17条）

3. **検査・引き渡しの資料**
   - 竣工検査や中間検査で、見えない部分の確認に使います。
   - 公共工事では、写真の提出が仕様書で求められることが多いです（国土交通省「写真管理基準（案）」「デジタル写真管理情報基準」など）。

4. **後日のトラブル・責任追及への備え**
   - 施工不良を疑われたとき、「ちゃんとやった」という客観的な証拠になります。
   - 施工側は、引き渡した目的物が契約内容に適合しない場合に責任を負います（民法 第562条、第637条）。
   - 建設業者には、営業に関する図書などの保存義務があります（建設業法 第40条の3、同施行規則 第26条）。

5. **保守・改修・事故調査での活用**
   - 数年後の改修で「どこに配管が通っているか」を把握できます。
   - 火災や感電などの事故原因を調べるときの資料にもなります。

6. **自分の確認と技術向上**
   - 撮るときに「ここは問題ないか」と見直す機会になり、ミス防止につながります。
   - 先輩や上司からのフィードバックにも使えます。

## 補足：法律で「写真を撮れ」と決まっているか
民間工事では、**写真撮影そのものを直接義務付けた法令は基本的にありません**。実際には次のものが根拠になります。
- 契約書、仕様書、施工要領書
- 発注者や元請の指示
- 公共工事での各種基準（公共建築工事標準仕様書〔電気設備工事編〕など）

現場ごとに求められる内容が違うので、**必ず現場代理人や先輩に撮影項目を確認してください**。

## 撮影のコツ
- **黒板（工事名、日付、場所、内容、寸法など）を入れる**
- **全景と近接の両方を撮る**（どこの何かが分かる写真と、細部が分かる写真）
- **施工前・施工中・施工後**を押さえる
- **スケールやメジャーを当てて寸法を示す**（埋設深さ、離隔、支持間隔など）
- **測定器の数値が読めるように撮る**（絶縁抵抗、接地抵抗など）
- **隠れる前に撮る**（ふたを閉める前、埋め戻す前、ボードを張る前）
- **ピンボケ・暗さに注意する**（撮った直後に確認）

## 注意点
- お客様宅や施設では、**撮影してよい範囲を事前に確認**してください。
- 写真には個人情報や機密情報が写り込むことがあるので、**保管や共有の方法**にも気をつけてください。

具体的な工種（接地工事、地中配管、分電盤など）で何を撮るべきか知りたければ、教えてください。

# 漏電が起きる原因

## 1. 漏電とは
電気は本来、電線（導体）の中だけを流れるように、被覆などの**絶縁物**で囲まれています。この絶縁が劣化したり壊れたりして、電流が**大地や金属の外箱など、本来流れない場所へ流れる**のが漏電です。
絶縁がなくなった部分に人が触れると**感電**し、漏れた場所が発熱したり火花が出たりすると**火災**につながります。

## 2. 主な原因

| 分類 | 具体例 |
|---|---|
| **絶縁物の経年劣化** | 熱・紫外線・湿気による被覆のひび割れや硬化。モーターやヒーター内部の巻線絶縁の劣化 |
| **機械的損傷** | 釘・ビスが刺さる、ステープルの打ち込みすぎ、無理な曲げ、踏みつけ、ボックス角やダクト端部での擦れ |
| **水分の浸入** | 屋外・水回りの接続部からの浸水、結露、配管内への水の浸入、防水処理不良 |
| **施工不良** | 皮むき時に芯線や被覆に傷をつける、接続部のテープ巻き不足、端子からの素線のはみ出し、ボックスのフタで電線を挟む、不適切な場所への機器・電線の使用 |
| **汚損・トラッキング** | コンセント周りのほこりと湿気で、プラグの刃の間に炭化導電路ができる |
| **動物・虫** | ネズミが被覆をかじる、虫の侵入 |
| **過熱・過電流** | タコ足配線などで被覆が熱劣化する |
| **サージ** | 雷サージなどで絶縁が破壊される |

若手の方が特に意識したいのは、**施工時に付けた小さな傷や接続不良が、後で漏電になる**ことです。施工直後は問題なくても、湿気や経年でじわじわ悪化します。

## 3. 「正常でも少し漏れている」点に注意
実際の電路には、ケーブルの静電容量やノイズフィルタ（コンデンサ）を通って、**ごく微小な漏えい電流**が常に流れています。これは故障ではありません。ただし、漏電遮断器が不要動作しやすくなる原因にはなります。

## 4. 関連する法令・基準

- **電気設備に関する技術基準を定める省令（電技）第5条**：電路は大地から絶縁することを原則とし、その絶縁性能の基本を定めています。
- **電技 第58条**：低圧の電路の絶縁性能（絶縁抵抗値）を定めています。
- **電気設備の技術基準の解釈（電技解釈）第14条**：低圧電路の絶縁抵抗値の具体値です。
  - 300V以下で対地電圧150V以下：**0.1MΩ以上**
  - 300V以下でそれ以外（対地電圧150V超）：**0.2MΩ以上**
  - 300V超：**0.4MΩ以上**
- **電技 第15条**：地絡（漏電）が生じたときに自動的に電路を遮断する装置などの保護対策です。
- **電技解釈 第29条**：機械器具の金属製外箱などの接地（D種接地工事）と、漏電遮断器を設ける条件です。
- **電技解釈 第17条**：接地工事の種類です。
- **労働安全衛生規則 第333条**：移動式・可搬式の電動機械器具などに対する、漏電による感電防止（感電防止用漏電しゃ断装置の接続、接地）を定めています。
- **内線規程（民間規程）**：漏電遮断器の施設場所や、定格感度電流の選定の実務的な目安が載っています。

※条番号は改正で変わることがあるため、実務では最新の電技解釈で確認してください。

## 5. 現場での対策
1. **施工時**：被覆を傷つけない、接続部の絶縁処理を確実にする、防水が必要な場所では適切な部材を使う。
2. **竣工・点検時**：絶縁抵抗計（メガー）で測定し、基準値以上か確認する。
3. **保護装置**：漏電遮断器を設置する（一般住宅用は定格感度電流30mA、動作時間0.1秒以内が目安）。
4. **接地**：金属外箱を接地し、漏電時に確実に遮断器を動作させ、人体に電圧がかかるのを防ぐ。

# アース（接地）の目的

アースは、**漏電したときに人が感電したり、火災や機器の損傷が起きたりするのを防ぐため**に付けます。

## 1. 主な目的

### ① 感電防止（最も重要）
機器の内部で絶縁が劣化して漏電すると、金属製の外箱に電圧がかかります。アースがないと、その機器に触れた人の体が漏電電流の通り道になって感電します。

アースがあれば、次のように働きます。
- 漏電電流の大部分がアース線側へ流れ、外箱の電位上昇が抑えられる（人体に流れる電流が小さくなる）
- 地絡電流が流れることで、漏電遮断器やブレーカが確実に動作する

### ② 漏電遮断器などの確実な動作
アースがないと、地絡電流が小さすぎて漏電遮断器が動作しないことがあります。

### ③ 高圧と低圧の混触時の保護（B種接地）
変圧器内部で高圧側と低圧側が混触すると、低圧側に高電圧が侵入します。柱上変圧器の低圧側に施すB種接地は、これを防ぐためのものです。

### ④ その他
- 雷サージや異常電圧の逃がし
- ノイズ対策（電子機器の誤動作防止）
- 静電気対策

## 2. 根拠となる法令・基準

| 内容 | 根拠 |
|---|---|
| 電気設備の接地の原則（感電、火災などの防止） | **電気設備技術基準（省令）第10条** |

# 電線とケーブルの違い

## 結論
**ケーブルは電線の一種**です。「電線」は導体を含む広い概念で、ケーブルはそのうち「絶縁した導体の上に、さらに保護被覆（シース）を施したもの」を指します。

## 法令上の整理
- **電気設備技術基準（電技）第1条（用語の定義）**
  「電線」とは、強電流電気の伝送に使う次のいずれかです。
  1. 電気導体そのもの（裸電線）
  2. 絶縁物で被覆した電気導体（絶縁電線）
  3. 絶縁物で被覆した上を保護被覆で保護した電気導体（ケーブル）
- **電技解釈 第1条（用語の定義）**
  ケーブルは電線の一種として定義されています。
- **電気用品安全法（施行令・別表第一）**
  電線類は「電線（絶縁電線、ケーブル、キャブタイヤケーブル）」などとして特定電気用品・特定電気用品以外の電気用品に分類されます。

# 圧着器（圧着ペンチ）の用途

## 一言でいうと
**電線どうしの接続や、電線と端子の接続を、圧力で押しつぶして確実に固定するための工具**です。はんだ付けやねじ止めとは違い、専用の圧着スリーブや圧着端子を電線にかしめて接続します。

## 主な使い道
| 用途 | 使う部材 | 主な圧着器 |
|---|---|---|
| 電線どうしの接続（差込形コネクタを使わない場合） | **リングスリーブ**（小・中・大） | リングスリーブ用圧着ペンチ（刻印：○、小、中、大） |

- **電気設備に関する技術基準を定める省令 第7条（電線の接続法）**
  電線を接続するときは、次の条件を満たす必要があります。
  - 接続部分の電気抵抗を増加させない
  - 電線の引張強さを20%以上減少させない
  - 接続管その他の器具を使用するか、ろう付けする
  - 絶縁性能の低下を防ぐ（絶縁処理をする）

3. **電線の被覆をむく長さを守る**

4. **圧着後に確認する**

   - 芯線の先端がスリーブから適正に出ているか

   リングスリーブは、ビニルテープなどで絶縁処理をします。

## 結論

圧着端子の「2」「3.5」「5.5」などの数字は、**その端子に適合する電線の太さ（公称断面積 mm²）の系列**に由来する呼び方です。端子の寸法そのものではありません。

## 詳しい説明

**1. 数字は電線の太さの系列から来ている**

日本の電線の公称断面積は、従来から次のような系列で作られています。

> 1.25 / 2 / 3.5 / 5.5 / 8 / 14 / 22 / 38 / 60 / 80 / 100 / 150 …（mm²）

圧着端子の呼び（JIS C 2805「銅線用圧着端子」）は、この系列に合わせてあります。「2」の端子は2 mm²前後の電線用、「5.5」は5.5 mm²前後の電線用、という対応です。

**2. 数字が中途半端な理由**

隣り合う数字の比は、おおよそ1.6倍前後（1.25→2→3.5→5.5→8→14→22…）です。電線の太さを等比的に段階づけた系列なので、1.5、2.5、4、6のようなキリのよい数字になりません。IEC系の1.5 / 2.5 / 4 / 6 / 10 / 16とは別の、日本で古くから使われてきた系列です。この系列が成立した経緯の細部まで説明できる資料は、私は把握していません。

**3. 呼びと適合電線は完全一致ではない**

1つの端子で、ある程度の幅の電線に対応します。端子の呼びと適合電線範囲は、JISや各メーカーのカタログの表で確認してください。例えば「5.5」の端子に5.5 mm²ちょうどの電線しか使えないわけではありません。

**4. 「5.5-4」の2つ目の数字は別物**

たとえば「R5.5-4」と書かれていたら、次の意味です。

- **5.5**：適合電線の太さの呼び
- **4**：取付けネジの穴径（M4用）
- **R**：丸形（Y形、YAなどの形状記号もあります）

2つの数字を混同しないように注意してください。

**5. 絶縁被覆付き端子の色**

被覆付きの端子は、太さに応じてスリーブが色分けされています。

| 色 | 目安 |
|---|---|
| 赤 | 〜1.25 mm²クラス |
| 青 | 2 mm²クラス |
| 黄 | 5.5 mm²クラス |

詳しい範囲はメーカー表で確認してください。

## 根拠になる法令・基準

端子の呼びを定めているのは法令ではなく、**JIS C 2805** です。ただし、端子と電線の組み合わせを誤ると、次の規定に反する接続になります。

- **電気設備に関する技術基準を定める省令 第7条**（電線の接続法）：電気抵抗を増加させず、絶縁性能の低下や断線のおそれがないように接続すること。
- **電気設備技術基準の解釈 第12条**（電線の接続法）：接続部分で電線の電気抵抗を増加させないこと、引張強さを20%以上減少させないこと、接続器具を使うことなどを具体的に規定。

## 実務でのポイント

- 電線の太さに合った呼びの端子を選ぶ（細い電線に大きい端子を使うと、かしめ不良や抜けの原因になります）。
- 端子の太さに合った**圧着工具**（ダイス）を使う。
- 圧着後は、軽く引いて抜けないか確認する。

## ① 資格上、触ってはいけない（作業してはいけない）もの

### 資格なしの場合
- 電気工事士でなければ、配線や器具の取付け・接続などの「電気工事の作業」はできません（電気工事士法 第3条）。
- 例外は「軽微な工事」（電気工事士法施行令 第1条）と「軽微な作業」（電気工事士法施行規則 第2条）です。
 - 例：接続器やスイッチにコードを接続する工事、36V以下の小型変圧器の二次側配線、電線支持物の設置など。
 - 電線管やダクトの取付け、電気工事士の補助作業なども、規則に列挙された範囲に限られます。
- 次の作業は、資格がなければ行ってはいけません。
 - 電線の接続
 - コンセントやスイッチの結線
 - 分電盤内の作業
 - 配線工事
- 違反すると罰則があります（電気工事士法 第14条）。

### 第二種電気工事士の場合
- できるのは、**一般用電気工作物**（住宅や小規模店舗など、600V以下で受電する設備）の工事です（電気工事士法 第3条第2項）。
- **自家用電気工作物**（ビル、工場、受電設備のある需要設備など）の工事は、原則として第一種電気工事士が必要です（同法 第3条第1項）。

 - ネオン工事
 - 非常用予備発電装置の工事
- 受電設備（キュービクルなど高圧部分）の工事や操作は、第二種の範囲外です。

## 一般的な呼び方

**「ケーブルストリッパー」**（回転式のものは「ロータリーストリッパー」「ケーブルシースストリッパー」「外装むき器」などとも呼ばれます）です。ケーブルに巻き付けるようにして回し、外側のシース（外装）だけに切り込みを入れて剥ぐ工具です。

## 似た工具との区別

| 工具 | 用途 |
|---|---|
| **回転式ケーブルストリッパー** | ケーブル外周をくるっと回してシースを切る。CVケーブル、VCT、同軸ケーブルなど丸形ケーブル向け |
| **VVFストリッパー** | VVF（平形ケーブル）の外装と絶縁被覆をまっすぐ引いてむく |
| **ワイヤーストリッパー** | 心線の絶縁被覆をむく（シースではなく単線・より線の被覆） |
| **電工ナイフ** | 手作業でシースや被覆をむく。慣れが必要で、心線を傷つけやすい |

同軸ケーブル用は、2段・3段の刃で外被、編組、絶縁体を一度にむける専用品もあります。

- **刃の深さを調整する**。深すぎると内部の絶縁被覆や心線を傷つけます。
- ケーブルの外径に合った工具を選ぶ。
- 切り込みを入れたあとは、無理に引きちぎらず、縦にも軽く切れ目を入れてから剥ぐ。
- 心線に傷が入った場合は、その部分を切り落としてやり直す。

# 盤の中の変圧器の何があぶないのか

「変圧器があぶない」と言われた場合、主に次の理由が考えられます。盤の種類（高圧受電盤、分電盤、制御盤など）で重みは変わります。

## 1. 感電する

- 変圧器の端子や巻線は充電部がむき出しになっていることが多いです。
- 高圧用（6.6kVなど）は、触れなくても近づくだけで危険です。
- 低圧（100V/200V/400V）でも、濡れた手や狭い盤内では死亡事故につながります。

## 2. 停電しても、反対側から電気が来る（逆励磁）

一番見落としやすい点です。

- 変圧器は逆向きにも電圧を作ります。
- 例えば制御用トランスで、二次側（100V）に発電機、仮設電源、別系統の電源、試験電源がつながっていると、一次側が200Vや400V、場合によってはそれ以上になります。
- 「ブレーカを切ったから大丈夫」と思い込むと感電します。**必ず検電器で、作業する端子そのものを確認してください。**

## 3. 短絡・アーク・火災

- 二次側が短絡すると大電流が流れ、アーク（火花・高熱）でやけどや盤の焼損が起きます。
- 過負荷や通風不良でも変圧器は焼損します。
- 油入変圧器は絶縁油の漏れや火災のおそれがあります。古い機器はPCB含有の可能性もあります。

## 4. 高温でやけどする

運転中の乾式変圧器の表面は、触れない方がよいほど熱くなることがあります。停止直後も熱いままです。

## 5. 計器用変成器（CT・VT）は取り扱いが特殊

盤内の変圧器には計器用変圧器（VT）や変流器（CT）もあります。

- **CT二次側を開放してはいけません。** 二次側に高電圧が発生し、焼損や感電につながります。
- **VT二次側は短絡してはいけません。** 焼損します。

## 6. 接地が不良だと、低圧側に高電圧がかかる

高圧と低圧の巻線が内部で混触したとき、低圧側に高電圧が出ます。これを防ぐためにB種接地工事があります。接地線が外れていると非常に危険です。

## 結論（実務の目安）
- **1区間（ボックスからボックスまで）の曲げ角度の合計は270°以内**にします。90°曲げなら**3か所まで**です。

撤去ケーブルの切断事故でいちばん多いのは、**「死んでいると思い込んだ活線を切る」**ことです。感電だけでなく、短絡によるアーク火傷、停電事故、火災につながります。

## 1. 自分がその作業をしてよいか確認する

- **電気工事士法第3条**では、資格のない人が電気工事の作業に従事することを制限しています。
  - 一般用電気工作物（住宅や小規模店舗など）は、第一種または第二種電気工事士（第3条第2項）
  - 自家用電気工作物（ビル・工場など）は、原則として第一種電気工事士など（第3条第1項、第3項、第4項）
- 第二種電気工事士は、ビルや工場などの自家用電気工作物の工事はできません。

  2. **検電器**で、切る箇所の**すべての線**が無電圧であることを確認する
  3. 検電器は使用前後に、**電圧のある箇所で動作確認**をする
- ブレーカーの回路表示は、**増設・改修で実際と違うことがよくあります**。「OFFにしたから大丈夫」と思い込まないでください。

## 3. 撤去対象のケーブルを確実に特定する

- ダクト、ラック、ピット、天井内には、**撤去しないケーブルが一緒に通っている**のが普通です。
- 次の方法を併用して確認します。
  - 図面、ケーブル台帳、ケーブルの札
  - **両端**まで実際にたどって確認する（片端だけで判断しない）
  - ケーブル識別器（ケーブルチェッカー）などの機器
- 「見た目が同じ」「たぶんこれ」は禁物です。確証が持てないときは、作業を止めて責任者に確認してください。

## 4. 思わぬ電源や電荷がないか確認する

- 別系統から電気が来ていないかを確認します。
  - 非常用発電機、UPS、蓄電池、太陽光発電（逆流・自立運転）
  - 二重受電、他盤からの制御電源、インターロック回路
- **進相コンデンサ**やケーブルの静電容量に**残留電荷**がないか確認します。高圧では放電も必要です。
- 長いケーブルが近くの活線と並んでいる場合は、**誘導電圧**にも注意します。

## 5. 切断の方法と、切断後の処理

- 絶縁手袋、保護メガネなど適切な保護具を使い、**絶縁工具**や切断用の専用工具を使います。
- 活線の可能性が少しでも残る場合は、**活線作業**に当たります。活線作業・活線近接作業の規定は、労働安全衛生規則第2編第5章（第329条以降）にあります。資格のない人や若手が判断して行う作業ではありません。
- 切断後は、**切り口や残る側の端末を絶縁処理**（絶縁キャップやテープ）します。そのうえで、**電源側の端末が露出したまま残らない**ようにします。
- 電源側を先に外してから、負荷側を処理します。
- 作業後は、通電する前に**作業者全員が安全な位置にいる**ことを確認し、合図して通電します（労働安全衛生規則第340条、第345条など通電時の措置も参照）。

## 6. その他の確認事項

- **石綿（アスベスト）**：古い建物では、ケーブル被覆、耐火被覆、貫通部の充填材などに石綿が含まれていることがあります。事前調査が必要です（石綿障害予防規則第3条）。
- **防火区画の貫通部**：ケーブルを撤去したあとの穴は、**元の耐火性能を保つ処理**が必要です（建築基準法施行令第112条第20項）。
- **廃棄物**：ケーブルの被覆や金属くずは産業廃棄物として、廃棄物処理法に従って処理します。

**0.1 MΩ 以上**が必要です。
