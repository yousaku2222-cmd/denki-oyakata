# 資格がなくてもできる作業

結論から言うと、**あります。ただし範囲は限られます。** 次の3つに分けて考えると整理しやすいです。

## 1. 「電気工事」にあたらない軽微な工事
電気工事士法では、次の工事は「電気工事」から除かれています。

- 根拠は電気工事士法 第2条第3項ただし書と、同法施行令 第1条です。
- 具体的には次のものが該当します。
  - 600V以下で使う差込み接続器、ソケット、ローゼット、スイッチなどに、コードやキャブタイヤケーブルを接続する工事
  - 600V以下で使う電気機器や蓄電池の端子に、電線をねじ止めする工事
  - 電線を支持する柱や腕木などの工作物を設置・変更する工事
  - 地中電線用の暗渠や管を設置・変更する工事

## 2. 保安上支障がないとされる軽微な作業
電気工事士法 第3条のただし書と、同法施行規則 第2条（軽微な作業）に定められています。

- 600V以下で使う電力量計、電流制限器、ヒューズの取付け・取外し
- 電鈴、インターホン、火災感知器などに使う小型変圧器（二次電圧36V以下）の二次側配線
- 上記1の工事に類する作業

条文の項・号の細かい区分は、必ず最新の条文で確認してください。

## 3. 補助的な作業
電気工事士の指示・監督のもとで行う補助作業も、一般に資格なしで行われています。

- 資材の運搬、墨出し、はつり、穴あけ
- 工具の準備、片付け、清掃
- 電気工事士が行う作業の補助（支え、押さえなど）

次の点に注意してください。

- **電気工事士の作業を、手伝いの名目で無資格者が行うことはできません。** 例は次のとおりです。
  - 電線相互の接続
  - 配線器具の取付け
  - 電線管への電線の収納
  - 接地工事
- 電気工事士法 第3条は、無資格者が従事してはならない作業を定めています。違反すると罰則があります（同法 第14条）。
- 補助作業の線引きは、経産省の通達や運用に従います。迷ったら、自己判断せず、現場の責任者（電気工事士）や所轄の産業保安監督部に確認してください。

## 資格以外の注意点

- **特別教育**
  - 低圧・高圧の充電電路を扱う業務には、特別教育の修了が必要です（労働安全衛生法 第59条第3項、労働安全衛生規則 第36条）。
  - 電気工事士の資格があっても、教育の受講が必要になる場合があります。
- **停電作業・活線近接作業の措置**
  - 労働安全衛生規則 第329条以下、第339条、第341条以下に定めがあります。
  - 無資格かどうかにかかわらず、感電防止の措置が必要です。
- **電気工事業法**
  - 会社が電気工事業を営むには、登録または届出が必要です。
  - 主任電気工事士の設置義務もあります。

## まとめ

| 区分 | 無資格で可否 |
|---|---|
| コード接続、端子ねじ止め、ヒューズ交換など軽微な作業 | 可（条件あり） |
| 運搬、墨出し、補助作業 | 可（有資格者の指示・監督のもと） |
| 配線、器具取付け、電線接続など | 不可（第二種以上が必要） |

現場で迷ったときは、必ず先輩の電気工事士に確認してください。

# L線とN線の違い、線の色

## 1. LとNの違い

| | L線（非接地側電線） | N線（接地側電線） |
|---|---|---|
| 名称 | Live（電圧側・充電側） | Neutral（中性線、日本の100V回路では接地側） |
| 対地電圧 | 約100V（単相100V回路） | ほぼ0V |
| 接地 | されていない | 変圧器の低圧側で接地されている（B種接地工事） |
| 一般的な色 | 黒（3線式では赤も） | 白 |

- 柱上変圧器の低圧側の一端に **B種接地工事** がしてあり、その線が N（接地側）です。もう一方が L（非接地側）です。
- B種接地の根拠は、電気設備技術基準の解釈 第17条（接地工事の種類）と第24条（高圧・特別高圧と低圧の混触による危険防止施設）です。
- N線は電位がほぼ0Vですが、**触っても安全ではありません。**
  - 断線や接続不良があると、負荷を通じて N 線にも電圧が現れます。
  - 他の回路の電流が流れて電位が出ることもあります。
  - 作業前は必ずブレーカーを切り、検電することが基本です。

## 2. 色の意味

| 色 | 意味 | 備考 |
|---|---|---|
| **黒** | L（非接地側） | 単相3線式の外線の一方、VVFの標準色 |
| **白** | N（接地側） | 単相3線式の中性線も白 |
| **緑**（または緑／黄） | 接地線（アース線） | 機器の金属部分の接地用。電流は通常流れない |
| 赤 | 非接地側（もう一方のL） | 3心ケーブル、単相3線式の外線、スイッチの渡り線など |

### 現場での使い分け
- **VVFケーブル**
  - 2心は黒と白です。
  - 3心は黒、白、赤です。
- **単相3線式（100V/200V）**
  - 赤＝L1、黒＝L2、白＝N（中性線）です。
  - 100Vは赤と白、または黒と白から取ります。
  - 200Vは赤と黒から取ります。
- **スイッチ回り**
  - スイッチは必ず L（非接地側、黒）に入れます。
  - 白（N）は照明器具へ直接つなぎます。
  - 3路・4路スイッチの渡り線では、黒や赤を使います。
  - **やむを得ず白線をスイッチの線として使う場合**は、混同しないよう識別（黒や赤のテープなど）をします。
- **コンセント**
  - 向かって右の穴（長い方）が接地側（N、白）、左の穴（短い方）が非接地側（L、黒）です（JIS C 8303）。
  - 接地極付きは、下側の丸い穴に緑線をつなぎます。

## 3. 法令上の位置づけ（重要）

- **色そのものを一律に義務づけている条文は、基本的にありません。** 色別は主に **内線規程（JEAC 8001）** の「電線の色別」や、JIS・業界の慣行によるものです。内線規程は民間規格ですが、現場では事実上の標準です。
- 法的に重要なのは、**接地側と非接地側を取り違えない**ことです。
  - **電気設備技術基準（省令）第10条**は、電気設備の接地を定めています。
  - **電気設備技術基準の解釈 第17条**は、接地工事の種類と施設方法を定めています。
  - **電気設備技術基準（省令）第5条**は、感電・火災などの防止（絶縁・接地）に関する基本原則です。
  - 接地側電線には、原則として **開閉器やヒューズ（過電流遮断器）を単独で入れない**のが決まりです。N線が切れるとスイッチ OFF でも機器側に電圧が残るためです。詳しい条文は最新の解釈と内線規程で確認してください。
- 作業の資格については、**電気工事士法 第3条**が、一般用電気工作物の工事は電気工事士でなければ従事できないと定めています。資格がない人は、軽微な作業（例：電球の交換）以外はできません。

※条文番号は改正されることがあります。実務では、最新の「電気設備技術基準の解釈」と内線規程の該当箇所を確認してください。

## 4. 覚え方（若手向け）

1. **黒＝電気が来ている（L）、白＝戻り（N）、緑＝逃がす（アース）。**
2. スイッチは **黒側**、器具へ直行するのが **白側**。
3. 色を信用しすぎないことも大切です。古い配線や他人の工事では、色が守られていないことがあります。**検電器や測定器で必ず確認**してください。
4. 資格がない場合は、**有資格者の指示と監督のもと**で作業してください。

必要なら、スイッチ・コンセント・3路スイッチの結線を図で説明することもできます。

# 工事写真を撮る理由

## 結論
一番の理由は、**あとから見えなくなる部分が、きちんと施工されたことを証明するため**です。
なお、「工事写真を撮れ」と直接定めた法律の条文は、一般的にはありません。主に**契約（仕様書・施工要領書）で求められる**ものです。法令は、記録や基準適合を求める形で間接的に関係しています。

## 主な理由

1. **隠ぺい部の証明**
 天井裏、壁内、床下、地中の配管・配線、接地極の埋設などは、完成後に確認できません。写真が唯一の証拠になります。

2. **基準どおりに施工した証拠**
 - 電線の接続、絶縁処理、支持間隔、配管の曲げ、貫通部処理、接地工事の状態など
 - 絶縁抵抗計・接地抵抗計の測定値（数値が読める状態で撮る）
 
 根拠：
 - 電気工事士法 第5条（電気工事の作業は技術基準に適合するよう行う）
 - 電気設備に関する技術基準を定める省令 第58条（低圧電路の絶縁性能）、第10条・第11条（接地）など

3. **検査・引渡しの資料**
 発注者や監督員がすべてを立ち会い確認することはできません。写真で確認できるようにしておきます。公共工事では、国土交通省の「工事写真の撮影要領」や公共建築工事標準仕様書（電気設備工事編）に基づく写真管理が求められます。

4. **トラブル・責任問題への備え**
 後日、漏電、火災、不具合、手直し要求があったときに、「施工は適正だった」「原因は施工以外にある」と示す材料になります。
 - 民法 第559条・第562条以下（請負への契約不適合責任の準用）
 - 民法 第637条（契約不適合の通知期間）

5. **記録の保存**
 - 電気工事業法 第24条、同法施行規則 第13条：電気工事業者は帳簿を備え、5年間保存します。記載事項は施工場所、施工年月日、作業者名、検査結果などです。写真は条文上の義務ではありませんが、裏づけ資料として使われます。
 - 建設業法 第40条の3、同法施行規則 第26条：建設業者は営業所ごとに帳簿を備え、法令で定める図書を保存します。

6. **保守・改修時の資料**
 将来の増設や改修のときに、配管ルートや配線位置が分かります。

7. **安全管理・教育**
 KY活動の記録、危険箇所の是正前後の比較、新人教育の資料にもなります。

## 現場での撮り方のポイント
- **施工前・施工中・施工後**を撮る（比較できるように）
- **場所と内容が分かる**ように、黒板や小黒板で工事名、場所、日付、内容を入れる
- **寸法や数値が読める**ようにスケールや計器を一緒に写す
- **隠れる前**に撮る（ふたをする前、ボードを張る前、埋め戻し前）
- ピンボケや暗さで分からない写真は意味がないので、撮ったその場で確認する
- お客様の私物や個人情報、他社の情報が写り込む場合は取り扱いに注意する

## 補足
実際に何を、どの程度撮るかは、**工事の仕様書、発注者の指示、会社のルール**によって違います。分からないときは、先輩や現場代理人に「この工事で必要な写真の項目はどれですか」と先に確認しておくと安心です。

# 漏電はなぜ起こるのか

## 1. 漏電とは
電線や機器の中を流れるはずの電気が、絶縁が破れたり弱まったりして、**大地や金属部分へ漏れて流れる現象**です。電気は電線の被覆（絶縁物）で閉じ込められており、その絶縁が保てなくなると漏電になります。

## 2. 主な原因

**① 絶縁物の劣化**
- 熱：過電流、許容電流を超える使用、タコ足配線、高温の場所での使用
- 紫外線・オゾン・油・薬品による被覆の硬化やひび割れ
- 経年劣化（VVFケーブルなどは長年使うと被覆がもろくなる）

**② 水分・湿気・ほこり**
- 雨水の浸入、結露、配管内への水の滞留
- コンセント周りにほこりと湿気がたまる「トラッキング現象」
- 屋外・浴室・厨房など水気のある場所での防水処理不足

**③ 機械的な損傷**
- 施工時の電線の傷（ステープルの打ち込み過ぎ、ボックスの角での擦れ、無理な曲げ）
- 壁内の釘・ビスによる貫通
- 踏みつけ、挟み込み、引っ張り

**④ 施工不良**
- 接続部の絶縁処理（テープ巻き、差込形コネクタの使い方）の不備
- 電線の皮むき時に心線を傷つける
- 防水コネクタやブッシングの未使用
- 誤配線

**⑤ 機器内部の故障**
- モーター巻線やヒーターの絶縁劣化
- 電気機器内部への水や虫、小動物の侵入（ネズミのかじりなど）

- **感電**：漏電中の機器の金属ケースに触れると、人体を通って電流が流れる

# アース（接地）の目的

## 結論
アースは、**漏電や異常電圧が起きたときに、人が感電したり火災が起きたりしないようにするため**に設けます。

## 主な目的

### 1. 感電の防止（機器側のアース）
洗濯機や冷蔵庫などの金属外箱が内部で漏電すると、アースがなければ外箱が充電状態になります。そこに人が触れると、人体を通って電流が流れ、感電します。

アースがあれば、
- 漏電電流の大部分がアース線を通って大地に流れるので、外箱の電位が上がりにくい。
- 漏電電流が確実に流れるので、漏電遮断器（ELCB）や過電流遮断器が動作しやすい。

### 2. 火災・機器損傷の防止
漏電や地絡を放置すると、火花や発熱で火災の原因になります。アースで地絡電流の通り道を確保して遮断器を確実に動作させることで、これを防ぎます。

### 3. 異常電圧の抑制（系統側のアース）
柱上変圧器の低圧側に施すB種接地がこれにあたります。高圧線と低圧線が接触（混触）したときに、低圧側の電位が大幅に上がるのを防ぎます。落雷などのサージ電圧を大地に逃がす役割もあります。

### 4. ノイズ対策・機能の安定
電子機器のノイズ対策や、基準電位の確保にも使われます（機能用接地）。

| 内容 | 根拠 |

# 電線とケーブルの違い

## 結論
**ケーブルは電線の一種**です。「電線」という大きな分類の中に、「裸電線」「絶縁電線」「ケーブル」などがあります。違いは**絶縁体の外側に、さらに保護被覆（シース）があるかどうか**です。

## 定義（法令上の根拠）
- **電線**：電気設備技術基準（電技）第1条第六号で、次のいずれかの電気導体とされています。
  - 絶縁物で被覆していない導体（裸電線）
  - 絶縁物で被覆した導体（絶縁電線）
  - 絶縁物で被覆した上を保護被覆で保護した導体（ケーブルなど）
- **ケーブル**：電気設備技術基準の解釈（解釈）第1条（用語の定義）に定義があります。電線のうち、導体を絶縁体で覆い、さらに外装（シース）で保護したものを指します。号番号は改正で変わることがあるため、最新版で確認してください。

## 具体例

| 区分 | 構造 | 例 |
|---|---|---|
| 裸電線 | 導体のみ | 硬銅線、接地線の一部 |
| 絶縁電線 | 導体＋絶縁体 | IV、HIV、DV、OW |
| ケーブル | 導体＋絶縁体＋シース | VVF、VVR、CV、CVT |

- **IV線**は絶縁電線で、ケーブルではありません。
- **VVF（Fケーブル）**は、絶縁体の上にビニルシースがあるのでケーブルです。

## 現場での違い

**1. 施工方法**
- 絶縁電線は、電線管（金属管・合成樹脂管など）、線ぴ、ダクトなどに収めて施工するのが基本です。むき出しでの配線は原則できません（解釈第146条、第148条など）。
- ケーブルはシースで保護されているため、ケーブル工事として、造営材に沿わせて支持するなどの方法で施工できます。

**2. 電線管内での使用**
- 電線管の中に通すのは、通常は絶縁電線（IVなど）です。ケーブルを管に通す場合もありますが、これは保護のために管を使う場合です。

**3. 製品規制**
- 電線やケーブルの多くは、電気用品安全法の対象（特定電気用品または特定電気用品以外の電気用品）です。PSEマークの有無を確認します。

- **キャブタイヤケーブル**：ゴムなどの厚い外装を持つ丈夫なケーブルで、移動用機器に使います。

# 圧着器とは

**圧着器（圧着ペンチ）は、電線同士や電線と端子を、圧力でかしめて電気的・機械的に確実に接続するための工具**です。はんだ付けやねじ止めの代わりに、接続部を金属スリーブや端子ごと変形させて密着させます。

|---|---|---|

# 圧着端子の「2」「3.5」「5.5」の由来

## 結論
この数字は、**その端子に使える電線の太さ（公称断面積、単位 mm²）の区分**を表す「呼び」です。数字が 2、3.5、5.5 と中途半端なのは、日本で昔から使われてきた**電線の断面積の標準系列**（…1.25、2、3.5、5.5、8、14、22、38、60、80、100…）をそのまま使っているためです。

## 詳しい説明

### 1. 数字は電線の断面積に対応している
圧着端子は JIS C 2805（銅線用圧着端子）で規格化されています。端子の呼びは、適用電線の公称断面積に合わせてあります。

| 端子の呼び | 適用電線の目安（概数） |
|---|---|
| 1.25 | 約0.25〜1.65 mm² |
| 2 | 約1.04〜2.63 mm² |
| 3.5 | 約2.63〜4.2 mm² |
| 5.5 | 約4.2〜6.6 mm² |

範囲の細かい数値はメーカーのカタログや規格表で確認してください。

### 2. なぜ飛び飛びの数値なのか
- 電線の断面積は、約1.6倍刻みの等比数列に近い系列で標準化されています。
- 太さが少しずつ違う電線ごとに端子を作ると種類が増えすぎます。そのため、1つの端子で一定の幅の電線をカバーする設計になっています。

- 前の数字：適用電線の太さの区分
- 後ろの数字：締め付けるねじの径に合う穴の大きさ

- 違いは、管の**硬さ（剛性）と外径**から来る、実務上の部材選びと留め方です。
- 呼び径が同じでも外径が違うので、**サドルは管ごとの専用品**を使います。

## 1. 法令・基準(共通ルール)
**電気設備技術基準の解釈 第158条(合成樹脂管工事)** に、次の趣旨の規定があります。
- 管の支持点間の距離は **1.5m以下**とする。
- 支持点は、**管端、管とボックスの接続点、管相互の接続点のそれぞれの近く**に設ける。

この規定は「合成樹脂管」としてまとめられており、VE管(硬質塩化ビニル電線管)とPF管(合成樹脂製可とう電線管)のどちらにも適用されます。項番号は版によって変わることがあるので、手元の最新版で確認してください。実務での「管端やボックスから30cm程度以内」という目安は、**内線規程**の合成樹脂管工事の節に基づく運用です。

## 2. 実務上の違い

| | VE管 | PF管 |
|---|---|---|
| 性質 | 硬くて真っすぐ。自立しやすい | 曲がる。放っておくとたわむ |
| 外径 | 呼び径に対して細め(例:呼び16で外径22mm) | 同じ呼び径でもVEと外径が違う |
| 支持部材 | VE管用サドル(片サドル・両サドル)、吊りバンドなど | PF管用サドル、PF管用バンド |
| 留め方のコツ | 温度による**伸縮**が大きい。長い直線では伸縮カップリングを検討し、締め付けすぎて動きを拘束しない | たるみ防止のため1.5m以下を確実に守る。潰さない程度に留める |
| 接続 | 接着剤(TSカップリング)で接続 | PF用コネクタ・カップリングで接続 |

## 3. よくある失敗
- **VE用サドルにPF管を留める(またはその逆)**: 径が合わず、ゆるんだり管を潰したりします。
- **PF管の支持間隔が広すぎる**: 曲がるので、見た目でたるみが出やすいです。
- **CD管(オレンジ)との混同**: CD管は**コンクリート埋設専用**で、露出配管や天井内の支持配管には使えません。露出・隠ぺいで使うのは、自己消火性のあるPF管です。

## まとめ
「支持間隔1.5m以下、管端・接続点の近くを支持」というルールは両方に共通です。部材は、VE管にはVE管用、PF管にはPF管用のサドルやバンドと、管の種類・サイズに合った専用品を選びます。現場では、メーカーのカタログで適合管種と呼び径を確認する習慣をつけてください。

# 盤の中の変圧器は何が危ないのか

「変圧器は危ない」と言われる理由は、主に次の6つです。

## 1. 感電する（ブレーカーを切っても安心できない）
- **変圧器は一次側と二次側の2か所から電気が来る機器です。** 一次側のブレーカーを切っても、二次側に別の電源がつながっていれば充電されます。
- **逆送電（逆励磁）の危険があります。** 二次側に電圧が入ると、一次側に巻数比どおり昇圧された電圧が出ます。例えば 200V→6.6kV の変圧器なら、二次側から逆に電気が来ると一次側に高い電圧が出ます。原因になるのは非常用発電機、太陽光発電のパワコン、別系統からの連絡、仮設電源などです。
- **進相コンデンサなどの残留電荷があります。** 停電後も端子に電圧が残る場合があります。
- **高圧（6.6kV）の場合は触れなくても危険です。** 近づくだけで放電（フラッシュオーバー）することがあります。

## 2. 短絡・アーク（アークフラッシュ）
変圧器の二次側は短絡電流が大きく、工具を落とす、端子を短絡させるなどでアークが出ます。やけどや失明の原因になります。

## 3. 高温でやけどする
運転中の変圧器は、巻線や外箱がかなり熱くなります。停止直後でも熱いままです。

## 4. 火災・爆発
- 油入変圧器は、内部故障で絶縁油が噴出・引火することがあります。
- 過負荷や端子の締付け不良による発熱が、焼損や火災につながります。

## 5. 接地不良による感電
変圧器の二次側は **B種接地工事** が必要です。これは高圧と低圧の混触時に低圧側の電圧上昇を抑えるものです。接地線が外れたり切れていたりすると、故障時に低圧側が危険な電圧になります。外箱の接地も同様です。

## 6. 重量物
変圧器は重く、移動や据付で挟まれる、倒れるといった事故が起こります。

# 工事黒板の書き方の基本

## 1. まず押さえること：法令上の「書き方」は決まっていない
電気工事士法や電気工事業法に、工事黒板の記載方法を定めた条文はありません。書き方は**発注者・元請の指定**で決まります。

- **公共工事**：国土交通省の「営繕工事写真撮影要領」や「デジタル写真管理情報基準」など、工事ごとの特記仕様書で指定された基準に従います。
- **民間工事**：元請や施主の指示、社内ルールに従います。

最初に**現場代理人や職長に「写真の指定（様式・枚数・撮影箇所）」を確認**するのが確実です。

## 2. 黒板に書く一般的な項目
| 項目 | 記入例 |
|---|---|
| 工事名 | ○○ビル 電灯・コンセント設備工事 |

  - 150V超300V以下 0.2MΩ以上
  - 300V超 0.4MΩ以上

# 安全ブレーカの100V用と200V用の見分け方

結論として、**見分けられます**。ただし外観の色だけで判断するのは危険です。本体の表示と極数・素子数で判断してください。

## 1. まず本体表示を見る
- ブレーカ側面や前面に**定格電圧**の表示があります（例: AC100V、AC100-200V、AC200V）。
- 住宅用の小型ブレーカは**「AC100-200V」の両用品**が多く、その場合は本体だけでは用途が決まりません。回路の使い方（単相3線式のどこにつなぐか）で決まります。
- ハンドルの色や形はメーカーごとに違い、100V/200Vを統一的に示す決まりはありません。

## 2. 極数（P）と素子数（E）で見る
単相3線式（L1・N・L2）の住宅分電盤では、主に次の3種類です。

| 種類 | 外観・表示の特徴 | 使い方 |
|---|---|---|
| 1P1E（1極1素子） | 幅が狭い。接続端子は1つ（L相のみ） | **100V回路** |
| 2P1E（2極1素子） | N相側に「N」「中性極」等の表示。過電流素子はL相側のみ | **100V回路**（N相も開閉できる） |
| 2P2E（2極2素子） | 2極とも過電流素子があり、ハンドルは連動 | **200V回路**（L1-L2間） |

- **200V回路には2P2Eを使う**のが基本です。
- 2P1Eは片側にしか過電流素子がありません。200V回路に使うと、素子のない側の電線は過電流から保護されません。
- 製品によって表示方法が違うので、取扱説明書や製品カタログも確認してください。

- **電気設備技術基準の解釈 第33条**: 過電流からの電線および電気機械器具の保護対策。
- **電気設備技術基準の解釈 第34条**: 低圧電路に施設する過電流遮断器の性能等（配線用遮断器の動作特性など）。
- **電気設備技術基準の解釈 第149条**: 低圧分岐回路等の施設（分岐回路の過電流遮断器、電線の太さとの関係）。
- **電気設備技術基準の解釈 第143条**: 電路の対地電圧の制限（住宅の屋内電路は原則150V以下）。単相3線式で100Vと200Vが取り出せる前提になっています。
- **電気用品安全法**: 配線用遮断器は特定電気用品で、定格電圧・定格電流などの表示が義務づけられています。
- **内線規程（JEAC 8001）**: 単相3線式の中性線の扱いや、分電盤の施設要領が書かれています。解釈の条文だけでなく、こちらも確認してください。

# 撤去ケーブルを切る前の注意点

## 1. 資格の範囲を確認する

  - 自家用電気工作物（500kW未満の需要設備）：第一種電気工事士（同条第1項）。600V以下の簡易電気工事は認定電気工事従事者も可（同条第4項）。第二種のみでは不可です。

# 分電盤の容量変更後、送電前にやること

住宅や小規模店舗などの一般用電気工作物（低圧）を前提に説明します。

## 0. 前提：資格の確認
- 分電盤の取替えや容量変更に伴う配線作業は、電気工事士の資格が必要です（電気工事士法第3条、同法施行規則第2条の軽微な工事に該当しない）。無資格の方は、有資格者の指示のもとでの補助や測定の手伝いまでです。
- 自家用電気工作物（受電設備のあるビルや工場など）の場合は、電気主任技術者の関与や保安規程に基づく検査が別途必要です。

## 1. 容量の整合性を確認する
容量を変えると、「幹線・分岐の電線が新しい容量に耐えられるか」が最も問題になります。
- **幹線**：過電流遮断器の定格が幹線の許容電流以下であること（電技解釈第148条）。
- **分岐回路**：ブレーカ定格と電線太さ、コンセントの定格の組合せが適合していること（電技解釈第149条）。
- **過電流遮断器の性能**：定格・遮断容量が適切であること（電技解釈第33条、電技第14条）。
- 引込口配線の太さや、契約容量（電力会社との契約アンペア）とも整合させます。

## 2. 目視・外観・結線の点検（停電状態で）
- 端子の締付け（トルク）、電線の被覆損傷、心線の挟み込みがないか。
- 極性：白線を接地側に接続しているか。
- 単相3線式の場合：中性線欠相保護付ブレーカ（3P2E）の使用、中性線の接続（電圧線と中性線の取り違えがないか）。
- 漏電遮断器の設置（電技第15条、電技解釈第36条）。
- 回路表示（回路名のラベル）の更新。
- 電気用品（PSEマーク付き）であること（電気用品安全法第27条）。

## 3. 絶縁抵抗測定
- 根拠：電技第58条、電技解釈第14条。
- 分岐回路ごとに、負荷を切り離し、スイッチ類をON、分岐ブレーカをONにして測定します。主開閉器はOFFです。
- 判定値（対地電圧150V以下の電路）は **0.1MΩ以上** です。
  - 150V超300V以下：0.2MΩ以上
  - 300V超：0.4MΩ以上
- 機器を外せない場合は、漏えい電流 1mA 以下で判定する方法もあります（電技解釈第14条）。

## 4. 接地抵抗測定と接地線の確認
- 根拠：電技第10条、電技解釈第17条（D種接地）、電技解釈第29条（機械器具の金属製外箱等の接地）。
- D種接地工事は **100Ω以下** です。ただし、0.5秒以内に動作する漏電遮断器がある場合は **500Ω以下** まで認められます。
- 接地線の接続と太さも確認します。

## 5. 導通・極性・電圧確認
- 回路計で導通と極性（コンセントの極性など）を確認します。
- 単相3線式では、中性線の導通と、線間（200V）・対地間（100V）の電圧関係を確認します。

## 6. 漏電遮断器の動作確認
- 試験ボタンで動作確認をします。
- 可能なら漏電遮断器テスターで動作電流・動作時間も確認します。

## 7. 送電と送電後の確認
- 周囲に通電を連絡し、主開閉器から順に投入します。
- 送電後に電圧測定を行い、各回路の動作確認をします。
- 負荷電流や発熱（端子の温度）を必要に応じて確認します。

## 8. 記録と手続き
- 検査結果（絶縁抵抗、接地抵抗など）を記録して残します。
- 電気工事業者は、測定器（絶縁抵抗計、接地抵抗計、回路計）を備える義務があります（電気工事業法第20条、同法施行規則第11条）。
- 契約容量の変更は電力会社への申込みが必要で、電力量計や契約用ブレーカの変更は電力会社が行います。電気事業法第57条に基づく技術基準適合の調査が行われる場合もあります。

## 現場でよくある失敗
- ブレーカだけ大きくして、幹線や分岐の電線は元のままにしてしまう。
- 絶縁抵抗測定時に、機器を外し忘れて数値が悪くなる、あるいは電子機器を壊してしまう。
- 単相3線式の中性線の締付け不良による欠相。
- 接地線をつなぎ忘れる。

※ 条番号は改正で変わることがあるため、実際の工事では最新の電気設備技術基準・同解釈、内線規程（JEAC 8001）で確認してください。

# 100V回路の絶縁抵抗の基準

## 結論：0.1MΩ以上

100V回路（対地電圧150V以下）は、**絶縁抵抗0.1MΩ以上**が必要です。

## 根拠
- **電気設備に関する技術基準を定める省令 第58条**（低圧の電路の絶縁性能）
- **電気設備技術基準の解釈 第14条**（低圧電路の絶縁性能）

| 電路の使用電圧の区分 | 絶縁抵抗値 |
|---|---|
| 300V以下で、対地電圧150V以下（単相100V、単相3線式100/200Vなど） | **0.1MΩ以上** |
| 300V以下で、対地電圧150V超（三相200Vなど） | 0.2MΩ以上 |
| 300V超 | 0.4MΩ以上 |

## 測定のポイント
- 開閉器や過電流遮断器で区切れる電路ごとに測定します。
- 測定箇所は、**電線相互間**と**電路と大地間**です。
- 100V回路には、定格測定電圧**125V**の絶縁抵抗計を使うのが一般的です（JIS C 1302）。
- 測定は停電状態で行います。
- 電子機器、調光器、SPD（避雷器）、LED照明などは、測定電圧で壊れるおそれがあるため、**切り離してから**測定します。
- 解釈第14条では、絶縁抵抗測定が困難な場合に、使用状態で漏えい電流が**1mA以下**であれば認められる例外もあります。

## 実務上の注意
- 0.1MΩは**法令上の最低ライン**です。新設の配線では通常、数十MΩ〜100MΩ超（測定器の上限）を示すのが普通です。
- 1MΩを大きく下回る場合や、前回測定値から大きく下がった場合は、劣化や水の浸入などの異常が疑われます。0.1MΩ以上でも「合格だから問題なし」とは限りません。
- 資格がない方は、電気工事の作業自体が電気工事士法（第3条）の制限を受けます。測定を含め、有資格者の指導のもとで行ってください。

# D種接地工事の接地抵抗値

## 結論
- **原則：100Ω以下**
- **例外：500Ω以下でよい場合**

- **電気設備技術基準の解釈 第17条**（接地工事の種類及び施設方法）：D種接地工事の接地抵抗値を規定しています。
- 上位の法令は **電気設備に関する技術基準を定める省令 第10条・第11条**（電気設備の接地、機械器具の鉄台等の接地）です。
