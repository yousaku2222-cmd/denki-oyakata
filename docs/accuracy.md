# 資格がなくてもできる作業

結論から言うと、**できる作業はあります**。ただし範囲は法令で限定されており、「電気工事士の補助」と「軽微な工事・作業」に分けて考える必要があります。

## 1. 原則（資格が必要な作業）
- 一般用電気工作物（住宅や小規模店舗など）の電気工事の作業は、**第一種または第二種電気工事士**でなければ従事できません（電気工事士法 第3条第2項）。
- 自家用電気工作物（ビルや工場など）の作業は、原則として**第一種電気工事士**が必要です（同法 第3条第1項）。
- 違反すると罰則があります（同法 第14条）。

## 2. 無資格でもできる作業

### (1) 「軽微な工事」（そもそも電気工事に当たらない）
電気工事士法 第2条第3項と、同法施行令 第1条で除外されています。主なものは次のとおりです。
- 600V以下で使用する差込み接続器、ねじ込み接続器、ヒューズなどの接続器や開閉器に、コードやキャブタイヤケーブルを接続する工事
- 600V以下で使用する電力量計、電流制限器、ヒューズの取付け・取外し
- 電鈴、インターホン、火災感知器などに使う小型変圧器（二次電圧36V以下）の二次側の配線工事
- 電線を支持する柱、腕木などの設置・変更
- 地中電線用の暗渠や管の設置・変更

### (2) 「軽微な作業」（電気工事ではあるが資格不要）
電気工事士法 第3条第1項・第2項のかっこ書きを受けた、同法施行規則 第2条に定められています。例は次のとおりです。
- 600V以下で使用する電気機器や蓄電池の端子に、電線をねじ止めする作業
- 小型変圧器（二次電圧36V以下）の二次側の配線作業
- 電線を支持する柱、腕木などの設置・変更
- 地中電線用の暗渠や管の設置・変更

※号ごとの細かい適用範囲（一般用か自家用かなど）は、条文で必ず確認してください。

### (3) 電気工事士の指示・監督下での補助作業
法令に「補助作業」を列挙した条文はなく、経済産業省の解釈（通達）で運用されています。一般的には次のような作業が該当します。
- 材料や工具の運搬、墨出し
- 穴あけ、はつり、仕上げ、片付け
- 支持金物の取付けなど、電線に触れない準備作業

一方、次の作業は**資格が必要**です。
- 電線の接続、結線
- 配線器具や電気機器の取付け
- 配線の施工

境界は微妙です。現場では、必ず電気工事士の指示のもとで、会社や元請の判断を確認してください。

## 3. 資格とは別に必要なもの
- **特別教育**：低圧の充電部の敷設や修理などの業務には「低圧電気取扱業務特別教育」の修了が必要です（労働安全衛生法 第59条第3項、労働安全衛生規則 第36条第4号）。無資格の方こそ必須です。
- **通信線**：電話線やLANなど弱電の一部は、電気工事士法の対象外です。ただし、電気通信事業者の回線に端末機器を接続する工事には、工事担任者資格が必要な場合があります（電気通信事業法 第71条）。
- **電気工事業者側の義務**：電気工事業を営むには登録が必要で（電気工事業法 第3条）、営業所ごとに主任電気工事士を置く必要があります（同法 第19条）。

## まとめ
| 区分 | 無資格で可否 |

| 運搬、墨出し、はつりなどの補助 | ○（有資格者の監督下） |
| 軽微な工事・作業（施行令第1条、施行規則第2条） | ○ |
| 結線、器具取付け、配線施工 | ×（電気工事士が必要） |

# L線・N線の違いと線の色

## 1. 結論

| 線 | 名称 | 色 | 役割 |
|---|---|---|---|
| **L**（Line） | 非接地側電線（電圧側） | **黒**（3線式では赤も） | 対地電圧がかかっている線 |
| **N**（Neutral） | 接地側電線 | **白** | 変圧器側で接地された線。対地電圧はほぼ0V |
| **E**（Earth） | 接地線（アース線） | **緑**（または緑／黄） | 通常は電流を流さない。漏電時の保護用 |

※単相3線式（100/200V）では、黒と赤が電圧線（L1・L2）、白が中性線（N）です。VVFケーブルでは2心が黒・白、3心が黒・白・赤です。

## 2. LとNの違い

- 柱上変圧器の低圧側の1線は**B種接地工事**で大地に接続されています（電気設備技術基準の解釈 第17条、第24条）。この接地された線がN（白）です。
- もう一方の線がL（黒）です。大地との間に約100Vの電圧があり、**Lに触れて大地に電流が流れると感電します**。
- Nは対地電圧がほぼ0Vですが、**電流は流れています**。負荷が動作中に断線したり、他の回路と誤接続したりすると、N側にも電圧が出て感電することがあります。「白だから安全」とは考えないでください。

## 3. 施工上の違い（なぜ区別が重要か）

- **スイッチ・ブレーカー・ヒューズはL側に入れる**のが原則です。N側に入れると、スイッチを切っても器具側にLの電圧が残り、感電の危険があります。接地側電線への開閉器・ヒューズの施設を避けることは、電気設備技術基準の解釈（過電流遮断器の施設に関する各条）や内線規程に規定されています。
- **コンセント**は、接地側極（N）に「W」の表示があるものを使い、白線をそこに接続します。
- **ランプレセプタクル、ソケット**は、受金ねじ部（人が触れやすい側）をN（白）に接続します。
- **単相3線式の中性線**は、欠相すると負荷の電圧バランスが崩れて機器を壊すおそれがあります。そのため、中性線の接続や遮断器の扱いには特別な注意が必要です。
- **接地線（緑）**は、通常時は電流を流さない保護用の線です。LやNの代用にしてはいけません。

## 4. 根拠法令・基準

- **電気設備技術基準（省令）第10条**：電気設備の接地、感電・火災防止の考え方
- **電気設備技術基準の解釈 第10条（電線の識別）**：接地線の色（緑または緑／黄）や、接地側電線の識別（白など）を規定
- **電気設備技術基準の解釈 第17条**（接地工事の種類）、**第24条**（高圧・特別高圧と低圧の混触による危険防止、B種接地）
- **内線規程（JEAC 8001）**：スイッチ・コンセントの極性、接地側電線の扱いなどの実務規定（これは民間規程で、法令ではありません）
- **電気工事士法 第3条**：一般住宅などの低圧設備の工事は電気工事士の資格が必要です。資格のない人は配線工事ができません。

※条文の細かい項番や文言は改正されることがあります。現場で根拠として使うときは、最新の「電気設備技術基準の解釈」で確認してください。

## 5. 現場での注意

- **色だけで判断せず、必ず検電器・テスターで確認**してください。古い建物や他人の施工では、色の誤りや逆接続（極性違い）があり得ます。
- 作業前に**ブレーカーを切り、検電して無電圧を確認**してください。Nも無電圧とは限りません。
- 白線を黒の代わりに使うなど、色の流用は避けてください。やむを得ず使う場合は、テープなどで識別を明示します。

必要なら、単相3線式の結線や、スイッチ・コンセントの結線図も説明します。

# 工事写真を撮る理由

## 結論
工事写真は、**完成後に見えなくなる部分を、正しく施工した証拠として残すため**です。電気工事士法などに「写真を撮れ」という一般的な条文はありません。ただし、**公共工事では契約図書（仕様書など）で撮影が求められ**、民間工事でも発注者や元請との契約・社内ルールで求められるのが普通です。

## 主な理由

1. **隠ぺい部は後から確認できない**
   天井裏、壁内、床下、コンクリート埋設配管、地中埋設ケーブルなどは、仕上げ後には見えません。「ちゃんとやった」と言えるのは写真だけです。

2. **施工品質の証明（検査・竣工）**
   - 配管・配線の施工状況、接地工事、絶縁抵抗測定、接地抵抗測定の結果などを記録します。
   - 根拠となる技術基準の例
     - 絶縁抵抗：電気設備技術基準（省令）第58条、解釈第14条
     - 接地工事：解釈第17条
     - 地中電線の埋設深さ：解釈第120条
   - 基準どおり施工した証拠として、測定値を示した計器の写真や、深さのわかる写真を撮ります。

3. **不具合・トラブル時の責任の切り分け**
   - 後で漏電、火災、不具合が起きたときに、施工が原因か別要因かを判断する材料になります。
   - 請負工事では、施工が契約内容に適合しない場合に**契約不適合責任**を負います（民法第559条・第562条・第637条）。写真は会社と自分を守る証拠になります。

4. **手直し・増設・改修時の資料**
   壁の中の配線ルートや分岐位置が分かれば、後の工事や点検が安全で早くなります。

5. **工程・数量の確認、請求の根拠**
   出来高の確認や、追加工事・変更の根拠になります。

6. **安全管理・教育**
   作業手順や安全対策（停電、検電、接地など）の記録にもなります。

## 公共工事の場合
国土交通省の「写真管理基準」や、営繕工事の「工事写真撮影要領」、公共建築工事標準仕様書（電気設備工事編）などで、撮影項目や方法が定められています。具体的な条番号は版によって異なるので、**現場の特記仕様書と、元請の施工計画書を確認してください**。

## 現場で撮る代表例
- **着工前・完成**：同じアングルで撮る
- **隠ぺい前**：配管・配線ルート、支持間隔、接続部、ボックス内の結線
- **接地工事**：埋設前の接地極、接地線の接続
- **測定**：絶縁抵抗計、接地抵抗計の表示（工事名・回路名が分かるように黒板などと一緒に）
- **地中埋設**：埋設深さ（スケール入り）、埋設標識シート、砂巻き
- **貫通部**：防火区画貫通処理
- **使用材料**：品名・規格が分かる状態

## 撮り方のコツ
- **黒板（工事名、場所、内容、日付、寸法・測定値）を入れる**
- 全景と近景の両方を撮る
- 「何を写したか」が第三者に分かるようにする
- 隠れる前に撮る。**撮り忘れは後から取り返せません**
- 測定値は、読み取れる大きさでピントを合わせる
- 顧客の個人情報（表札、書類、室内の私物など）は写り込みに注意し、データ管理にも気を付ける

## まとめ
写真は「見えなくなる部分の品質と安全を証明する記録」で、自分や会社を守ると同時に、次の工事や保守の人を助けます。撮影項目は現場ごとに決まっているので、**着工前に先輩や現場代理人に必ず確認しておきましょう**。

# 漏電が起きる理由

## 1. 漏電とは
電気は本来、電線の中だけを「行き」と「帰り」で流れます。電線を覆う**絶縁物（被覆など）が壊れたり性能が落ちたりして**、電流が大地や金属製の外箱、水などを通って流れてしまう現象が漏電です。技術基準では**地絡**（ちらく）と呼ばれます。

## 2. 主な原因

| 分類 | 具体例 |
|---|---|
| **絶縁物の劣化** | 経年劣化、熱、紫外線、油・薬品による被覆の硬化・ひび割れ |
| **機械的な損傷** | 壁内のケーブルにビス・釘が刺さる、引き込み時の傷、踏みつけ、挟み込み、被覆をむくときに芯線や被覆を傷つける |
| **水・湿気の侵入** | 屋外配線、防水処理不足、屋外コンセントや接続部への雨水の浸入、結露 |
| **施工不良** | 接続部の絶縁処理不足、端末の処理不良、芯線のはみ出し、ボックス内での被覆の傷 |
| **機器内部の故障** | モーター巻線やヒーターの絶縁劣化、機器内部への水やほこりの侵入 |
| **過熱** | 過負荷や接触不良で発熱し、被覆が劣化・溶ける |
| **汚損・トラッキング** | コンセント周りのほこりと湿気で表面に電流の通り道ができる |
| **動物など** | ネズミがケーブルをかじる |

若手が特に関わりやすいのは、**施工時の傷**、**接続部の絶縁処理**、**防水処理**の3つです。引き渡し時は問題なくても、数か月から数年後に漏電となって表れることがあります。

## 3. なぜ問題か
- **感電**: 漏電している機器の金属外箱に触れると、人体を通って電流が流れます。
- **火災**: 漏電箇所の接触抵抗で発熱し、周囲の木材や断熱材などが燃えることがあります。電流が小さくても、長時間続くと危険です。

## 4. 関係する法令・基準
- **電気設備に関する技術基準を定める省令（電技）第5条**: 電路は大地から絶縁することが原則です。
- **電技第58条**: 低圧電路の絶縁性能です。絶縁抵抗は次の値以上とします。
  - 300V以下で対地電圧150V以下: **0.1MΩ以上**
  - 300V以下でそれ以外（例: 三相200V）: **0.2MΩ以上**
  - 300V超: **0.4MΩ以上**
- **電技第15条**: 地絡が生じたとき、自動的に電路を遮断する装置（漏電遮断器など）の施設を求めています。
- **電技第10条、第11条**: 電気設備の接地について定めています。
- **電気設備の技術基準の解釈（電技解釈）第14条**: 低圧電路の絶縁性能の具体的な基準です。
- **電技解釈第36条**: 地絡遮断装置の施設です。水気のある場所や、金属製外箱を持つ機器の電路などで必要になります。
- **電技解釈第17条、第29条**: 接地工事の種類と、機械器具の金属製外箱などの接地です。

※解釈は改正で条番号や内容が変わることがあります。実務では最新版を確認してください。

## 5. 漏電を防ぐために
1. 配線時は被覆に傷をつけない。傷があれば処理するか交換する。
2. 接続部は規定どおりに絶縁処理する。
3. 屋外や水気のある場所では、防水型の器具とコネクタを使う。
4. 接地工事を確実に行い、漏電遮断器を適切に設置する。
5. 竣工時に**絶縁抵抗測定**（メガー）を行い、記録を残す。
6. 漏電遮断器が落ちたら原因を調べる。分岐ブレーカーを1回路ずつ入れて、どの回路が原因かを絞り込む。

# アース(接地) の目的

## 一言でいうと
**電気の逃げ道をつくって、人と設備を守るため**です。

## 主な目的

### 1. 感電の防止 (いちばん重要)
洗濯機や冷蔵庫などは、内部の絶縁が劣化すると金属の外箱に電気が漏れ (漏電)、外箱が充電状態になります。

- **アースがない場合**: 人が触れると、体を通って大地へ電流が流れ、感電します。
- **アースがある場合**: 漏れた電流の大部分は接地線を通って大地へ流れます。外箱の電位が上がりにくく、感電の危険が大きく減ります。

### 2. 漏電遮断器・過電流遮断器を確実に動作させる
アースがあると地絡電流が流れやすくなり、漏電遮断器や配線用遮断器が動作して電路を自動的に切ってくれます。アースがなければ、漏電していても電流が流れず、遮断器が動かないまま外箱が充電され続けることがあります。

### 3. 高圧と低圧の混触時の電位上昇を抑える (B種接地)
柱上変圧器の内部故障などで高圧が低圧側に混ざると、低圧側の電位が一気に上がります。変圧器の低圧側を接地しておくと、この電位上昇を抑えられます。

### 4. 雷などの異常電圧を逃がす (A種接地など)
避雷器や高圧機器の外箱を接地して、異常電圧を大地へ逃がします。

電位の基準をとる、ノイズを逃がして機器の誤動作を防ぐ、などの目的もあります。

# 電線とケーブルの違い

## 結論
- **法令上の「電線」は広い概念**で、ケーブルも電線の一種です。
- **現場で「電線」と言うときは、多くの場合「絶縁電線（IV、HIVなど）」を指します。** これは、導体を絶縁体だけで覆った状態のものです。
- **ケーブルは、絶縁した導体の外側をさらに保護被覆（シース）で覆ったもの**です（VVF、CV、CVTなど）。

## 構造の違い

| 種類 | 構造 | 例 |
|---|---|---|
| 裸電線 | 導体のみ | 裸銅線、架空線の一部 |
| 絶縁電線 | 導体＋絶縁体 | IV、HIV、DV、OE |
| ケーブル | 導体＋絶縁体＋シース（外装） | VVF、CV、CVT、EM-EEF |
| コード | 細い素線をより合わせた可とう性のもの | ビニルコード、キャブタイヤ |

## 法令上の位置づけ
- **電気設備技術基準（電技）第2条第1項第六号**に「電線」の定義があります。それによると、電線とは強電流電気の伝送に使う次のものです。
  - 電気導体
  - 絶縁物で被覆した電気導体
  - 絶縁物で被覆した上を保護被覆で覆った電気導体

  最後のものがケーブルに当たります。
- **電気設備技術基準の解釈 第1条（用語の定義）**に「ケーブル」の定義があります。電線のうち、絶縁物で被覆した導体を保護被覆で覆ったものなどです。号番号は改正で変わることがあるため、最新版で確認してください。

## 施工上の違い（実務で重要な点）
- **絶縁電線**
  - 絶縁体だけでは機械的保護が足りません。
  - そのため、金属管・合成樹脂管・金属線ぴ・金属ダクトなどに収めて施工します（解釈 第157条ほか、各工事の条文）。
- **ケーブル**
  - シースがあるので、そのままケーブル工事として露出・隠ぺい配線ができます。
  - 支持点間は、造営材の側面または下面に沿う場合に2m以下などの規定があります（解釈 第164条）。
  - 電線管に入れて使うこともできます。

## 補足
- 電線やケーブルは**電気用品安全法**の対象で、規格はJISに規定されています。
  - 例：VVFはJIS C 3342、CVはJIS C 3605
  - 該当品にはPSEマークが必要です。
- 第二種電気工事士の試験でも、「VVFはケーブル」「IVは絶縁電線」という区別は頻出です。
- 条番号は改正で変わることがあるため、実際の施工や設計では最新の**電技解釈**と**内線規程**で確認してください。

# 圧着器（圧着工具）とは

## 用途
**電線同士の接続や、電線と端子の接続を、圧力をかけて確実に固定するための工具**です。ねじ止めやはんだ付けではなく、金属の接続部品（スリーブや端子）を電線ごとかしめて、電気的・機械的に一体化させます。

### 主な用途
1. **リングスリーブによる電線相互の接続**
   - 屋内配線のVVFケーブルの心線どうしの接続など。
   - 第二種電気工事士の技能試験でも使います。
2. **圧着端子（丸形・Y形など）の取り付け**
   - 分電盤、配電盤、機器の端子台への接続のため、電線の先端に端子を付けるとき。
3. **差込形コネクタとは別の接続方法**
   - コネクタは工具なしで接続できますが、圧着は工具で確実にかしめる方式です。

## 使い方のポイント
- **スリーブの大きさと電線の太さ・本数の組合せ**に合った刻印（○、小、中、大）で圧着します。
  - 例：1.6mm×2本は小スリーブを「○」の刻印で圧着。
  - 例：1.6mm×3〜4本、または2.0mm×2本は小スリーブを「小」の刻印で圧着。
  - 例：1.6mm×5〜6本、または2.0mm×3〜4本は中スリーブを「中」の刻印で圧着。

# 圧着端子の「2」「3.5」「5.5」の由来

## 結論
この数字は、その端子に適合する**電線の太さ（公称断面積 mm²）の呼び**です。端子専用の数字ではなく、電線側の昔からのサイズ系列（1.25、2、3.5、5.5、8、14、22、38…）をそのまま使っています。

## なぜ中途半端な数字なのか
旧来の電線は、**より線の素線の本数と径から断面積を計算して、近い値に丸めた呼び**を付けていました。例えば7本より線では次のようになります。

| 素線構成 | 計算上の断面積 | 呼び |
|---|---|---|
| 7本 × φ0.6 | 約1.98 mm² | 2 |
| 7本 × φ0.8 | 約3.52 mm² | 3.5 |
| 7本 × φ1.0 | 約5.50 mm² | 5.5 |
| 7本 × φ1.2 | 約7.92 mm² | 8 |

単線でも同様です。φ1.6 mm は約2.0 mm²、φ2.0 mm は約3.1 mm²で呼び3.5、φ2.6 mm は約5.3 mm²で呼び5.5 に対応します。これは第二種電気工事士の試験でおなじみの太さです。

この系列は、隣り合う値の比が約1.6倍の等比に近い並び（R5系列に近い）になっています。

現在は、IEC系の1.5、2.5、4、6、10…という系列も使われています。ただし圧着端子は旧系列の呼びが残っています。

## 実務上の目安
適合電線は端子ごとに範囲があり、おおよそ次のとおりです。

- 1.25：〜1.5 mm² 程度
- 2：〜2.5 mm² 程度
- 5.5：4〜6 mm² 程度

正確な範囲はメーカーのカタログで確認してください。

## 注意点
- 「R2-4」のようにハイフンの後ろにある数字は、**ねじ（ボルト）の穴径**（mm）で、電線の太さとは別です。
- ビニル絶縁圧着端子の色（赤＝1.25、青＝2、黄＝5.5）は目安です。色だけでなく表示を確認し、圧着工具もそのサイズ用（リングスリーブとは別の、端子用の工具）を使います。

## 根拠となる規格・法令
- **JIS C 2805（銅線用圧着端子）**：端子の形状、寸法、適合電線の呼びを規定。この数字の直接の根拠です。
- **電気設備技術基準 第7条**（電線の接続法）：接続部で電気抵抗を増加させず、引張強さを20%以上減少させないこと。
- **電気設備技術基準の解釈 第12条**（電線の接続法）：圧着接続の具体的な要件。端子部分の扱いも含みます。

数字の由来そのものは、法令ではなく**JISの規格体系と電線の公称断面積の慣習**によるものです。法令が求めているのは、適合する電線サイズと工具で確実に接続することです。

# 通称と種類

「刃を当ててくるくる回して被覆を取る工具」は、一般に **ケーブルストリッパー**（ロータリー式ケーブルストリッパー、シースストリッパー、ケーブルジャケットストリッパーなどとも呼ばれます）です。

## 用途で呼び名が違うことがあります
- **VVF（平型ケーブル）用**: 「VVFストリッパー」。くるくる回すのではなく、挟んで引いて剥く工具です（Fケーブル用）。
- **丸形ケーブル用**（CV、CVT、VCT、キャブタイヤなど）: 「ケーブルストリッパー」や「ケーブルシースストリッパー」。ケーブルに巻き付けて回し、シース（外装）を円周方向に切ります。刃の出る量を調整できる機種が多いです。
- **同軸・通信ケーブル用**: 「同軸ストリッパー」や「ロータリーストリッパー」。
- **太い電力ケーブルのシース**: 「ケーブルシースカッター」や「リングカッター」と呼ばれることもあります。

## 使うときの注意
- 刃の深さをシースの厚さに合わせます。深すぎると内部の絶縁体や心線を傷つけます。
- 縦方向の切り込みは、別にナイフやカッターで入れる場合があります。
- 傷を付けた心線は、そのまま使わず切り戻してやり直すのが基本です。

## 関連する法令・基準
工具名そのものを定めた条文はありませんが、次の規定が関係します。

1. **電気設備技術基準の解釈 第12条（電線の接続法）**
   接続部分では、電線の絶縁性能の低下や電気抵抗の増加を起こさないことが求められます。被覆剥ぎで心線を傷つけると、これらの原因になります。

2. **電気設備に関する技術基準を定める省令 第5条（電路の絶縁）、第6条（電線等の断線の防止）**
   心線の傷は断線の原因にもなります。

3. **電気工事士法 第3条、同法施行規則 第2条（軽微な作業）**
   一般用電気工作物の工事は、電気工事士でなければ作業できません。被覆を剥いて接続する作業は軽微な作業に含まれず、**資格がない人は行えません**。無資格の方は、資格者の指示のもとで補助作業（材料の準備、運搬など）にとどまります。

## まとめ
- 名称は **ケーブルストリッパー（ロータリー式）** です。
- 刃の深さ調整と心線の傷に注意してください。
- 無資格者は被覆剥ぎ・接続の作業は不可です。

写真や型番があれば、より正確な名称も案内できます。

# VE管とPF管の支持の違い

## 結論
**法令上の支持間隔は同じ（1.5m以下）**で、違いは「管の性質（硬い／曲がる）」と「使う支持材が管の外径に合った専用品かどうか」です。

## 根拠
**電気設備技術基準の解釈 第158条（合成樹脂管工事）** で、VE管（硬質ビニル電線管）もPF管（合成樹脂製可とう電線管）も同じ条文で扱われています。主な内容は次のとおりです（項番号は改正で変わることがあるので、最新の解釈で確認してください）。

- 管の支持点間の距離は **1.5m以下**
- 支持点は、管端、管とボックスの接続点、管相互の接続点の**それぞれの近く**に設ける
- 管相互、管とボックスの接続では、差込み深さを管外径の**1.2倍以上**（接着剤を使う場合は**0.8倍以上**）にして堅ろうに接続する

実務上の具体的な寸法や施工方法は、民間規程の**内線規程（合成樹脂管工事の節）**にも書かれています。

## 実務上の違い

| | VE管 | PF管 |
|---|---|---|
| 性質 | 硬い。熱で曲げる | 可とう性があり、手で曲がる |
| 支持材 | VE管用サドル、吊りバンドなど | PF管用サドル、PF管用バンドなど |
| 接続 | TSカップリング＋接着剤（接着剤使用で差込み0.8倍） | PF用のコネクタ、カップリングで機械的に接続（接着剤は使わない） |
| 注意点 | 温度変化で伸び縮みする。長い直線や屋外では伸縮継手を検討 | たるみやすいので、1.5m以下でも間隔を詰めて施工することが多い |

## 間違えやすいポイント
- **サドルは「呼び径が同じでも外径が違う」ため、VE用とPF用は互換性がありません。** 合わないサドルを使うと、ゆるんだり管をつぶしたりします。
- PF管は曲がる分、1.5mぎりぎりだとたるむので、実際は1m前後で止めることが多いです。これは現場の施工品質の話で、法令の数値ではありません。
- 「PF」と似た「CD管」は、**コンクリート埋設専用**です。露出や天井内では、PF管（または不燃・自消性の管）を使います（解釈 第158条の該当項）。

## 覚え方
1. 支持間隔は両方とも **1.5m以下**で、管端やボックス、接続部の近くにも支持点をとる。
2. VEは硬い管なので、**伸縮**に注意する。
3. PFは曲がる管なので、**たるみ**に注意する。
4. 支持材は、**その管専用のものを選ぶ**。

現場では、仕様書や会社の施工要領で「支持間隔1m以下」などより厳しい指定がある場合があります。その場合はそちらが優先です。

# 盤内の変圧器の危険性

「何が危ないか」は、大きく6つに分けられます。

## 1. 感電(いちばん大きな危険)

- **一次側が高圧(6.6kVなど)の場合**は、触れる前に近づくだけで放電(アーク)や感電事故になることがあります。
- **低圧の変圧器(200V→100Vなど)でも**、一次側・二次側ともに充電部がむき出しの端子です。短絡すればアークによる大やけどもあります。
- 感電は50V程度でも危険とされ、100V・200Vでも死亡事故は起きています。

## 2. ブレーカーを切っても安全とは限らない(逆励磁・逆送電)

変圧器は二次側から電圧をかけると、一次側にも電圧が出ます。

- 二次側に非常用発電機、太陽光発電のパワコン、別系統からの渡り配線がつながっていると、一次側を切っても端子が充電されたままのことがあります。
- 盤内に複数の電源(制御電源・予備電源)が引き込まれている場合もあります。
- 盤の表示と実際の回路が違うことも珍しくありません。

**停電させたつもりでも、検電するまでは充電中と考えてください。**

## 3. やけど

鉄損・銅損で常に発熱しています。特に過負荷や換気不良、ほこりの堆積があると、表面や巻線がかなり高温になります。停止直後も熱いままです。

## 4. 短絡・絶縁劣化・火災

- 絶縁劣化や巻線のレアショートで焼損し、発火することがあります。
- 油入変圧器は油漏れや引火のリスクもあります。
- 工具や切れ端を落とすと、端子間短絡の原因になります。

## 5. 高圧と低圧の混触

高圧側と低圧側が内部で触れる(混触する)と、低圧側に高電圧が出ます。そのため**B種接地工事**(混触防止)が義務づけられています。接地線が外れていたり腐食していたりすると、非常に危険です。

## 6. 計器用変成器との混同にも注意

盤内には**CT(変流器)**や**VT(計器用変圧器)**もあります。

- **CTは二次側を開放してはいけません**(高電圧が発生し、焼損や感電のおそれがあります)。
- **VTは二次側を短絡してはいけません**(焼損します)。

「変圧器」とひとまとめに言われている場合、これらも含んでいる可能性があります。

# 分電盤の容量変更後、送電前にやること

「容量変更」は、主開閉器（主幹ブレーカ）の容量変更や契約アンペア変更に伴う入れ替え、という前提で答えます。一般用電気工作物（住宅や小規模店舗）を想定しています。

## 0. 資格の線引き
- 分電盤内の結線、ブレーカの取付け・取替えは電気工事にあたります。第二種電気工事士以上でないと作業できません（電気工事士法 第3条）。
- 資格なしの人は、補助作業（運搬、盤内の清掃、記録の補助など）に限られます。
- 作業する工事士には、技術基準に適合させる義務と免状の携帯義務があります（同法 第5条）。

## 1. 送電前の確認項目

### ① 目視・結線確認（停電状態のまま）
- 図面や回路表のとおりに結線されているか。
- 端子のねじが規定トルクで締まっているか。増し締め忘れは発熱事故の典型例です。
- 単相3線式では、中性線（N）が確実に接続されているか。中性線欠相保護付きの主幹かどうかも確認します。
- 電線の被覆の傷、心線のはみ出し、圧着不良がないか。
- **主幹と幹線・分岐の協調**を確認します。
  - 主開閉器の容量に対して、幹線の太さ（許容電流）が足りているか（電技解釈 第148条）。
  - 分岐回路の電線太さとブレーカ容量の組合せが適正か（電技解釈 第149条）。
  - 例：20A配線用遮断器の回路には1.6mm以上の電線。
- 過電流遮断器の定格電流と遮断容量が適切か（電気設備技術基準 第14条、電技解釈 第33条）。

### ② 接地の確認
- 分電盤の金属製外箱や接地線が確実に接続されているか（電技解釈 第29条）。
- 接地抵抗値を測定します（電技解釈 第17条）。
  - D種接地は100Ω以下。
  - 0.5秒以内に動作する漏電遮断器がある場合は500Ω以下。

### ③ 絶縁抵抗測定（送電前の最重要項目）
- 根拠は電気設備技術基準 第58条（低圧電路の絶縁性能）と、電技解釈 第14条（具体的な数値）です。
- 測定のしかた：
  - 開閉器や過電流遮断器で区切れる回路ごとに測定します。
  - 電線相互間と、電路と大地間の両方を測ります。単相3線式ならL1-N、L2-N、L1-L2、各線-大地です。
  - 負荷機器は外すか、スイッチを切った状態にします。電子機器やLED器具は絶縁計の電圧で壊れることがあるので注意してください。
- 判定値（電技解釈 第14条）：

| 電路の使用電圧 | 絶縁抵抗値 |
|---|---|
| 対地電圧150V以下（100V回路、単相3線100/200V） | 0.1MΩ以上 |
| 150V超300V以下（三相200Vなど） | 0.2MΩ以上 |
| 300V超 | 0.4MΩ以上 |

- 絶縁抵抗計は、一般的な低圧回路なら125V〜500Vレンジを使います。

### ④ 導通・極性確認
- 回路計で導通を確認します。
- 接地側電線（白）と非接地側電線（黒・赤）が逆になっていないか確認します。
- 単相3線式では、極性や相の取り違え、N線の誤接続に注意してください。

### ⑤ 漏電遮断器の確認
- 地絡遮断装置が適切に施設されているか（電技解釈 第36条、電気設備技術基準 第15条）。
- 送電後にテストボタンで動作を確認します。可能なら漏電遮断器テスターも使います。

### ⑥ 最終確認
- 盤内に工具、端材、ビスなどの異物が残っていないか。
- 回路名の表示が現状どおりか（分岐回路を変えた場合は書き換える）。
- カバーが確実に取り付けられているか。
- 作業者全員が盤から離れているか。声かけをして、関係者に送電することを周知します。

## 2. 事務・手続き面
- 契約アンペアの変更を伴う場合は、電力会社（一般送配電事業者）への申込みが必要です。契約用ブレーカ（アンペアブレーカ）やメーター側の作業は、電力会社が行うのが通常です。
- 電気工事業者としての検査・記録の義務については、電気工事業法とその施行規則（検査器具の備付けなど）で定められています。会社のルールに従い、測定値を記録に残してください。

## 3. 送電後（試送電時）
- 主幹から順に、分岐ブレーカを一つずつ投入します。
- 電圧を測定します（単相3線式で100V/200V）。
- 異音、異臭、発熱がないか確認します。
- 漏電遮断器のテストボタンで動作を確認します。

## 注意
- 条番号は、電気設備技術基準の解釈の改正で変わることがあります。実務では最新版を必ず確認してください。
- 作業前の停電、検電、短絡接地や施錠・札掛けなどの安全措置（労働安全衛生規則 第339条など）も、送電前確認と同様に重要です。
- 判断に迷う場合は、必ず先輩の有資格者に確認してください。

必要なら、「絶縁抵抗測定の具体的な手順」や「単相3線式の結線チェックポイント」も詳しく説明します。

# 100V回路の絶縁抵抗

## 結論
**0.1MΩ以上**が最低基準です。

## 根拠
- **電気設備技術基準（電技）第58条**（低圧の電路の絶縁性能）
- **電気設備技術基準の解釈 第14条**

| 電路の使用電圧の区分 | 絶縁抵抗値 |
|---|---|
| 300V以下で対地電圧150V以下 | **0.1MΩ以上** |
| 300V以下で対地電圧150V超 | 0.2MΩ以上 |
| 300V超 | 0.4MΩ以上 |

100V回路は対地電圧が150V以下なので、0.1MΩ以上が基準です。

## 実務での注意点

1. **単相3線式100/200Vも0.1MΩ以上です。**
   対地電圧（電線と大地の間の電圧）は100Vなので、同じ区分になります。

2. **三相200V回路は0.2MΩ以上です。**
   非接地方式だと対地電圧が200Vになり、150Vを超える区分になるためです。「200V＝0.2MΩ」と覚えるのは危険で、**判断基準は使用電圧ではなく対地電圧**です。

3. **測定の区切り**
   電技第58条により、開閉器や過電流遮断器で区切れる電路ごとに、電線相互間および電路と大地の間を測定します。

4. **測定レンジ**
   100V回路では、一般に125Vまたは250Vレンジの絶縁抵抗計（メガー）を使います。500Vレンジで測る現場もありますが、電子機器が接続されたままだと壊すおそれがあります。測定前に**機器を外す**、またはスイッチ類を入れた状態で測定するなど、測定条件を確認してください。

5. **測定が困難な場合**
   解釈第14条では、絶縁抵抗の測定が困難な場合、使用電圧を加えた状態で**漏えい電流が1mA以下**であればよいとされています。

6. **実際の目安**
   新設の正常な回路なら、数MΩから「∞（測定上限超え）」になるのが普通です。0.1MΩぎりぎりの値は、基準は満たしていても劣化や水分侵入の兆候かもしれません。原因を確認しましょう。

## 補足
測定前には必ず**停電・検電・ブレーカOFF**を確認してください。電子機器や漏電遮断器、タイマー、LED器具などは、メーカー指示に従って取り外すか切り離してから測定します。

| 条件 | D種の接地抵抗値 |
|---|---|

## 根拠法令

- **電気設備技術基準の解釈（電技解釈）第17条**：接地工事の種類（A〜D種）と施設方法を定めており、D種の接地抵抗値はここに規定されています。
- **電技解釈 第29条**：機械器具の金属製外箱等の接地を定めています。
