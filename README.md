# でんきの親方

> **あなたの一言が、業界の未来へつながる**
> ベテランが話すだけで、会社の知恵袋が育っていく。

電気工事のベテランが話した現場の知恵を、AI（Claude）が聞き返しながら「知恵カード」にまとめ、若手の質問に**出どころつき**で答える Web アプリです。答えられなかった質問はベテランの「質問箱」に届き、答えると次からは誰でも聞けるようになります。使うほど、会社の知恵袋が育っていきます。

Built with Claude: Japan 2026（2026年11月2日〜8日）の期間中に、Claude Code で新しく作りました。

## 審査員の方へ：試し方

- 公開URL：https://denki-oyakata.web.app （スマホでの利用を想定しています。パソコンでも開けます）
- 最初の画面で「審査員の方はこちら（デモ）」を押すと、ログインなしで若手として試せます。審査員モードで公開したカードと質問箱に送った質問は、その端末にだけ見えるので、ほかの審査員の画面を汚さずに一周を試せます（「切替」で役割を変えてもモードは続き、画面上の「終える」で抜けます）。
- ベテランの側も試せます：右上の「切替」→「ベテランとして使う」→「話す」で話す（文字入力も可）→ AI の聞き返しに答える →「カードにする」→ 確かめて公開。もう一度「切替」で若手に戻って同じことを聞くと、🧰 親方の知恵として答えに出ます。
- 1日に使える回数には上限があります（費用を守るため）。AI を使う操作（聞く・話す・撮る）は1台40回・同じ回線から300回・全体600回分（写真は1回で2回分、写真だけで全体150回）、質問箱への送信は1台20件、カードの新規公開は1台10枚まで（同じ回線・全体にも上限があります）。上限に達すると画面にそう表示されます。同じ回線の上限は、審査員の方が同じ Wi-Fi から触ることを考えて高めにしているため、1つの回線から全体の半分まで使えます（費用の上限は全体の600回で決まります）。同じ質問への答えは保存して使い回し、AI の回数に数えないので、例題はいつでも試せます（保存した答えだけで1台1日200回まで）。
- デモのため、誰でもベテランとしてカードを公開できます（ログインを作らない方針）。公開数の上限、検索語の長さの制限、答えの数値の照合で影響を抑えていますが、実際の運用では会社ごとに招待した端末だけがベテランになれる形を想定しています。

## 普通の AI との違い（正答率テスト）

若手の本物の質問（記入シート）とベテランの失敗談・法令から作った20問と、答えの指示を直す時に見ていない確認用の10問を、でんきの親方と、同じモデル（Claude Sonnet）に知恵カードも条文も渡さずに聞いた答えで比べました。採点は Claude Opus が「正解の要点」と条文の原文に照らして行い、正解の要点はベテランが確かめています。

2026-11-04 に、答えを毎回作り直して4回測りました（同じ問題。3回目は下の「写真の質問から生まれたカード」の直しのあと、4回目は電技解釈を22条から82条に広げたあと）。

| | でんきの親方 1回目 | 2回目 | 3回目 | 4回目 | 素の Claude 1回目 | 2回目 | 3回目 | 4回目 |
|---|---|---|---|---|---|---|---|---|
| 正しさ（○=1, △=0.5）20問 | **93%** | **90%** | **90%** | **90%** | 80% | 80% | 78% | 85% |
| 正しさ　確認用10問 | **95%** | **85%** | **80%** | **95%** | 70% | 65% | 75% | 70% |
| 根拠の誤り（条番号の取り違え・条文に無い内容） | **0問** | **0問** | **0問** | **0問**※ | 19問 | 20問 | 18問 | 18問 |
| 危ない誤り（資格・感電・安全） | **0問** | **0問** | **0問** | **0問** | 4問 | 3問 | 2問 | 5問 |

※ 4回目は採点で1問（#11）が根拠の誤りとされましたが、採点役が「標準仕様書 2.3.4 は金属管の節」と取り違えたものです。2.3.4 は「合成樹脂管配線（PF 管、CD 管）露出配管の敷設」で、引用した文も原文にそのまま書かれているので、ここでは0問としています（[docs/accuracy.md](docs/accuracy.md) には採点のまま載せています）。

- いちばん差が出るのは根拠です。素の Claude は内容が合っていても、「500kW の根拠は施行規則第2条の2（正しくは法第2条第2項）」「断線を防ぐのは電技省令第7条（正しくは第6条）」のように条番号を取り違えます。でんきの親方は、引用が原文と一致しない文を法令として出さないので、根拠の誤りが出ません。
- 素の Claude の危ない誤り（1回目の4件）は、どれも「無資格でもコンセントの取替えはできる」「有資格者の監督の下なら無資格でも作業できる」のように、資格の要らない範囲を広く言いすぎたものでした。でんきの親方は、資格の判定を電気工事士法の条文と、計算（プログラム）でしか出しません。
- 正しさの%は回ごとに5〜10%揺れます（同じ問題でも答えの文が毎回少し変わり、採点も揺れるため。どの問が△になるかも回ごとに動きます）。1回の数字ではなく幅で見てください。根拠の誤り0は、どの回でも変わりません。
- 同じ質問には保存した答えを返す仕組みがあるので、測り直しは functions をデプロイした直後に行います（保存した答えが返ると、測定は止まります）。
- 直した点：写真の質問から生まれたカードが、きっかけの質問の文（「これは何に使いますか？」）のせいで「何に使う」と聞く質問すべてに当たり、圧着器の質問に2連スイッチの知恵が混ざっていました。写真の質問から生まれたカードは、AIが判定した部材名だけで探すように直しました。
- 直した点：電技解釈を、よく使う22条から、第1章 総則の電線・接続・絶縁・接地など・第3章の一部・第5章の全部の82条に広げました。前は一般知識だけで答えていた「電線とケーブルの違い」「圧着器」が、第5条・第9条・第12条を引いて答えるようになり、確認用10問は 80% から 95% になりました。
- 試した変更：専門用語に（ ）で言い換えを付けさせると、20問で83%・確認用で90%でした。揺れの中に収まる差でしたが、上がりはしなかったので外し、言葉の意味は答えの中の下線（押すと意味と出どころ）で見せています。
- 分かっている弱点：#11（VE管とPF管の支持）は、質問が露出か隠ぺいかを言っていないため、PF管の露出配管の「取付け間隔は 1ｍ以下」（標準仕様書 2.3.4）が答えから抜けることがあります。「基準の値は聞かれていなくても示す」指示を足して測りましたが（20問 88%・確認用 85%、根拠の誤り0問）、#11 は直らなかったので外しました。テストの問題に合わせ込むことはしていません。
- このテストの限界：採点も Claude です（人の確かめはベテランの目で一部だけ）。確認用10問は、1回目の結果を見たあとで、ベテランの指摘で正解の要点を直し、カードを足しています（答えの指示は確認用を見て直していません）。採点役にはどちらの答えかを知らせず、アプリの答えは出どころの札を外し、素の答えは書式の記号を外した文章で渡し、両方が挙げた条文の原文を渡しています。それでも文の書きぶりの違いは残ります。
- 11/4 に直した点：前の版では、素の Claude の呼び出しの上限が考える分で使い切られ、20問のうち4問が空の答えのまま×と採点されていました（素の Claude に不利）。直して測り直したのが上の表です。
- 足りない点の多くは、ベテランの知恵が要る所でした。「分電盤の容量変更のあと、送電前に何をする？」は、カードが無い時は△でした。ベテランが「送電前に必ず電圧を測る。中性線が緩んでいると100Vの機器に200V近くかかって壊れる」と話してカードにすると、○になりました。**カードが集まるほど、正しさは上がっていきます。**
- 問題と正解の要点は `scripts/accuracy/questions.json`・`holdout.json`、1問ずつの答えと採点は [docs/accuracy.md](docs/accuracy.md)・[docs/accuracy_holdout.md](docs/accuracy_holdout.md)。`node scripts/accuracy.mjs`（確認用は `--holdout`）で誰でも回し直せます。

## できること

| 画面 | 内容 |
|---|---|
| ベテラン「話す」 | 大きなマイクボタンで話すだけ。AIが1問ずつ聞き返し、知恵カードの下書きを作ります。本人が確かめて直すまで公開されません。名前を出すかどうかは毎回選べます。若手がスマホを持って質問を読み上げる「若手が聞き役」モードもあります。 |
| 若手「聞く」 | 話し言葉・現場の呼び名のままで質問できます。答えは一文ずつ出どころで色分けされます。⚖️青＝法令・基準（原文の引用つき。引用が原文と一字一句一致したものだけ「✔ 引用は原文と一致」。文そのものは AI が引用を読んだもの）、🧰緑＝親方の知恵（誰の・いつの話か）、💡灰＝一般知識（要確認）。引用を押すと条文の全文が開き、引用した所に色が付きます。 |
| 質問箱 | 根拠のある答えが見つからなかった質問がベテランに届きます。押すとそのまま話して答えられ、カードには「きっかけの質問」が残ります。 |
| 貢献の見える化 | 若手が「助かった」を押すとベテランに届きます。質問した若手には「あなたの質問から知恵カードが生まれました」と表示されます。 |
| 計算・判定 | 電線管の占有率（何本入るか・どの太さの管か、断面の図つき）／電圧降下と電線の太さの適否（こう長に応じた目安・許容電流、並列にも対応）／kW から電線の太さ（電動機の幹線は 1.25倍・1.1倍）／電線の許容電流（IV は電技解釈 第146条、CV・CVT はメーカー表、325sq まで）／分岐回路のブレーカーから電線の太さ（電技解釈 第149条 149-1表）／ケーブルラックの配置（1〜2段、必要な幅、高圧と低圧の離隔、断面の図つき）／絶縁抵抗の合否（電技省令 第58条）／接地抵抗の合否（A〜D種、B種は 17-1表・17-2表）／配管・ケーブルの支持間隔／ケーブルラックの支持間隔／この資格でできる工事か（電気工事士法）／監理技術者・専任が要るか（建設業法施行令）。「聞く」で話しかけると Claude が計算を選んで値を入れ、**計算そのものはプログラム**が行います。結果には根拠の条文（原文と照合済み）と計算の過程が付きます。「計算」タブから直接入力もできます。 |
| 撮る | 部材の写真から、名前・現場の呼び名・用途を判定します。自信は「ほぼ間違いない／たぶんこれ（印字で確かめて）／分からない（候補から選ぶ）」で言い切らずに示します。銘板や型番の小さい印字は、写真から切り出して拡大し、読み直します。読めた管の種類・呼びやブレーカーの定格から、その値を入れた計算（占有率、149-1表の電線の太さ）を開けます。関係する親方の知恵カードと条文（Claude が一覧から選び、プログラムが実在を確かめる）、間違えやすい部材、一緒に使う物も出ます。分からない時は写真ごと質問箱へ送れ、調べた部材は「わたしの部材帳」にたまります。 |

## Claude の使い方

仕事ごとにモデルを使い分けています（`functions/src/models.ts`）。

| 仕事 | モデル |
|---|---|
| 質問の振り分け・言い直し（「こう受け取りました」） | Claude Haiku |
| 答えづくり、ベテランへの聞き返し、知恵カードへの整理、部材の写真の判定（小さい印字は拡大して読み直し） | Claude Sonnet |
| 法令カードづくり（条文ごとの要約・検索語・場面。最初に1回だけ）、正答率テストの採点（どちらの答えかを伏せて） | Claude Opus |
| 引用の照合・計算 | プログラム（AI任せにしない） |

AI の答えは、出どころをプログラムで確かめてから表示します。
- 「法令・基準」の文は、AI が付けた引用（quote、12字以上）が、渡した条文の原文に一字一句あるかを照合します（改行・空白・全角半角の違いだけは無視）。さらに、文の中の数値が条文にあるかも確かめます（「六百ボルト」「〇・一メガオーム」のような漢数字も数値に直して比べます）。どちらかが合わなければ法令としては表示せず、一般知識（要確認）に格下げします。一字一句を保証するのは引用の部分で、画面にもそう表示します。
- 「親方の知恵」の文は、実在する公開カードを指しているか、文の中の数値がそのカードにあるかを確かめ、合わなければ一般知識に格下げします。
- 若手の質問とカードの本文は、プロンプトの中で資料として区切って渡し、中に書かれた指示には従わないよう指示しています。

費用と重なりを抑える仕組み:
- **答えの保存**：同じ質問（空白・全角半角・文末の「？」をそろえた文）で、使える共有カードが変わっていなければ、前の答えをそのまま返し、Claude を呼びません。カードの追加・非公開・直しと、新しいデプロイで作り直します。保存するのは質問の文と答えだけで、人ごとの情報は入れません。審査員モードで自分のカードがある時は保存しません。
- **料金の記録**：Claude を呼ぶたびに、モデルごとの回数・トークン数・料金の目安を日ごとに記録します（`functions/src/usage.ts`、Firestore の `usage/<日付>`。画面からは読めません）。
- **同じ質問のまとめ**：まだ答えのない同じ質問が質問箱に届くと、1つにまとめて、聞いた人の数を出します。ベテランが1回答えると、聞いた全員の「わたし」に届きます。まとまった人に返すのは自分が送った文と答えだけで、ほかの人の端末IDや名前は返しません。写真付きの質問はまとめません。

## 構成

- `web/` … Vite + React + TypeScript（スマホ向け、ホーム画面に追加できる形）
- `functions/` … Firebase Cloud Functions。Claude API はここからだけ呼びます。APIキーはサーバー側の Secret に置きます。
- Firestore … 画面からは読むだけ。書き込みはすべて Functions 経由です（`firestore.rules`）。

## 手元で動かす

必要なもの：Node.js 22 以上（Functions の実行環境は 22。web の firebase ライブラリは 24.12 以上を推奨と警告を出しますが、22 でもビルド・動作します）、Java 21 以上、Firebase CLI。

```sh
cd functions && npm install && npm run build && cd ..
cd web && npm install && cd ..
firebase emulators:start --project demo-denki-oyakata   # 別の画面で
cd web && npm run dev                                   # http://localhost:5173
node scripts/e2e.mjs                                    # 一周の動作確認
cd functions && FIRESTORE_EMULATOR_HOST=127.0.0.1:8080 npm test   # 回数制限のテストも含めて
```

APIキーが無い場合は、ダミーの応答で一周動きます。Claude を使う場合は `functions/.secret.local` に `ANTHROPIC_API_KEY=...` を書きます（このファイルは Git に入りません）。

法令・基準の原文は `functions/data/laws.source.json`（条文ごとの原文）と `functions/data/laws.json`（原文＋Claude Opus による要約・検索語）に収めています。作り方は `scripts/laws/`。

| 資料 | 版 | 出典 |
|---|---|---|
| 電気設備の技術基準の解釈（経済産業省） | 令和7年11月20日改正 | https://www.meti.go.jp/policy/safety_security/industrial_safety/law/kijyunkaisyaku.html |
| 公共建築工事標準仕様書（電気設備工事編）（国土交通省大臣官房官庁営繕部） | 令和7年版 | https://www.mlit.go.jp/gobuild/gobuild_tk2_000017.html |
| 電気工事士法・同施行令・同施行規則、電気設備に関する技術基準を定める省令、建設業法施行令 | e-Gov 法令データの現行版（各条の施行日をアプリ内に表示） | e-Gov 法令API v2 https://laws.e-gov.go.jp/ |

- CV・CVT の許容電流（`functions/src/calc/electrical.ts`）は、JCS 0168-2 によるメーカー公表値です（SWCC 総合カタログ「許容電流」、矢崎エナジーシステム 技術資料。2社で一致）。
- 電線管の占有率・ケーブルラックの寸法（`functions/src/calc/conduitData.ts`）は、JIS に基づくメーカー公表の代表値です：IV・VVF（SWCC、HS&T、矢崎の仕様書・カタログ）、CV・CVT（古河電工・SWCC・矢崎の大きい方）、6600V CVT（矢崎 6kV-CVT 仕様書）、管の内径（VE・PF・CD・FEP は積水化学・未来工業・パナソニック・古河電工の小さい方、鋼製電線管はパナソニック・丸一鋼管の外径−2×厚さ、プリカは三桂製作所・パナソニック）。占有率の基準（曲がりが多い・長い配管は 32%、直線・短い距離は 48%）と電圧降下の目安（こう長 60m 以下は 2%、それより長いと 4%・5%・6%）は内線規程の考え方で、内線規程の本文は収めていません。
- 標準仕様書・技術基準の解釈は、PDF から現場でよく使う条・節だけを抜き出し、改行やページ番号を取り除いて（加工して）使っています。要約は AI によるもので、判断には必ず原文を確認してください。
- 電技解釈・標準仕様書・e-Gov の法令は、各サイトの利用規約（政府標準利用規約）に従い、出典を示して使っています。収めている条文は112条で、電技解釈（令和7年11月20日改正）は第1章 総則のうち電線・接続・絶縁・接地・過電流遮断器・地絡遮断・避雷器の20条、第3章 電線路のうち屋側電線路・架空引込線・地中電線路の3条、第5章 電気使用場所の施設の全59条です（発電所・電気鉄道・系統連系の章は入れていません）。電技解釈の表（146-1表・146-2表など）の数値は PDF から文字として取り出せなかったため原文データに入っておらず、許容電流の計算では原文の表の値をプログラムに書いています（条文の画面にもその旨を表示）。
- 知恵カードの中身は、作者の会社のベテランが話した内容です。カードの一覧はリポジトリに含めませんが、正答率テストの記録（`docs/accuracy*.md`・`scripts/accuracy/result*.json`）には、答えに使われたカードの題名と知恵の文が載っています（話した人の名前は載せていません）。書いた人の端末ID、名前を出さないと選んだ時の本名、聞き取りのやりとりの原文は、画面からは読めない場所（`cardPrivate`）にだけ置きます。質問箱の質問（聞いた人の端末ID・写真）も、画面からは直接読めず、Functions を通して必要な分だけ返します。この形にする前に公開したカードは、`scripts/migrate-private.mjs` で移せます。
- 知恵袋のイラスト（`web/public/bag.png`）は、ハッカソン期間中に作者が Google の画像生成（Nano Banana）で作り、背景を切り抜いて縮小したものです。最初の画面の3枚の絵（`web/public/flow/`）も、2026-11-04 に作者が同じ画像生成で、知恵袋の絵を画風の見本にして作り、縮小したものです。画面のアイコン（`web/public/icons/`、36個）も同じ日に同じ画像生成で12個ずつ3枚の表として作り、プログラムで1個ずつに切り分けて背景を抜いたものです。そのほかの絵（ハンコ・計算の図など）と画面の動き（Motion）はすべてコードで描いています。
- 端末を変える時は、「わたし」「わたしのカード」の「端末を変える時」で引き継ぎコードを出し、新しい端末で入れると、カードと質問が移ります（ログインが無いため）。
