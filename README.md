# でんきの親方

> **あなたの一言が、業界の未来へつながる**
> ベテランが話すだけで、会社の知恵袋が育っていく。

電気工事のベテランが話した現場の知恵を、AI（Claude）が聞き返しながら「知恵カード」にまとめ、若手の質問に**出どころつき**で答える Web アプリです。答えられなかった質問はベテランの「質問箱」に届き、答えると次からは誰でも聞けるようになります。使うほど、会社の知恵袋が育っていきます。

Built with Claude: Japan 2026（2026年11月2日〜8日）の期間中に、Claude Code で新しく作りました。

## 審査員の方へ：試し方

- 公開URL：（準備中。11/7までにここに載せます）
- 最初の画面で「審査員の方はこちら（デモ）」を押すと、ログインなしで試せます。
- 1日に聞ける回数には上限があります（費用を守るため）。

## できること

| 画面 | 内容 |
|---|---|
| ベテラン「話す」 | 大きなマイクボタンで話すだけ。AIが1問ずつ聞き返し、知恵カードの下書きを作ります。本人が確かめて直すまで公開されません。名前を出すかどうかは毎回選べます。若手がスマホを持って質問を読み上げる「若手が聞き役」モードもあります。 |
| 若手「聞く」 | 話し言葉・現場の呼び名のままで質問できます。答えは一文ずつ出どころで色分けされます。🧰緑＝親方の知恵（誰の・いつの話か）、💡灰＝一般知識（要確認）、⚖️青＝法令・基準（開発中）。 |
| 質問箱 | 根拠のある答えが見つからなかった質問がベテランに届きます。押すとそのまま話して答えられ、カードには「きっかけの質問」が残ります。 |
| 貢献の見える化 | 若手が「助かった」を押すとベテランに届きます。質問した若手には「あなたの質問から知恵カードが生まれました」と表示されます。 |

開発中：法令の原文との照合（引用が原文にあるかをプログラムで確かめて「✔ 原文と一致」）、電線管の占有率などの計算、部材の写真からの調べもの。

## Claude の使い方

仕事ごとにモデルを使い分けています（`functions/src/models.ts`）。

| 仕事 | モデル |
|---|---|
| 質問の振り分け・言い直し（「こう受け取りました」） | Claude Haiku |
| 答えづくり、ベテランへの聞き返し、知恵カードへの整理 | Claude Sonnet |
| 法令カードづくり、見直し役（開発中） | Claude Opus |
| 引用の照合・計算 | プログラム（AI任せにしない） |

AI の答えのうち「親方の知恵」とされた文は、実在する公開カードを指しているかをプログラムで確かめ、指していなければ一般知識に格下げします。

## 構成

- `web/` … Vite + React + TypeScript（スマホ向け、ホーム画面に追加できる形）
- `functions/` … Firebase Cloud Functions。Claude API はここからだけ呼びます。APIキーはサーバー側の Secret に置きます。
- Firestore … 画面からは読むだけ。書き込みはすべて Functions 経由です（`firestore.rules`）。

## 手元で動かす

必要なもの：Node.js 22 以上、Java 21 以上、Firebase CLI。

```sh
cd functions && npm install && npm run build && cd ..
cd web && npm install && cd ..
firebase emulators:start --project demo-denki-oyakata   # 別の画面で
cd web && npm run dev                                   # http://localhost:5173
node scripts/e2e.mjs                                    # 一周の動作確認
```

APIキーが無い場合は、ダミーの応答で一周動きます。Claude を使う場合は `functions/.secret.local` に `ANTHROPIC_API_KEY=...` を書きます（このファイルは Git に入りません）。

## 使っている外部のデータ

- 現時点で、外部のデータは使っていません。法令・基準（電気設備の技術基準の解釈、公共建築工事標準仕様書、e-Gov 法令データなど）を取り込んだら、出典と版をここに記載します。
- 知恵カードの中身は、作者の会社のベテランが話した内容です（リポジトリには含めません）。
